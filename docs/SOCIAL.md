# 무장 대결·설전·외교 통합

기준 커밋: 2a654a9. 변경 전 42개 테스트, 타입 검사, Vite 빌드 통과. 이전 분석에서 발견한 시작 방비 초기화 오류를 확인했다.

## 통합 판단

- 기존 장수에 무력·지력·매력 수치가 없다. 기존 전투 능력은 유지하고 활동 적성(1~3)과 타입 있는 특성만 추가한다. 적성은 시작 체력·집중·기세를 조금 조정한다. 반격·통찰·보급·중재 등 상황별 특성이 대표 선택의 대안이다.
- 8층(결전 포함), 최대 4장수, 전열·후열, 기존 카드·보상 루프를 유지한다. 대결은 지정 편성 3종에서 원정당 최대 2회 제안하며 거절은 무료다. 기존 사건 3곳 중 최대 2곳에 신규 사건을 배치한다. 보급 노드의 일반 선택도 남긴다. 보급 협상 화면에서 향촌 외교를 대안으로 선택할 수 있다.
- 기존 영입은 무료이므로 여기에 비용을 새로 강요하지 않는다. 비용 있는 신규 인재 사건에서 설전 할인(5→4→2)을 적용한다.
- `Pending` 판별 유니온에 제안/진행/조건 확인/결과를 추가한다. 전투 상태와 동시 진행하지 않는다. 활동 선택은 라운드 번호를 검증하고, 결과 확인은 상태 전환으로 1회 적용한다.
- 대결은 4회, 상대 다음 행동 공개. 강공/견제/방어/승부수, 연속 행동 감쇠와 기세 비용을 사용한다. 방어는 상대 견제에 추가 피해4를 받아 단일 방어 반복을 막는다. 체력 0 판정 후 최대 회차에는 체력 비율 비교(체력 2에 해당하는 차이 이내 무승부). 원정 병력 손실·장수 영구 사망 없음. 승리 방비6, 무승부 방비2, 패배·기권 첫 턴 지휘력-1. 다음 턴 피로 자동 해제.
- 설전은 4개 논점에 대응하는 합의·신뢰 조건이다. 성공 합의10/신뢰2, 부분 성공 합의6/신뢰1, 그 외 실패. 집중·행동 비용, 양보 회복, 같은 답 연속 감쇠. 다음 논점은 통찰 장수만 추가 공개한다. 도전 비용 군량1, 원정 장소당1회. 결과 뒤 수락/포기를 남긴다.
- 외교는 낙양 상단·관문 의용군·향촌 연합 관계 -1~2만 사용한다. 원정 종료 시 초기화. 보급(군량2→5, 다음 카드 보상1회 선택지1감소; 설전 성공 시 감소 없음), 통행(군량3→이동3회 비용1감소), 지원(군량3→다음 전투 방비4·적 전원 피해6·그 전투 카드 보상 선택지1감소). 지원은 관계1 이상. 사절 특성 비용1감소(최소1). 수락은 관계+1. 설전 실패 조건 수락은 관계-1. 제안 장소당 거래1회, 활성 협정 중첩 불가. 협정은 이동마다 소모, 지원은 전투 시작에 소모한다.
- 시작 방비 초기화 오류는 신규 전투 시작 효과에도 영향을 주므로 첫 플레이어 턴 초기화를 시작 효과보다 먼저 수행하는 최소 수정으로 고친다. 기존 전법 `duel` ID는 저장 호환성을 위해 유지하고 사용자 이름만 공식 명칭으로 바꾼다.
- 신규 화면과 공통 HTML 조각은 별도 모듈로 분리. 규칙 미리보기는 복제 상태에서 실제 처리기를 호출한다. 신규 난수는 기존 RNG만 사용한다.

## 확인 방법

군주 선택의 **검증 원정 시작 (시드 31001)**. 1층 화웅 전 대결 → 기존 전투/보상 → 2층 영입 설전 → 3층 외교에서 보급 거래로 우호 → 4층 통행 또는 지원 → 후속 이동/전투. 모든 칸에서 같은 검증 경로를 제공한다. 원정 길이와 보스는 유지하며 검증용 군량20·장수3명만 조정한다. 일반 원정에는 적용하지 않는다.

## 저장·검증

원정 버전2. 버전1의 활동 필드를 기본값으로 채운다. 진행 중 라운드·난수·논점·관계·협정·사용 이력은 저장된다. 구조가 깨진 저장은 안내하고 새 원정을 허용한다. 메타 버전1 유지. 생성 규칙이 바뀌어 버전1·2의 새 원정 지도는 동일 시드라도 달라질 수 있다. 이전 저장의 이미 생성된 지도·전투·RNG는 보존한다. 자동 플레이는 공개 미리보기로 활동 선택, 설전은 조건 확인 후 수락/포기, 외교는 단순 보급·통행·지원 정책. 사람의 빌드 운영이나 재미를 평가하지 않는다.

기존 적 턴 예상 피해의 복합 행동 오차와 여포 발동 설명 차이는 이번 범위에서 수정하지 않았다. 신규 활동 미리보기는 실제 규칙을 재사용하므로 별도 추정식을 쓰지 않는다. 추가 콘텐츠의 재미·난이도는 사람 플레이 검증이 필요하다.
