# 시드 141001 도시 탐색 실행 안내

기준: 2026-10-10 작업본. 아래는 코드와 자동 진행에 근거한 조작 안내이며, 사람의 실제 브라우저 플레이 결과는 **미검증**이다.

## 실행

PowerShell에서 저장소의 `package.json`이 있는 폴더로 이동한다.

```powershell
Set-Location 'C:\Users\mambo\Documents\Codex\2026-10-09\mam\work\mambo1'
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Node 22.18 이상이 필요하다. `dev`는 실제 package.json의 Vite 실행 명령이다. 서버가 출력하는 **Local:** 뒤의 주소를 사용자 브라우저에 입력하고 터미널을 열어 둔다. 보통 `http://127.0.0.1:5173/`이지만 실제 출력이 기준이다. 포트가 이미 사용 중이면 오류를 확인한 뒤 5174 등으로 포트를 바꿔 실행한다. 주소·포트가 바뀌면 브라우저 저장 공간도 달라질 수 있다.

배포용 소스는 `outputs/mambo1`, ZIP은 `outputs/mambo1-source.zip`이다. ZIP을 풀었다면 그 안의 `package.json` 폴더에서 실행한다. 자체 포함 HTML은 `outputs/cheonha-gunjin.html`이다. 에이전트가 파일 주소로 다시 접속하거나 보안 설정을 변경하지 않았다.

## 시작과 첫 만남

1. 제목 화면에서 **천하 캠페인 시작**을 선택한다.
2. **시드 141001 / 형양 / 진궁 / 재야 명사**를 고른다.
3. **이 도시에서 이야기를 시작**을 누른다. 기존 저장의 이어하기는 예전 6단계 화면일 수 있으므로 새 도시 화면 확인에는 새 캠페인을 사용한다.
4. 객사에 주인공 표식이 있고 준비 시간 42칸이 남아 있는지 확인한다. 지도 드래그·확대만으로 시간·자금·위치가 변하면 오류다.
5. 현재 객사에 **진입**한다. 입장에 시간이 들고, 주인공과 사건 장면·방문 인물이 나타난다. 새 캠페인의 첫 인재 단서는 순욱이다.
6. 순욱의 부탁은 이제 즉시 완료되지 않는다. 객사 기록 확인 → 문서고 조사·설전/대체 접근 → 결론 → 객사 귀환 보고를 진행한다. [현재 객사 의뢰의 정확한 버튼 순서](INN-PLAY-GUIDE.md)를 따른다. 보고 뒤 **임시 지원 카드**를 선택했다면 손패에서 실제로 사용해 협력 실적을 만든다. **관계 협력**은 카드 대신 신뢰와 실적을 얻는 선택이다.
7. 신뢰·부탁·실적·자금 조건이 충족되면 고유 카드 하나를 선택해 등용한다. 새 개인 카드는 자동으로 덱에 모두 들어가지 않는다.
8. 지도에 돌아와 **카드 보관함**에서 사용할 개인 카드를 편성한다. 등용한 인재를 **인재** 패널에서 동행자로 지정한다. 초기 동행은 1명이며 파견 인재와 중복할 수 없다.

카드는 먼저 선택해 미리보기와 비용을 읽고 사용한다. 장소마다 사용할 수 있는 카드 계열이 다르다. 카드 사용은 장소 종료나 설전 라운드 종료와 별개다.

## 도시를 돌아다니며 조합 만들기

처음에는 **객사 → 시장 → 곡물 창고**를 살펴보면 탐색·카드·물품의 차이를 이해하기 쉽다. 지도에서 목적지를 선택한 뒤 표시되는 이동 시간·군량·노출을 확인하고 이동한다. 이동 후에는 장소 진입을 따로 누른다.

| 장소 | 확인할 선택과 연결 |
| --- | --- |
| 시장 | 장부 분쟁을 조사한다. 정보 카드로 접근 조건을 바꾸고, 거래·설전·호위 대결 중 현재 열린 선택을 확인한다. 여러 단계가 이어지는 복합 사건이다. |
| 곡물 창고 | 비축 확보와 운반 접근을 비교한다. 군량과 도시 창고 협력의 차이를 확인한다. |
| 민가 | 보호 약속과 주민 지지를 얻는 대가를 확인한다. 약속은 거병 후에도 도시 의무가 된다. |
| 문서고 → 관청 | 정보·소개장·인장 등의 실제 접근 조건을 비교한다. 문서를 보존하면 거병 후 운영에도 연결된다. |
| 향촌 사당 | 실제 설전으로 공론을 모아 민회 계획을 발견한다. 실패하면 남은 기록과 후속 중재를 확인한다. |
| 병영 → 동문 | 군사 지도자와 만나고 무장 대결·군영 장악·통행 계획을 비교한다. 승리만으로 인재가 자동 등용되지는 않는다. |
| 성외 폐장원 | 지도 물품이나 정보로 위치를 찾은 뒤 위험·이동비를 확인한다. 시간과 노출을 감수하는 선택이다. |

**모든 경로를 한 번에 돌 필요가 없다.** 같은 시드라도 카드 사용 순서·동행·시간 소비가 달라지면 만나는 인물과 결과가 달라진다. 현재 위치와 다음 이동 단서는 인물 기록과 소문에서 확인한다. 장소를 고르는 동안 다음 방문에 쓸 시간을 남긴다.

일반 물품은 3칸, 중요 물품은 2칸이다. 물품 패널에서 출처와 사용처를 읽는다. 소개장·장부·인장은 관련 사건의 증거·권한으로 소비한다. 치료 물자는 피로를, 지도는 길과 인물 정보를 바꾼다. 보관 공간이 차면 사용하거나 버린 뒤 대기 중인 물품을 받는다.

두 사건을 경험하면 주인공 성장 선택을 확인한다. **통찰**은 정보와 중요 물품, **결단**은 부담 카드 교체에 초점을 둔다. 성장 뒤 동행 한도가 2명으로 늘어난다. 인재 경험 2를 채우면 숙련 또는 권한 성장도 비교한다. 권한에는 의무가 따른다.

## 설전·대결과 저장 복원

설전 화면에서는 요구 수치, 신뢰, 부담, 집중, 다음 반론을 읽는다. 카드를 사용해도 집중과 유효 행동이 남으면 계속 행동한다. **라운드 종료**를 눌러야 상대 반론과 다음 손패로 진행한다. 최종 제안의 예상 등급을 확인한 뒤 합의를 제안한다.

무장 대결에서는 상대의 다음 행동과 선택별 예상 체력을 비교한다. 대결 결과를 확인하는 버튼을 눌러야 그 결과가 도시 사건에 반영된다. 패배·기권도 결과를 처리한 뒤 다음 선택으로 이어진다.

다음 지점에서 각각 새로고침한 뒤 **천하 캠페인 이어하기**를 선택한다.

- 지도 이동 직후: 위치·시간·카메라·군량이 같은가?
- 장소의 첫 접근 이후: 사건 단계·이미 사용한 카드·소모한 물품이 같은가?
- 설전 또는 대결 중간: 손패·집중·체력·상대 예고가 같은가?
- 보상 또는 성장 직후: 보상이 중복 지급되지 않는가?
- 거병 후: 같은 도시의 확보 장소·피해·시설·인재 배치가 남는가?

새로고침 전후 값을 기록한다. 저장을 개발자 도구에서 수정하거나 승리 상태를 주입하지 않는다.

## 거병에서 첫 원정까지

1. **거병 준비** 패널에서 발견한 계획을 확인한다. 민회는 공론, 군영은 군사 협력, 내응은 관청·통행 정보가 단서다. 잠긴 계획은 필요한 방향을 읽는다.
2. 준비가 됐으면 탐색을 마치고 대표·보좌를 확정한다. 최종 카드 정제도 한 번 선택한다.
3. 계획의 준비 부족·노출·약속을 비교한 뒤 실제 관문을 시작한다. 내응은 설전과 대결이 이어진다.
4. 성공 결과에서 세력 교리를 정하고 이름·군기를 확인해 창설한다.
5. **같은 형양 지도**가 운영 화면으로 이어지는지 확인한다. 관청에서 인사·정책, 시장에서 교역, 병영에서 모병·훈련, 창고에서 비축을 확인한다. 명령은 행정력·담당 장수·자원을 실제로 사용한다.
6. 필요한 인재를 도시에 임명한다. 도시 담당과 군단을 동시에 맡을 수 없으며, 개인 카드도 실제 배치에 따라 사용 가능 여부가 바뀐다.
7. 동문 또는 **전도**에서 성고 등 목표 도시를 선택한다. 금고 2·전략 행동력 1·병력 12 이상과 화면에 표시된 군량 조건을 준비한다. 부족하면 실제 모병·교역·턴 정산으로 보충한다.
8. 출진할 병력과 군량을 입력하고 확정한다. 도시 비축에서 차감된 값과 실제 원정 자원이 일치하는지 확인한다.

남은 시간 3 이하이고 계획이 하나도 없다면 긴급 민회 선택이 나타난다. 채무와 노출을 감수하며 최종 관문으로 넘어가는 선택이다. 좋은 준비와 같은 결과를 보장하지 않는다.

## 데스크톱·모바일 확인

모든 항목의 초기 상태는 **미검증**이다.

- 데스크톱: 지도와 좌우 패널의 겹침, 긴 한글 줄바꿈, 손패 가로 스크롤, 확대 후 현재 위치 찾기, 키보드 초점과 버튼 설명.
- 좁은 화면: 주인공·지도·문맥 패널의 재배치, 잘린 버튼, 손패 스크롤, 서랍 닫기, 터치 드래그와 장소 선택의 충돌.
- 접근성: 글자 확대, 확대율 125~200%, 동작 줄이기 설정, 색상 없이도 위험·확보·잠금 구분 가능 여부.
- 실제 모바일은 창 크기를 줄인 데스크톱 검사와 따로 기록한다.
