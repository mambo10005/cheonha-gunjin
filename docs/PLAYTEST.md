# 사람 플레이 시험 묶음

자동 테스트·자동 정책 결과는 재미를 증명하지 않습니다. 이 묶음은 사람이 직접 플레이하며 같은 조건에서 기록을 남기기 위한 것입니다.

## 조건
- 시드 **141001** (새 게임 도시 탐색 기본 시드)
- 관문 난도 **표준(검토 중)** — 계획 화면 「관문 난도」에서 확인
- 시작 인물 **진궁 · 재야 명사**
- 목표: 순욱(문서·정론·조항), 전위(방비·반격·빈틈), 노숙(장부·비용·정보) 중 하나로 거병까지

## 추천 경로
「덱·책략」 서랍의 「사람 플레이 시험」 → 「막혔을 때만 열기 · 추천 경로」에 접혀 있습니다. 처음에는 열지 않고 스스로 연쇄를 찾는 것이 목적입니다. 내용은 `src/data/playtest.ts`에 있으며 자동 검증 스크립트가 실제로 끝까지 간 경로를 요약한 것입니다.

## 기록 내보내기
같은 서랍의 「플레이 기록·설문 내보내기(로컬 파일)」 — 카드 사용·미사용, 표식, 책략 발동, 보상 선택, 덱 교체, 사건별 카드 수, 설전·대결 순서, 설전 등급·조항, 대결 목표 등급, 난도, 설문 답을 JSON 파일로 저장합니다. 이 브라우저에만 저장되며 외부로 보내지 않습니다.

## 플레이 후 설문 (그렇다 / 보통 / 아니다)
1. 카드를 얻을 때 선택이 어려웠는가
2. 핵심 연쇄를 스스로 발견했는가
3. 인재 선택이 덱을 바꿨는가
4. 설전이 반복적이었는가
5. 대결에서 상대 행동을 읽었는가
6. 실패 원인을 이해했는가
7. 거병 관문이 준비를 시험한다고 느꼈는가
8. 다시 다른 빌드를 시도하고 싶은가

추천 경로를 열었다면 언제 열었는지 따로 메모해 주세요(설문에는 자유 기입란이 없습니다).
