## 2. 핵심 카드 연쇄 (턴 순서)
**순욱 — 문서고(6시)**: 장부 조사(장부 2) → 문서 정리: 기록 공백 −2(장부 열쇠 소비), 장부 +2 → 정론 제기: 장부 1 소비 → 서리의 경계 −2·공론 +2, 「공론의 조항」 발동(조항 초안 1) → 인망의 추천: 직전 명분 → 지지 +1, 피난민 불신 −2, 「공론의 조항」 발동(초안 2) → **서리 설전**(조항 정리 2장이 덱에 들어감) 성공. 관청에서 문서 정리 → 정론 제기(초안 3), 사당에서 왕좌의 인선 → 명망의 기초 → 인망의 추천(순욱 원칙 「공론의 인선」 공론 +1) → 민회 설전 성공 → 최종 조항 「공동 운영 조항」(유민 정착 정책).

**전위 — 곡물 창고(6시)**: 호위 인력 조사(방비 1) → 방비 태세: 호위 공백 −2(방비 열쇠 소비, 「반격의 진형」 장애 +1·기세 +1), 방비 +2 → 반격: 방비 1 소비 → 막힌 통로 −2(+「반격의 진형」) → 통행권 대결 승리(선제 돌격/반격 태세/결사 일격). **병영(26시)**: 방비 태세 → 반격(방비·기세 소비, 전위 원칙 「선봉 호위」, 지휘권 불신 −3 해소) → 훈련 대표 대결 승리 → 군영 장악 대결: 시작 방비 9·기세 5·반격 추가 피해 3 → 결사 일격 23 피해 → 신승.

**노숙 — 시장(6시)**: 거래 주선(장부 1·약속 1) → 장부 대조: 장부 1 소비 → 단서 +2·내부 협력 +1, 「장부의 그물」 → 수비 교대 조사: 「장부의 그물」(장부 소비 → 단서·내부 협력) → **곡물 창고(11시)**: 노숙 공동 대조 → 장부 대조: 막힌 통로 −2(단서 열쇠) → 거래 주선: 「장부의 그물」 → 우회로 확보 → 장부 설전 성공. **동문(36시)**: 장부 대조 → 수비 교대 조사(「장부의 그물」) → 양측의 계산: 단서 2 소비 → 내부 협력 +2(노숙 원칙) → 성문 내응 설전 성공, 우회로·내부 협력 8로 후속 대결 없이 개방.

## 6. 전위 공동 호위 전투 패배 분석
9edf070의 패배 전투를 같은 시드로 재현했습니다(체력 16, 산적 3명이 후열에 턴당 15 피해, 첫 손패 동요 1장+창 4장, 시작 방비 0).

| 조건(같은 덱, 손패 60회 재분배) | 승률 |
|---|---|
| 탐욕 자동 정책 | 8% |
| 같은 덱, 4장 탐색 정책 | 55%(원래 시드도 승리) |
| 목표 고정 정책 / 방비 우선 정책 | 5% / 8% |
| 동요 2장 제거 | 42% |
| 계약 방비 3 추가 | 42% |
| 체력 +6(병력 +2) | 62% |
| 방진 1장 추가 | 22% |

- **덱 자체**: 약하다기보다 병력 2로 체력 16이 첫 턴 피해 15를 견디지 못하는 준비 조건이 가장 큼.
- **준비 임시 카드 부족·불균형**: 대결로 통과한 경로는 피해 +3만 받고 방비가 없었음. 미해결 장애 2개가 동요 2장(죽은 카드)으로 들어감. → 통행권 대결 승리에 「호위 대표의 인정 → 방진」 변환을 추가(적 수치는 바꾸지 않음).
- **드로우 편차**: 첫 손패에 방비 카드가 없었음(재분배로 승률이 크게 흔들림).
- **자동 정책**: 1수 앞 탐욕 정책이 첫 턴에 한 적을 끝까지 줄이는 판단을 못 함(8% vs 55%).
- **목표 선택·방비 순서**: 목표 고정·방비 우선 정책은 더 나쁘거나 같아 주원인이 아님.
현재 규칙의 같은 빌드 전투는 손패 재분배 승률 90%(탐색 정책 100%)지만, 이번 실행의 원래 시드는 탐욕 정책이 첫 턴에 방진 1장·창 1장만 쓰고 둘째 턴 피해 12를 받아 패배했습니다(같은 시드에서 탐색 정책은 승리).
