## 판단
- 세 빌드는 방문 장소·의뢰·퍼즐 해결 방식·인재·성장 방식·관문·거병 후 정책이 모두 다릅니다. 카드 이름만 바뀐 같은 경로는 아닙니다.
- 관문 대조에서 빌드가 시작 조건을 실제로 바꿉니다(민회: 요구 2 감소·신뢰 +2, 군영: 상대 체력 −7). 성문 내응 설전은 대조와 요구가 같고, 빌드 효과는 후속 대결 생략에 몰려 있습니다.

## 확인된 약점(다음 작업 후보)
1. **책략이 거의 발동하지 않았습니다.** 첫 사건 보상으로 얻은 뒤 남은 카드 사용 기회가 적어, 세 빌드 모두 책략 효과 로그가 없거나 한 번뿐입니다. 책략 획득 시점을 앞당기거나 시작 시 1개 선택이 필요해 보입니다.
2. 세 빌드의 기본 7장이 같아 연쇄의 상당 부분이 공용 카드에서 나옵니다(전위 빌드도 물자→물자 연쇄가 가장 많음). 인재 카드가 손패에 오는 빈도가 낮습니다.
3. 전위 빌드의 공동 호위 전투는 자동 전투 정책으로 패배했습니다(미해결 장애 2개가 동요 카드로 들어감). 사람 플레이 결과는 아닙니다.
4. 설전 결과는 자동 정책 1회씩이며, 빌드 제거 상태에서 실제 설전을 끝까지 비교하지는 않았습니다(시작 조건만 비교).
5. 정보(程普) 중심 부담 빌드는 단위 테스트로만 확인했고 이 시드의 전체 플레이로는 검증하지 않았습니다.
