# 낙양 지역 원정 지도 — 구현·자료·검증·실행 안내

작성: 2026-10-09. 지원 시점: 190년(초평 원년). 역사 데이터 `henan-190-review-1`, 지역 규칙 1, 기존 저장 형식 5.

## 적용 범위와 현재 저장소 분석

기존 「천하군진」을 유지하면서 낙양 동쪽의 하남윤 회랑을 새 원정 지도에 연결했다. 기존 최종 상대가 동탁이므로 남양에서 새 결전을 만들기보다 형양에서 낙양으로 서진하는 지역을 선택했다. 동탁과 낙양 성외에서 싸우는 결말, 장수의 참여, 활동 위치는 **가상 전개**다. 190년 실제 전쟁의 전개나 당시 도시 상태를 그대로 재현하지 않는다.

`docs/DESIGN.md`, README, package.json, 지도 생성·이동·저장·협정·자동 플레이·기존 UI/테스트를 확인했다. 적용되는 AGENTS.md는 발견하지 못했다. 내부 단계와 열 좌표는 성장 기회, 상대 등급, 협정 대상, 자동 플레이, 저장 검사에 강하게 결합되어 있다. 따라서 이를 삭제하지 않고 `newRegionalRun` 어댑터를 추가했다. 22개 거점, 8단계, 기존 인접 열 연결을 유지한다. 내부 `floor/col`은 그대로 두고 새 화면은 행군으로 표시한다.

기존 지형은 이미 이동·전투 규칙이었다. 새 지도는 이를 시드와 독립된 지리 거점에 고정한다. 기존 생성기의 RNG 소비 순서와 적·시설·보상 생성은 유지한다. 협정은 여전히 `{floor,col}`에 연결되며 지역 어댑터로 같은 위치에 의무 표시를 붙인다. 카메라와 레이어는 별도 UI 저장소에만 저장되고 RNG·군량·전투 판정에 참여하지 않는다.

## 지도 기술과 조작

Leaflet의 Simple CRS는 이미지·게임 지도와 DOM 마커에 적합하다([공식 문서](https://leafletjs.com/reference)). MapLibre는 벡터 타일·WebGL·3D 레이어가 중심이며([공식 소개](https://maplibre.org/projects/gl-js/)), 이 규모에서는 타일·고도·GPU 파이프라인이 필요하지 않다.

**2D 방식 A의 설계를 채택하되, Leaflet 패키지 대신 현재 프로젝트의 SVG/DOM 렌더러를 확장했다.** 22개 거점의 독자 제작 약도를 위해 라이브러리를 추가하지 않은 조정이다. Leaflet 또는 MapLibre가 실제 설치되어 있다고 주장하지 않는다. 광역 GIS/복잡한 다각형이 늘어나면 Leaflet 전환을 재검토할 수 있다. 3D, DEM, pitch, 실측 hillshade는 구현하지 않았다. 능선·음영·고도색은 가독성을 위한 벡터 미술이다.

세 화면을 제공한다. 개관은 낙양 주변 방향 맥락만 보여 준다. 지역 지도는 실제 원정 중심이다. 역사 도시와 활동 거점의 상세 패널은 출처·신뢰도·현대 참고·지형·군량·의무 및 기존 콘텐츠 진입을 연결한다. 전체 중국의 행정 지도나 독립적인 도시 내부 전투 지도는 구현하지 않았다.

카메라: 드래그, 휠, 두 손가락 드래그·핀치, 지도 배경에 초점을 둔 화살표·+/−, 현재 군단·전체 지역·결전·선택 구간 맞춤, 지명 검색. 지역 밖 빈 공간으로 계속 벗어나지 않도록 카메라 범위를 제한한다. SVG 여백을 고려해 포인터 좌표를 환산한다. 거점 클릭과 드래그를 분리한다. 현재 위치 복귀를 기본으로 하고 마지막 카메라 복원은 옵션이다.

지형·지명·경로·군단·거점·정찰·의무·게임 세력 영향 레이어, 고대비·연출 감소, 지도 글자 확대, 전체 거점 목록을 제공한다. 멀리서는 보조 라벨을 줄이고, 가까이서는 정찰 정보를 추가한다. 지도 글자·마커는 카메라 배율과 화면 크기에 맞추어 과도하게 작아지지 않도록 보정한다. 이동 후보 비교와 목록은 SVG와 별개의 HTML 버튼이며 최소 44px 클릭 영역을 가진다. 태블릿·모바일의 선택 패널은 하단 시트다. **실제 화면의 라벨 충돌·모바일 터치 정확성은 사용자 검증이 필요하다.**

## 실제 이동·로그라이트 규칙

카메라는 자유롭게 탐색하지만 군단은 다음 행군의 연결된 2~3곳에서 선택한다. 마지막은 단일 결전이다. 연결은 기존 그래프이며, 새 지형·약도 위에서 북쪽 나루·관도·남쪽 산길을 비교한다. 동일 장소로 무제한 돌아가 보상을 반복할 수 없다.

|---|---|
|평야·관도|군량 1, 기병 카드 피해 +3|
|산길|군량 2, 적 후열 공격 +2, 매 턴 첫 계책 비용 −1; 다음 거점 편성 정찰 제한|
|하천·나루|군량 1, 화상 부여 절반, 방비 효과 +2. 도하점은 약도상 재구성|
|성채|군량 1, 적 시작 방비 10, 승리 군량 +4|
|2행군 중앙 성고 검문|추가 군량 1. 통행 협정이 있으면 검문료 면제; 기존 할인·횟수 소모도 적용|
|일부 산길의 낙석 우회|시드로 고정되는 창작 구간 사건. 군량 1 추가 소비·도착 기록, 경로당 1회 처리|

이동 시간은 산길 2, 나머지 1의 **작전 단위**를 누적한다. 실제 일수나 날씨 효과는 없다. 군량 부족은 기존과 동일하게 부족량당 병력 5 손실이다. 이동 목적지의 고정 지형을 그대로 전투에 전달한다. 검문은 비용을 부과하는 통과 가능한 길이며, 잠긴 관문이나 설전으로 새 간선을 생성하는 기능은 구현하지 않았다.

`movePreview`가 원정 전체를 복제하고 실제 `moveTo`를 실행한다. 성장 선택이 먼저 열리는 경우 이번 클릭 비용이 0이라는 사실, 통행권 소모, 의무 이탈 대가, 군량 부족, 구간 사건 비용까지 같은 결과를 표시한다. UI에서 이동 군량을 별도로 계산하지 않는다. 현재 후보의 비용은 실행 규칙 기반이며, 미확인 구간의 사건 이름·적·보상 결과는 숨긴다. 미래 편성은 정찰 단계에 맞춰 공개한다.

범위 조정: 현재 비교는 **다음 행군의 서로 다른 경유 후보** 2~3개다. 동일 목적지까지 여러 행군을 자동 최적화하는 A*/Dijkstra 경로 계획기나 미래 보상까지 합산하는 자원 예측은 없다. 이후 분기는 실제 그래프를 따라 표시하고 미확인 정보를 미확인으로 남긴다.

도시·하천은 공개다. 군사 상황은 미탐색/지형/거점/위험/완전 정찰로 분리한다. 방문 지점은 완전 정찰, 다음 연결 거점은 평야·하천에서 위험 확인, 산길에서 시설 확인 수준이다. 이동 후 현재 게임 좌표의 거리 반경으로 주변 정보를 추가 공개하고 발견한 간선을 저장한다. 별도 유료 정찰·기상·우회 선택형 구간 사건은 초기 범위에 없다.

세력 영향은 시드로 정해지는 검문군·향촌·상단 표시이며 행정 경계와 구분한다. 기존 세력 관계와 통행·지원·후원·호송 의무는 기존 협정 패널 및 정확한 활동 좌표에 연결된다. 전투·무장 대결·설전·외교·카드 성장·보상은 기존 콘텐츠를 그대로 사용한다.

## 저장·호환성

새 원정은 지역/역사 버전, 시드, 현재 역사 기준점에 연결된 활동 지점, 게임 좌표, 원정 단계, 정찰, 발견 경로, 방문 이력, 소비된 구간 사건, 최근 이동·누적 단위를 저장한다. UI 카메라·레이어·글자 크기는 별도 키에 저장한다.

이동 판정은 동기적으로 한 번 완료한 뒤 기존 활동에 진입한다. 애니메이션은 이미 확정된 결과의 표현이므로 연출 도중 새로고침해도 비용·보상을 다시 처리하지 않는다. 서버와 연동되는 중간 이동 상태는 없으며 `travel.status=arrived`만 저장한다. 소모 이벤트·현재 좌표·정찰 값·버전 등을 검사한다.

기존 버전 1~5 및 지역 정보 없는 원정은 기존 지도를 유지한다. 방문 기록을 지어내거나 이미 진행 중인 전투의 지형을 바꾸지 않는다. 지역 데이터 버전이 맞지 않으면 독립 검사를 통과한 기존 규칙 지도·군량·활동·협정을 보존하고 지역 표현만 제거하여 기존 방식으로 완료한다. 새 원정부터 지역 지도를 사용한다. 기존 31001/51001/61001 전용 데모는 계속 기존 지도에서 동작한다.

```powershell
npm run dev -- --host 127.0.0.1
```

터미널에 출력된 `Local:` 주소를 사용자 브라우저에서 연다. 포트가 사용 중이면 출력된 실제 포트를 따른다. 임의로 5173이라고 단정하지 않는다. 파일 직접 접근이나 브라우저 보안·관리자 설정 변경은 필요 없다.

첫 화면 → **새 원정 → 역사 지리 원정 · 낙양 (81001) → 교리 선택**. 이 데모는 군량 18과 전위·조인·곽가를 준비한다. 일반 새 원정의 시작 자원은 기존대로다. 데모의 1행군은 북쪽 외교, 중앙 재야 인재 설전, 남쪽 산길 화웅 대결 중 선택한다. 셋을 연속 체험하려면 서로 다른 새 원정을 시작해야 한다. 기존 원정 진행은 덮어쓰므로 유지할 원정이 있다면 먼저 해당 브라우저의 저장을 백업한다.

1. 지명 검색에 성고/낙양/구씨를 입력한다. 역사 지명 상세의 위치 추정·자료 출처가 표시되어야 한다. 군량·단계는 그대로여야 한다.
2. 드래그·휠·두 손가락·화살표·+/−를 시험한다. 현재·전체·결전·선택 구간 버튼으로 돌아온다. 군단은 이동하지 않아야 한다.
3. 지도 레이어를 끄고 켠다. 지형·도시를 숨겨도 목록에서 같은 다음 거점을 선택할 수 있어야 한다. 멀리 있는 거점의 적 편성은 공개되지 않아야 한다.
4. 북쪽·관도·산길의 첫 후보를 선택하고 취소해 본다. 군량은 변하지 않아야 한다. 지형 규칙과 이동 단위, 비용을 비교한다.
5. 중앙 첫 후보에서 진군 확정하면 재야 인재 설전 활동으로 들어간다. 실제 카드 여러 장을 낼 수 있고 라운드 종료 버튼으로 반론을 받는다. 다른 새 데모에서 북쪽은 상단 협정, 남쪽은 화웅 대결 제안으로 들어가야 한다. 자동으로 성공하거나 보상을 지급하지 않는다.
6. 활동 도중 새로고침하고 이어하기를 누른다. 같은 상대·카드·활동·군량·원정 위치가 복원되어야 한다. 연출은 다시 보일 수 있으나 비용·보상은 추가 적용되지 않아야 한다.
7. 다음 행군 중앙 성고 검문은 통행 협정 없이 군량 2, 통행 할인 1이 있는 경우 이동 비용 0으로 표시된다. 단, 교리 성장 선택이 먼저 열리면 아직 이동한 것이 아니므로 성장을 선택한 뒤 다시 진군한다. 활성 의무의 이탈 대가가 있으면 총 결과가 달라진다.
8. 계속 진행하여 보급·협정·성장·전투를 해결하고 8행군의 낙양 결전에 도달한다. 같은 시드와 같은 선택을 반복하면 콘텐츠·판정이 같아야 한다.
9. 데스크톱·노트북·태블릿·모바일에서 검색·큰 버튼·하단 시트·명칭 겹침·가로 스크롤·현재 위치·의무·고대비·연출 끄기를 확인한다. 모바일은 목록 모드에서도 동등한 이동 결정을 할 수 있어야 한다.

위 예상 결과는 규칙·DOM 테스트를 근거로 한 사용자 확인 항목이다. **실제 사용자 플레이 결과는 모두 미검증**이다.

## 검증 결과·성능

`npm test`: **189개 통과, 실패 0**. 새 지역 규칙 8개와 컴파일된 DOM 조작 1개를 포함한다. `npm run build`: 타입 검사 및 Vite 빌드 통과. 규칙 검사와 DOM 검사는 실제 Chromium/Firefox/Safari 검사가 아니다.

지역 규칙: 역사 레코드 중복·부모·지원 연도·좌표·신뢰도·출처 검사, 100개 시드의 고정 지형과 연결·결전 도달, 미리보기 불변성·실제 이동 일치, 전투 지형 전달, 정찰·사건 기록·중복 이동 방지, 검문/통행, 군량 고갈, 저장·잘못된 정찰/이동 상태 거절, 버전 변경 폴백, 81001의 실제 세 활동 입구를 확인했다. 기존 협정·무장 대결·설전·전투 테스트도 통과했다.

DOM: 드래그·핀치·휠·키보드 이벤트에 따른 카메라 변경, 검색·출처·레이어·개관·목록, 선택/취소, 카메라와 원정 상태 분리, UI 복원, 이동 1회 실행을 확인했다. 터치 이벤트를 합성한 DOM 결과로 실제 모바일 조작을 검증했다고 주장하지 않는다.

성능 예산: 지역 정적 JSON 환산 40KB 이하, 전체 JS gzip 120KB 이하, CSS gzip 20KB 이하. CPU 기반 원정 생성 평균 1ms, 이동 미리보기 p95 5ms 이내를 개발 측정 목표로 삼았다. 측정 환경은 로컬 Node이며 브라우저 초기 로딩·FPS·모바일 메모리는 미측정이다.

측정: 지역 레코드 JSON 환산 **18,071바이트**, gzip **2,145바이트**. 거점 22개·역사 레코드 9개. 300회 측정의 생성 평균 **0.161ms**, 이동 미리보기 중앙값 **0.272ms**, p95 **0.839ms**. 최종 전체 JS **283.92KB / gzip 95.90KB**, CSS **59.54KB / gzip 14.64KB**. 기존 게임 전체를 포함한 값이며 지도 단독 번들 크기로 해석하지 않는다.

`node scripts/verify-geography.ts`: 실제 전투·성장·활동을 수행하는 헤드리스 자동 플레이, 정책별 30회·총 90회. 최소 군량·정찰 우선 각 25/30회 결전 도달·9회 승리, 성장 우선 27/30회 결전 도달·18회 승리. 군량 고갈은 이 샘플에서 0회다. 최소 군량·정찰 정책은 같은 우선순위 동률 규칙 때문에 북쪽 경로에 집중했고, 성장 정책은 남쪽도 선택했다. 정책의 우월성이나 사람의 재미를 입증하지 않는다. 의무 관찰값은 최종 계약 이행률과 구별한다.

`node scripts/render-geography-fixtures.ts`: 17개 정적 DOM 자료. 상태를 준비한 개관·지역·확대·산길·나루·관문·역사/창작·정찰·세력·의무·모바일·고대비·연출 감소·출처·목록이다. **스크린샷이나 시각 회귀 통과 자료가 아니다.**

실제 브라우저 검증: **실시하지 않음**. 사용자 지시에 따라 정책 차단을 우회·재시도하거나 브라우저 보안/관리자 설정을 변경하지 않았다. 실제 화면·FPS·물리적 터치·사용자 플레이를 추가 확인해야 한다.
