# 시드 141001: 객사에서 시작하는 인연과 의뢰

기준: 2026-10-10 작업본. 자동 규칙·DOM 입력으로 확인하는 순서다. 사용자의 실제 브라우저 플레이와 화면 품질은 **미검증**이다. 이전 저장은 보존된다. 이미 해결한 부탁을 다시 체험하려면 새 캠페인을 선택한다.

## 실행

Node 22.18 이상에서 저장소의 `package.json` 폴더를 연다.

```powershell
Set-Location 'C:\Users\mambo\Documents\Codex\2026-10-09\mam\work\mambo1'
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Vite가 출력한 **Local:** 뒤 주소를 사용자 브라우저에 입력한다. 보통 `http://127.0.0.1:5173/`이다. 서버 터미널을 열어 둔다. 포트 사용 오류가 나면 오류 문구를 기록하고 5174처럼 사용 가능한 포트로 실행한다. 실제 출력 주소가 기준이며 주소·포트가 달라지면 저장 공간도 달라질 수 있다. ZIP을 풀었다면 그 안의 `mambo1/package.json` 폴더에서 같은 명령을 사용한다.

자체 포함 게임 파일은 `outputs/cheonha-gunjin.html`이다. 사용자가 직접 실행할 수 있으나 에이전트의 파일 주소 접근은 재시도하지 않았다. 브라우저 정책이나 관리자 설정을 변경할 필요가 없는 개발 서버 실행을 권장한다.

## 순욱의 부탁을 끝까지 진행하기

1. 제목 화면에서 **천하 캠페인 시작**을 누른다. **시드 141001 / 형양 / 진궁 / 재야 명사**를 고르고 **이 도시에서 이야기를 시작**을 누른다.
2. 현재 장소 **객사**에 **진입**한다. 주인 한복과 순욱, 전위, 심운, 허림의 초상을 확인한다. 한복을 선택하고 **인사와 객사의 규칙**을 누른다. 주인 신뢰가 1이 된다. 같은 인사를 다시 읽어도 증가하지 않아야 한다.
3. 순욱의 작은 초상을 누른다. 주인공과 순욱의 반신 원화, 추천서에 관한 대사가 나타난다. **부탁의 목표·위험·진행 단계 확인**을 누른다.
4. **피난민 추천서의 구휼 보증**의 비용과 기한을 읽는다. **의뢰 수락 · 목표를 지도에 기록**을 누른다. 시간 1·군량 2를 지급한다. 이때 부탁 완료·등용·개인 카드 획득은 아직 일어나지 않는다.
5. 위쪽 의뢰 추적기에서 **공개 출입 기록 확인**을 누른다. 다음 목표가 **문서고**로 바뀐다. 비공개 기록은 주인 신뢰 2나 소개가 필요하다. 첫 체험에는 공개 기록을 사용한다.
6. **도시 지도로** 돌아간다. **문서고**를 선택해 이동 비용을 확인하고 이동한다. 형양에서는 객사와 문서고가 직접 연결된다. 이동 후 **진입**을 별도로 누른다.
7. 의뢰 추적기의 **현장에서 기록과 관련자 조사**를 누른다. 다음 단계에서 **상대의 진술을 실제 설전으로 검증**을 선택한다. 실제 논거 손패와 집중·요구·신뢰·부담, 반론 예고가 나타나야 한다.
8. 카드를 선택하고 미리보기를 읽은 뒤 사용한다. 카드 한 장 사용으로 라운드가 끝나지는 않는다. 집중과 연계 조건을 보며 여러 장을 쓰고 **라운드 종료**로 상대 반론을 처리한다. 모든 결과는 승리를 보장하지 않는 실제 규칙이다.
9. 설전 결과를 확인하고 **설전 결과를 도시 사건에 반영**으로 도시 활동에 돌아온다. 결렬되었다면 **결렬 뒤 추가 조사 · 노출 1**을 선택한다. 결렬 전에는 이 버튼을 사용할 수 없다. 설전 대신 **자금 2로 사본·중재 확보**를 고르는 경로도 있다.
10. 결론 단계에서는 **조건부 보증 · 채무와 구휼 의무**를 선택하면 부분 성공으로 이어진다. 완전히 검증했다면 사실대로 보증하는 결론을 선택할 수 있다. 조건부 보증이 무료의 완전 성공은 아니며 채무와 약속이 남는다.
11. **도시 지도로** → **객사** 선택·이동 → **진입**한다. 의뢰 추적기의 **의뢰인에게 직접 보고**를 누른다. 보고에도 시간 1이 필요하다.
12. 순욱의 부탁 완료·신뢰 15 증가·실적·경험, 주인 반응과 계획 발견 기록을 확인한다. 보고 버튼을 반복해도 보상을 다시 받으면 안 된다. 개인 카드는 보고만으로 덱에 자동 추가되지 않는다.
13. 순욱 대화의 **협력과 등용 · 이미 보고한 인재**를 연다. 실제 지원 카드 사용 또는 관계 협력으로 조건을 쌓고, 표시된 신뢰·자금 조건을 충족했을 때 개인 카드 하나를 골라 등용한다. 상단 **카드 보관함**에서 편성하고 **인물·동행**에서 동행자를 지정한다.

시간을 많이 쓰는 다른 활동은 첫 보고 뒤 체험한다. 의뢰 기한이 지난 후에는 보상을 받을 수 없고, 수락 비용을 돌려받기 위해 포기·재수락할 수도 없다. 보관함에 대기 물품이 있으면 먼저 정리해야 보고가 가능하다.

## 다른 객사 활동

| 활동 | 순서와 기대 규칙 |
| --- | --- |
| 주인 소개 | 한복 선택 → 안쪽 방 소개. 신뢰 2/소개장 보유 시 비용 할인, 아니면 표시된 방값 |
| 개인 부탁 | 한복 → 주인의 개인 부탁 → 수락 → 시장 조사 → 민가 조사 → 객사 보고. 신뢰 2·소개장·안쪽 방 |
| 소문 탐색 | 한복 → 소문 → 구매 → 소문 의뢰 확인·수락 → 성문 조사 → 창고 조사 → 객사 보고. 출처·신뢰도·기한과 지도 단서 확인 |
| 전위 호위 | 전위 부탁 수락 → 창고 조사 → 성문 대결 또는 유료 경비 계약 → 객사 보고. 패배해도 우회 가능 |
| 뒤뜰 시험 | 객사 전체 보기 → 뒤뜰 → 시험 시작. 시간 1·자금 1, 실제 대결, 캠페인당 한 번 |
| 숙박 | 한복 → 숙박과 식사 → 시간·비용 확인 후 선택. 피로 감소, 하루 한 번, 비용 환급 없음 |
| 관찰 | 한복과 인사 → 객당의 두 사람 대화 관찰 → 참여/몰래 듣기. 몰래 듣기는 신뢰 감소·노출 증가 |
| 거병 후 | 같은 객사의 한복 → 정보망(신뢰 2·도시 행정력 1·금고 1·턴당 한 번), 교역·휴전·종속의 실제 조건 확인 |

소개장·장부를 의뢰에 제출할 때는 첫 선택이 전달 확인이다. 같은 제출 버튼을 다시 눌러야 소비된다. 비용 할인용 소개장은 보유만 확인한다. 이 구분을 물품 수량과 기록에서 확인한다.

## 새로고침과 화면 점검

같은 접속 주소에서 **의뢰 수락 직후 / 문서고 조사 뒤 / 설전 중 / 결론 뒤 보고 전 / 보고 뒤 / 숙박 뒤 / 거병 후 객사** 각각 새로고침하고 **천하 캠페인 이어하기**를 누른다. 장소·시간·의뢰 단계·결론·손패·집중·물품·주인 신뢰가 이어져야 한다. 결과와 보상을 재굴리거나 중복 지급하면 오류다. 자동 저장 복원 통과와 사용자의 실제 새로고침 검증은 별도로 기록한다.

데스크톱에서는 두 인물과 대사가 겹치지 않는지, 작은 초상이 선택 가능한지, 목표·비용·결과가 읽히는지 확인한다. 모바일에서는 초상·구역·대화 버튼이 화면 밖으로 나가지 않는지, 의뢰 추적기와 제출 확인을 읽고 누를 수 있는지, 세로 스크롤과 지도 이동이 충돌하지 않는지 확인한다. 실제 모바일 터치는 미검증이다. 글자 확대 버튼과 모션 감소 설정도 함께 확인한다.
