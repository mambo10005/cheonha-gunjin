# 천하 캠페인 시작 화면 개선

> 이전 시작 방식의 기록입니다. 현재 새 캠페인은 [도시 탐색형 거병](PROLOGUE.md)과 [시드 131001 안내](PROLOGUE-PLAY-GUIDE.md)를 따릅니다. 이전 저장은 이 문서의 기존 규칙으로 계속합니다.


천하군진의 시작 화면을 풍경 지도와 인물 중심의 선택 장면으로 바꿨다. 현재 선택 가능한 진궁·장료·곽가의 전용 초상화 3장과 하남 풍경 1장을 새로 제작했다. 카드 거병과 도시·원정의 기존 규칙을 사용한다.

## 참고 게임과 적용 방향

| 비교 대상 | 참고한 구성 | 천하군진에 적용한 방향 |
|---|---|---|
| [삼국지 14 공식 화면 안내](https://www.koeitecmoamerica.com/manual/rtk14/en/3300.html) | 지도와 세력 정보, 선택 대상 정보가 구분되는 전략 화면 | 지도에서 도시 선택, 아래에 도시 기반 수치와 조건을 함께 표시 |
| [토탈 워 삼국 공식 상품 화면](https://store.steampowered.com/app/779340/Total_War_THREE_KINGDOMS/) | 역사 인물과 중국 풍경을 중심에 둔 시각적 분위기 | 큰 장수 초상화, 장수별 색과 성향, 풍경 위에 읽기 쉬운 선택 지점 |
| 개선 전 천하군진 | 굵은 단순 산·하천 도형, 동일한 도시 상자, 긴 설정 사이드바와 인물 드롭다운 | 창작 풍경과 얇은 도로, 선택 도시 강조, 인물 카드 3장, 출신·보좌·교리·특전의 별도 설정 구역 |

참고 게임과의 구성 비교에 따른 디자인 판단이다. 상용 게임과 같은 렌더링 기술·품질을 구현했다는 의미가 아니다. 기존 게임의 그림·인물 디자인·UI 파일을 가져오지 않았으며, 새 이미지와 HTML/CSS로 구성했다.

## 화면 구성

상단은 캠페인 제목·시나리오·시드다. 가운데는 하남 풍경 지도와 선택한 장수의 큰 초상화다. 지도에는 공현·성고·형양, 하천 회랑·관문 통로·산길 우회를 표시한다. 풍경과 핀 배치는 탐색을 위한 창작 지형도이며 측량 지도나 실제 축척이 아니다. 도시 운영 수치는 실제 CITY_DEFS에서 읽는다.

장수 선택 카드에는 이름·역할·선택 표시가 있고, 선택하면 큰 초상화·거병 성향·고유 카드 2장도 함께 바뀐다. 진궁은 명분과 조건, 장료는 군사와 결단, 곽가는 정보와 내응을 표현한다. 장수의 대사는 분위기를 위한 창작 문장이다. 능력 설명과 고유 카드 효과는 현재 거병 규칙을 기준으로 표시한다.

출신·보좌·교리·특전은 별도 설정 구역으로 옮겼다. 실제 거병 시작 처리기를 복제 상태에 실행해 시작 덱 10장, 남은 자금·군량·병력·지지를 미리 보여 준다. 도시나 장수를 다시 선택해도 시드·출신·보좌·교리·특전이 초기화되지 않는다. 선택 변경은 실제 게임 상태의 자원을 소비하지 않는다.

한글 본문과 카드 효과는 16~20px 이상으로 표시하며 제목·장수 이름은 더 크게 구분한다. 작은 화면에서는 설정을 세로로 쌓고 지도 안에서만 좌우 탐색한다. 키보드 초점과 선택 상태를 표시하고, 장수 버튼은 기본 버튼의 Enter·Space 조작과 `aria-pressed`를 지원한다. 단순 장식과 보조 캡션에는 작은 글자를 사용한다.

## 이미지 파일과 제작 기록

내장 **image_gen**으로 다음 원화를 만들고 웹용 WebP로 변환했다. 원본 그림의 내용과 구도는 변형하지 않았다.

| 파일 | 크기 | WebP 용량 | 인물 방향 |
|---|---|---|---|
| public/assets/campaign/chengong-v1.webp | 1024×1536 | 약 269KiB | 죽간·청록과 상아색 학자복·따뜻한 빛 |
| public/assets/campaign/zhangliao-v1.webp | 1024×1536 | 약 267KiB | 철제 갑옷·붉은 망토·군영의 불빛 |
| public/assets/campaign/guojia-v1.webp | 1024×1536 | 약 203KiB | 젊은 책사·밀서·남청색과 달빛 |
| public/assets/campaign/henan-v1.webp | 1672×941 | 약 426KiB | 황하·성곽·들판·안개 낀 산맥 |

전체 생성 프롬프트는 [campaign-art-prompts.json](verification/campaign-art-prompts.json)에 기록했다. 공통 지시에는 후한 말의 창작 역사 인물, 사실적인 회화 질감, 옥색·먹색·절제된 금색, 강한 얼굴과 실루엣, 게임용 초상화, 글자·로고·기존 게임 인물 디자인 제외를 명시했다. 각 인물과 지도에는 별도 프롬프트를 사용했다. 정밀 복식 고증과 역사적 실제 얼굴을 재현한 이미지는 아니다.

웹용 이미지는 저장소 `public/assets/campaign/`에 포함했고, 원본 PNG는 배포 폴더의 `campaign-art/originals/`에 보관했다. 기존 이미지 파일은 덮어쓰지 않았다.

## 구현과 확인

주요 파일은 `src/ui/campaign-setup.ts`, `campaign-setup.css`, `world-screen.ts`, `tests/campaign-setup.test.ts`다. 신규 이미지는 시작 화면에서만 사용하며 기존 전투·설전 그림은 유지한다. 기존 DOM 조작 경로는 새 화면에서도 이어진다.

공개 빌드를 JSDOM으로 실행하는 새 테스트는 초상화 선택과 표시 변경, 선택의 도시 변경 후 보존, 실제 이미지 파일 참조, 시작 덱 미리보기, 잘못된 시드 거부, 선택한 도시·장수·출신·보좌·교리·특전의 실제 시작 결과를 확인한다. 기존 거병 DOM 검증은 6거점·보상·설전·창설·내정·출진, 대결·재시작 복원, 이전 준비 저장의 변환을 확인한다.

검증 명령은 `npm test`와 `npm run build`다. 결과는 전체 자동 테스트 278개 통과, 타입 검사와 Vite 빌드 통과다. 이미지 생성 결과는 직접 확인했다. **실제 브라우저 레이아웃·모바일 기기·사용자 플레이는 미검증**이며, 브라우저 정책을 재시도·우회하거나 관리자 설정을 변경하지 않았다. JSDOM은 CSS 배치와 그림의 실제 화면 크기를 검증하지 않는다.

## 직접 실행과 점검

저장소에서 `npm ci` → `npm run dev`를 실행하고, Vite가 출력한 Local 주소를 사용자가 직접 연다. 기존 저장의 이어하기 화면 대신 **천하 캠페인 시작**을 누르면 새 화면을 볼 수 있다. 기본 시드는 121001이다. 장수 카드 3장을 번갈아 선택하고 도시·출신을 바꾼 뒤, 설정과 시작 덱·자원 표시가 유지·갱신되는지 비교한다. **이 도시에서 기반 마련**으로 기존 카드 거병 런에 진입한다.

화면 폭 1440·1024·390px, 확대율 125%·150%에서 얼굴 잘림, 도시 버튼 겹침, 설정 글자 잘림, 페이지 전체의 가로 넘침, 선택 표시와 키보드 초점을 확인한다. 모바일 지도는 안쪽 가로 스크롤로 도시 세 곳에 접근할 수 있어야 한다. 콘솔 오류와 선택 조합·화면 크기·스크린샷을 함께 기록한다. [거병 시드 121001 실행 안내](RAISING-PLAY-GUIDE.md)의 설전·대결·도시·출진 수동 검증도 이어서 사용할 수 있다.
