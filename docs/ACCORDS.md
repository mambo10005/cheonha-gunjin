# v0.4 설전·지속 협정 — 두 번째 완성 단위

기존 「천하군진」의 전열·후열 전투, 장수 능력, 덱, 8층 지도와 시드 저장을 유지하면서 설전과 외교를 원정 빌드에 연결했다. v0.3의 공통 성장·세 빌드·대결 전술에 이어, 요청의 두 번째 완성 단위를 구현했다. 세 번째·네 번째 단위는 아직 구현하지 않았다.

## 바뀐 플레이 판단

| 이전 문제 | 현재 판단과 구현 |
|---|---|
| 합의 점수만 올리는 설전 | 상대가 요구하는 이익·안전·명분·권한을 동시에 충족해야 한다. 신뢰 최소치와 부담 상한도 적용한다. |
| 같은 답을 반복하는 대응 | 정보 공개 후 바로 양보하면 신뢰가 추가 상승한다. 중간에 다른 논거를 쓰면 연결이 끊긴다. 연속 논거의 각 충족량은 1 감소한다(침착 예외). |
| 대표 적성만으로 선택 | 교리와 해당 장수의 성장에서 정보·집중을 얻는다. 기존 계책 전법·통찰은 정보를, 우호 관계·활성 협정은 신용을 제공한다. |
| 실패하면 보상을 못 얻는 협상 | 부분 영입은 군량 3과 다음 카드 보상 선택지 감소, 부분 보급은 군량 5와 병력 6이다. 부분 협정은 반환 가능한 예치금 2를 요구한다. 실패 후 기본 협정 재제안 또는 거절이 가능하다. |
| 외교가 즉시 구매에 그침 | 지정 보급·전투 경로 의무를 수락하고 실제 이행해야 관계와 후속 보상을 받는다. 활성 협정 2개 제한 때문에 기존 협정 포기와 새 제안 거절 사이에서 선택한다. |
| 활동의 성장이 이어지지 않음 | 공동 작전 승리는 지정 장수의 원정 성장으로 이어지고, 성장·교리는 일반 전투와 대결뿐 아니라 다음 설전의 준비에도 사용한다. |

## 설전 규칙

설전 도전 비용은 군량 1, 최대 네 선택이다. 무작위 성공·실패 판정은 없다. 시작에 두 번째 답변 뒤의 반론 축을 예고한다. 시드로 고른 반론은 해당 요구를 1 올리며 저장에 보존된다.

| 상대 | 처음 요구 | 신뢰 최소 | 부담 상한 | 반론 |
|---|---|---:|---:|---|
| 상단 | 이익 4·안전 3 | 2 | 3 | 이익 또는 안전 +1 |
| 향촌·의용군 | 안전 3 | 3 | 1 | 안전 +1 |
| 인재 | 명분 4·권한 1 | 2 | 3 | 명분 +1 |

성공은 모든 요구와 신뢰·부담을 함께 충족할 때다. 부분 합의는 상단의 이익 또는 안전 3, 향촌의 안전 3, 인재의 명분 3 이상이며 신뢰 1·부담 상한을 지켜야 한다. 나머지는 실패다. 화면은 현재 미충족 조건과 각 논거의 실제 처리 후 값을 보여 준다.

| 논거 | 비용·효과 |
|---|---|
| 근거 제시 | 집중 1 → 명분 2·이익 1·신뢰 1 |
| 반론 정리 | 집중 2 → 명분 3·신뢰 -1 |
| 부담 양보 | 집중 2 회복·안전 1·신뢰 1. 바로 직전 정보 공개면 신뢰 1 추가, 중재 특성도 신뢰 1 추가 |
| 작전 정보 공개 | 집중 1·정보 1 → 안전 2·신뢰 1, 바로 다음 양보 준비 |
| 운영 제안 | 집중 2 → 이익 3·안전 1·신뢰 1 |
| 실물 군량 제시 | 원정 군량 2 즉시 지불 → 이익 2·안전 2·신뢰 1·부담 1. 보급 운영 특성은 안전 1 추가 |
| 활동 권한 약속 | 집중 1 → 명분 2·권한 1·신뢰 1·부담 2. 설전당 한 번. 최종 성공/부분 제안을 수락하면 다음 카드 보상 1회 선택지 -1 |
| 협정 신용 활용 | 신용 1 → 이익 1·안전 1·신뢰 2 |

실물 군량은 실패·중단·거절해도 환급하지 않는다. 권한 약속은 실제 조건 수락 때만 대가가 생긴다. 정보·신용은 설전 시작에 최대 2로 준비하며, 전투 준비 토큰을 옮기는 방식이 아니다. 수비 반격·정보 계책 교리는 정보 1, 교대 돌파 교리는 집중 1을 제공한다. 호위·교란 성장은 단계당 정보 1, 책략 성장은 단계당 집중 1을 더한다. 대표의 성장만 적용하고 교리/성장 집중은 최대 2다.

성공 설전 뒤에는 개선 조건 또는 원정 성장을 선택한다. 성장을 받으면 거래는 부분 합의 조건으로 전환한다. 거래 수락은 별도 선택이며, 장수 성장 대신 회복 대안도 가능하다.

## 지속 협정

새 원정은 지속 조항 규칙을 사용한다. 관계는 서명만으로 오르지 않는다. 협정 의무를 끝내면 관계 +1, 최대 2. 경로 이탈·의무 미이행·포기·대상 장수 교체·목표 전투 패배는 관계 -1(최소 -1)과 군량 -2(최소 0), 예치금 몰수로 종료한다. 적대 세력과는 새 협정을 맺지 못한다.

| 조항 | 서명 비용 | 즉시/지속 지원 | 의무·후속 보상 |
|---|---:|---|---|
| 상단 후원 | 군량 1 | 군량 +5(성공 협상 +6). 이행 전 실제 군량 보급마다 +1 | 지정 일반/정예전 승리. 카드 보상 선택을 군량 +3으로 전환. 정예 보물은 유지 |
| 향촌 호송 | 군량 2 | 병력 +4. 지정 보급 완료 후 지정 전투 시작 전열 방비 8(성공 협상 12) | 지정 보급의 군량 획득 → 지정 전투 승리. 의약 선택은 의무를 충족하지 않음 |
| 의용군 공동 작전 | 군량 2 | 지정 정예전 시작 적 전원 피해 4(성공 협상 8) | 해당 정예전 승리 → 서명 때 지정한 군단 장수 성장. 교리 추가는 불가. 성장 한 분기·최대 2단계 및 회복 대안 유지 |

사절 특성은 기본 서명 비용을 1 줄이되 최소 1, 예치금은 할인하지 않는다. 부분 합의는 추가 예치금 2를 서명 시 지불하고 이행 때 반환한다. 권한 약속의 대가도 서명 시 적용한다. 실패 협상은 기본 조건 재제안 또는 거절로 진행할 수 있으나 같은 장소에서 재설전하지 못한다.

활성 슬롯은 2개, 같은 조항은 중첩 불가, 장소당 서명 1회다. 목표와 보급의 층·경로를 화면에 표시한다. 목표 노드를 떠나기 전 의무를 처리하며, 미보급 상태로 지정 보급 층을 지나면 만료한다. 지도/활동 사이에서 포기할 수 있고, 설전·성장 선택·전투 중에는 변경하지 않는다. 현재 지도에 실제 연결 경로가 없으면 제안을 비활성화한다. 기존 의무와 새 목표를 함께 이행할 연결 경로까지 검사한다.

## 구체적인 연결과 확인 방법

군주 선택 화면에서 **설전·협정 검증 원정 (시드 51001)**을 누른다. 일반 원정과 같은 규칙 입구를 사용하며, 협정·승리·성장 보상을 미리 주입하지 않는다.

1. 1층 상단 제안: 후원을 수락하면 즉시 군량을 얻지만 6층 카드 보상을 포기한다. 호송·작전을 함께 보려면 상단 제안을 거절한다.
2. 2층 보급을 선택하고 초기 성장/회복을 처리한다.
3. 3층 보급 협상에서 **보급 대신 향촌과 외교**를 고른다. 정보 공개 → 부담 양보 → 운영 제안 → 근거 제시로 부담 0의 안전 조건을 충족할 수 있다. 호송을 체결한다.
4. 4층 의용군에서 공동 작전을 체결하며 성장 대상 장수를 고른다.
5. 두 의무가 표시한 5층 경로의 **군량 수레**를 선택하면 호송 지원이 준비된다.
6. 지정 6층 정예전에서 호송 방비와 작전 피해가 함께 적용된다. 대결을 거절해도 협정 지원은 유지한다. 전투에 승리하면 두 관계가 오르고 지정 장수의 성장/회복 선택으로 이어진다.

정보 교리/장수 성장 → 설전 정보 논거 → 향촌 신뢰·안전 합의 → 보호 강화 → 정예전 승리 → 관계·장수 성장 → 다음 일반 전투·대결·설전이라는 원정 연결이다. 협정 후원이 같은 정예전과 겹치면 카드 보상 전환을 먼저 처리한 뒤 공동 작전 성장 화면으로 감싼다.

`npm run sim:accords`는 같은 시드에서 협정 없음 / 상단 후원 / 호송+공동 작전을 실제 봇 전투로 비교한다. 강제 승리는 없다. 이번 실행 결과:

| 선택 | 최종 결과 | 최종 군량 | 6층 시작 전열 방비 | 6층 적 합계 시작 피해 | 협정 이행 |
|---|---|---:|---:|---:|---|
| 없음 | 8층 패배 | 33 | 2 | 0 | 없음 |
| 상단 후원 | 8층 패배 | 47 | 2 | 0 | 후원 완료 |
| 호송+공동 작전 | 승리, 병력 35 | 25 | 14 | 8 | 호송·작전 완료 |

14 방비에는 성공 호송 12와 대결 후 2가 함께 포함된다. 이 비교는 특정 봇·선택·시드의 결과이며 사람의 재미나 일반 승률을 증명하지 않는다. 설전 봇은 남은 최대 네 선택을 실제 처리 복제 상태로 탐색하며, 지도 봇은 가능하면 기존 의무 경로와 지정 군량 보급을 따른다. 전체 원정·덱·장수 조합의 장기 최적화는 하지 않는다.

## 구현 위치와 처리 순서

- `core/accord-types.ts`, `data/arguments.ts`, `core/negotiation.ts`: 논거·요구·자원·반론·결과 조건. 기존 debate 미리보기는 복제 상태에 동일 처리기를 호출한다.
- `core/accords.ts`: 조항 정의, 실제 연결 경로 검증, 서명·포기, 이동/군량 보급/전투 시작/종료/장수 교체 훅. 조항 분기는 이 모듈에 둔다.
- `core/build.ts`, `social-run.ts`: 성장/교리 준비값, 원정 군량 지불, 설전 결과 선택과 수락. 활동 자원이 원정 군량을 변경하는 곳을 진입 함수로 한정한다.
- `core/run.ts`: 기존 이동·보급·전투 보상에 명시된 훅 호출. 시작 지원은 기존 대결/지원과 합산한다. 종료 시 카드 전환과 관계·예치금 처리 후 공동 성장 화면을 만든다.
- `ui/social-view.ts`, `ui/main.ts`: 요구·미리보기·지원 기간·의무·포기 비용·부분 조건 화면, 검증 원정 입구. 규칙은 DOM에 의존하지 않는다.
- `core/save-validation.ts`, `save.ts`: 버전 4 저장, 이전 규칙 보존 및 손상 검사.
- `sim/social-policy.ts`, `autoplay.ts`, `accord-scenarios.ts`: 신규 상태 입력과 의무 경로, 비교 시나리오.
- `tests/accords.test.ts`, `accord-ui.test.ts`: 새 규칙과 화면 입력·복원 검증. 기존 테스트는 이전 규칙 회귀를 계속 검사한다.

## 직접 실행한 검증

변경 전 현재 체크아웃의 테스트 **96개**, 타입 검사·Vite 빌드를 직접 실행해 통과를 확인했다. 변경 후 테스트 **118개**, 타입 검사·Vite 빌드가 모두 통과했다. 새 테스트는 요구별 성공, 반론, 정보 연쇄, 군량 지불, 미리보기 불변성, 성장 대가, 슬롯/소유 제한, 지도 연결, 이행/만료/포기/패배/교체, 동시 보상 순서, 저장 손상, 이전 저장 변환을 검증한다.

DOM 통합 테스트는 설전 중 저장·이어하기, 두 협정 체결, 보급 준비, 전투 시작 지원, 지정 장수 성장과 복원을 실제 화면 입력으로 확인한다. 전투 결과 화면 검사는 분리한 고정 승리 상태를 사용한다. 별도의 세 비교 시나리오는 실제 규칙으로 전투를 진행한다. 기존 자동 플레이 회귀의 두 군주 각 40개 시드도 종료했다.

**실제 브라우저·모바일 시각 확인과 사람 플레이는 미검증이다.** 브라우저 도구가 `file://` 접근을 차단했고, 관리 정책을 해제할 도구가 없다. 이를 우회하지 않았다. DOM 테스트를 브라우저 시각 검증으로 간주하지 않는다.

## 저장 호환성과 후속 작업

저장 버전은 4다. 버전 1/2/3 저장은 기존 카드·장수·지도·RNG를 유지하며, 기존 진행 중 설전/외교 조건을 바꾸지 않도록 원정 전체를 이전 활동 규칙으로 이어간다. 버전 1/2에는 이전에 정의한 기본 성장값을 채운다. 버전 3의 성장은 보존한다. 새 원정을 시작하면 새 조항 규칙을 사용한다. 협정 UID·조건·경로·예치금·활동 중 원정 군량 일치·완료 이력과 새 설전 상태를 검사하며 손상된 저장은 거부한다.

다음 구현은 요청의 **세 번째 단위**: 전법 개조와 기존 제거·복제의 통합, 유료 정찰과 실제 준비/위험 분기, 공개된 지역 위험 보상이다. 이후 네 번째 단위로 남은 층에 완료 가능한 연속 사건, 필요 시 준비 물품, 예고된 동탁 작전 변형을 구현한다. 이 기능들은 아직 화면에 노출하지 않는다. 신뢰 동맹·군량 운영의 독립 빌드는 후보이며, 이번 조항 연결을 독립 빌드 완성으로 보고하지 않는다.

변경은 로컬 산출물과 누적 패치에 담았다. GitHub에는 커밋·푸시하지 않았다.
