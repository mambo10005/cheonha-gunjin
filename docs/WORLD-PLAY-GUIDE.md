# 천하 캠페인 시드 111001 실행 안내

현재 통합 본편의 검증 시드는 **111001**이다. 이전 31001·61001·101001은 이전 체험/모드의 시드다. 이 안내는 규칙·DOM으로 확인한 경로를 사용하며 실제 브라우저 수동 실행은 **미검증**이다. 아래 예상값은 지정한 선택을 그대로 할 때의 규칙 기준이며 전투·교섭 이후는 플레이 선택에 따라 달라진다.

## 설치와 접속

소스 ZIP을 풀어 package.json이 있는 mambo1 폴더에서 터미널을 연다. Node 22.18 이상이 필요하다.

```powershell
npm ci
npm run dev
```

Vite가 출력하는 **Local:** 옆의 주소를 브라우저에 입력한다. 보통 localhost 주소지만 포트가 사용 중이면 달라질 수 있으므로 출력된 주소를 그대로 사용한다. 터미널은 게임 도중 켜 둔다. 파일의 file:// 주소 대신 개발 서버 주소를 사용한다. 보안 정책이나 관리자 설정은 변경하지 않는다.

타입·규칙·DOM 자동 검증과 배포 빌드는 별도로 실행한다.

```powershell
npm test
npm run build
npm run sim:world
```

249개 자동 테스트는 사용자 플레이를 대신하지 않는다. 배포 미리보기가 필요하면 빌드 후 `npm run preview`를 실행하고 새로 출력된 Local 주소를 사용한다. 개발 서버와 미리보기 주소는 저장을 공유하지 않을 수 있다.

## 시작과 거병

1. 제목의 **천하 캠페인 시작**을 누른다. 별도 도시 캠페인 버튼을 찾을 필요가 없다.
2. 190년 하남 지도에서 **형양**을 선택한다. 재야, 진궁, 민본, 군량 특전을 선택하고 시드 **111001**을 넣는다. 시작을 확정한다.
3. 준비 1단계: **인재 탐문** → **상단 자금 4** → **향촌 접촉**. **준비 단계 종료 · 새 행동 기회**를 누른다.
4. 준비 2단계: **인재 탐문** → **의용군 모집** → **창고 거점**. **준비 단계 종료 · 새 행동 기회**를 누른다.
5. 준비 3단계: **감시 회피** → **상단 자금 4** → **향촌 접촉**. 단계 종료를 더 누르지 말고 **의용군 결집** 항목의 **거병·세력 창설**을 누른다. 세력 이름·군기 색은 자유롭게 정할 수 있다.

화면의 행동 설명에 비용과 노출 변화가 있다. 두 번째 탐문에서 전위가 합류하는 것이 이 시드의 예상이다. 지정 경로로 창설하면 금고 6, 형양 식량 10, 예비병 20, 진궁·전위가 원정 후보에 남는다. 준비 장부의 자금·군량·병력은 0으로 이동 처리된다.

## 첫 도시와 출진

1. 지도 형양을 선택하고 **구역·내정 카드·임명·시설**로 들어간다. 식량·자재·인력·안정·치안·생산, 도시 덱과 담당을 확인한다.
2. 첫 짧은 정벌에서는 진궁·전위를 군단에 유지한다. 시설 청사진의 **둔전소**를 지을 수 있다. 시설 비용은 자재이며 정산 때 식량을 생산한다.
3. 세계 지도로 돌아와 **모병**을 한 번 실행한다. 금고 2·인력 2·식량 2가 소모되고 예비병 12가 늘어난다. 추가 소비가 없으면 금고 4·형양 식량 8·예비병 32다.
4. 성고를 선택한다. 출발 도시가 형양인지 확인한다. 정벌, 병력 **32**, 군량 **8**을 입력하고 출진을 확정한다. 금고 2와 전략 행동력 1도 소모된다. 형양 예비병·식량은 각각 입력량만큼 줄고, 군단은 그 자원으로 출진한다.

장수 임명을 체험하려면 진궁을 도시 문관으로 임명해 카드를 쓴 뒤 공통 턴을 종료하고 다음 턴에 담당을 공석으로 바꿔 군단에 복귀시킨다. 담당인 동안에는 군단에서 빠지는 것이 정상이다. 이 우회 체험은 식량·적 행동·손패가 달라져 위의 빠른 출진 수치와 같지 않다. 행정 카드의 예상 결과와 실제 결과를 비교하면 장수와 내정의 연결을 확인할 수 있다.

## 전투·설전·외교·점령

첫 정벌은 기존 8층 원정을 전부 재생하지 않고 세 행군 장면을 사용한다.

1. 원정 교리를 고른다. 첫 행군의 실제 도적 전투에서 전열·후열 공격 예고를 보고 방비·반격을 쓴다. 전위의 전열 효과와 진궁의 계책 효과를 확인한다. 카드 사용과 **전투 턴 종료**는 별도다.
2. 전투 보상을 처리한 후 다음 행군에서 사절 사건을 확인한다. 협정·설전·외교의 비용과 의무를 읽고 선택한다. 교섭 결과는 기존 관계·협정 기록에 남는다. 첫 시드에서 모든 무장 대결이 강제 발생하는 것은 아니다.
3. 성외에 도착하면 서로 다른 준비 두 가지를 선택한다. 군량이 충분하면 **정찰**과 **수비대 보급 차단**을 선택한다. 각각 군량 2가 필요하며, 정찰은 설득을 위한 정보 2, 차단은 적 방비·체력을 줄인다. 부족하면 화면에서 가능한 보급/징발 선택과 피해를 확인한다.
4. **수비대 설득**은 정보 2와 진궁 같은 책사가 필요하다. 카드의 논점·현재 요구·집중·신뢰·부담·예상 반론을 확인한다. 정보 카드는 자동으로 라운드를 끝내지 않는다. 실행 가능한 카드를 쓴 뒤 화면의 라운드 종료를 직접 선택한다. 성공 또는 부분 합의로 점령 단계에 갈 수 있다. 실패 시 열리는 선택을 확인하고 정벌을 계속한다.
5. **향촌 공동 운영**을 선택한다. 성고가 우리 소유로 바뀌고, 실제 도시 장부와 보급 연결이 생긴다. 생존 병력·잔여 군량은 점령 도시로 돌아가고 비출진 군단 병력·군량은 0이 된다.
6. 승리 정산 전 성고 내정을 확인하고 현안 우선 또는 민생 우선으로 위임할 수 있다. 두 소유 도시의 보급 발송은 실제 식량을 옮기며 손실·도시 행동력을 적용한다. 식량 총합이 무료로 증가하지 않아야 한다.
7. **캠페인 턴 종료**를 누른다. 각 도시가 한 번 정산되고 경쟁 세력이 행동한다. 도시 2개 이상, 각 안정 25 이상, 보급 연결, 성고의 경쟁 핵심 점령 조건을 충족하면 **하남 지역 패권 달성** 화면을 확인한다. 낮은 안정은 먼저 내정으로 회복한다.

무장 대결은 해당 사건이 제시될 때 능력·부상·비용·후속 결과를 확인한다. 강제 체험이 필요한 이전 전용 시드는 원정 도전/개발 체험의 별도 경로이며 본편의 필수 승리 조건이 아니다. 현재 본편 안내의 실제 브라우저 대결 진입은 미검증이다.

## 새로고침·복원 확인

같은 주소·같은 브라우저에서 아래 지점마다 수치와 화면을 기록하고 새로고침한 뒤 **천하 캠페인 계속**을 선택한다.

- 준비: 단계·행동력·노출·자금·단서가 같다. 새로고침으로 인재를 다시 뽑거나 준비 비용이 환불되지 않는다.
- 도시: 담당 장수·손패·사용 카드·자원·시행 정책이 같다. 담당 장수가 군단에도 생기지 않는다.
- 행군: 출발·목표·작전 ID·진행 장면·병력·군량이 같다. 출진 차감을 두 번 적용하지 않는다.
- 전투/설전: 현재 턴/라운드·손패·예고·논점·요구·효과가 같다. 연출 중 복원도 실제 수치를 보존하는지 확인한다.
- 점령 후: 소유 도시·귀환 병력·도시 식량·보급 연결이 같다. 귀환 자원이 다시 늘지 않는다.
- 턴 정산 후: 같은 턴에 같은 도시 생산이 다시 발생하지 않는다.

위 내용의 저장 형식은 자동 검증했지만 실제 브라우저 새로고침은 미검증이다. 저장 실패 경고가 있으면 새 게임으로 덮어쓰지 말고 기록한다. 기존 단일 원정/도시 저장을 가져올 때 원래 저장이 계속 남는지도 확인한다.

## 화면 수동 점검

데스크톱에서는 전체 지도·오른쪽 도시 패널·자원 숫자·선택 경로·전투 예고·카드 미리보기·툴팁이 읽히는지 확인한다. 확대 100%와 125%에서 버튼·모달이 잘리지 않아야 한다. 키보드로 주요 버튼과 종료 조작을 실행해 본다.

모바일 또는 좁은 화면에서는 지도 가로 스크롤, 페이지 세로 스크롤, 카드/모달 끝부분, 최소 버튼 터치 영역, 숫자 입력, 가상 키보드가 확정을 가리지 않는지 점검한다. 넓은 지도는 가로 이동이 가능한 것이 의도다. 콘솔 접근이 어려우면 화면 문제와 재현 순서를 먼저 기록한다. 실제 데스크톱·모바일 렌더링과 터치 품질은 미검증이다.
