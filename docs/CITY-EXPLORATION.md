# 천하군진 도시 탐색 구현과 검증

2026-10-10 작업본. 새 캠페인의 기본 시드는 **141001**이다. 실제 브라우저와 사용자 플레이는 미검증이다. 브라우저 정책 우회·재시도와 관리자 설정 변경은 하지 않았다.

## 무엇이 달라졌는가

새 캠페인의 거병 준비에서 6열·각 3후보의 선택표를 제거했다. 도시 지도에서 주인공의 위치를 확인하고, 도로로 연결된 장소를 선택해 이동한 뒤 그 장소에 진입한다. 지도 이동 중에는 손패가 접혀 있고, 장소 사건에서만 카드와 접근법이 펼쳐진다. 이동, 사건 접근, 인재의 부탁과 등용에 시간이 든다.

기존 6단계 데이터와 카드 엔진은 저장 호환과 카드 계산에 남겼다. 새 탐색의 사건 순서나 장소 이동은 그 열을 선택하지 않는다. 이미 진행 중인 구형 6단계 저장은 선택과 보상 기록을 훼손하지 않도록 이전 화면·규칙으로 계속한다. 새 도시 화면은 새 캠페인으로 시작한다.

## 도시와 공간

`CityDefinition.exploration`은 장소, 좌표, 연결 도로, 구역, 위험, 설명과 거병 후 역할을 갖는다. `CityState.exploration`에 실제 위치, 카메라, 시간, 장소 상태, 인물 위치, 사건과 처리 기록을 저장한다. 거병 전부터 `CampaignState.cities`에 실제 도시를 만들고, 거병 시 같은 객체의 소유권과 운영 기능을 바꾼다.

| 도시 | 구현 범위 |
| --- | --- |
| 형양 | 중심 수직 단면. 객사·시장·관청·문서고·병영·동문·민가·곡물 창고·향촌 사당·성외 폐장원, 10곳 |
| 성고 | 같은 엔진의 8곳 배치. 산문·성채 병영·산성 군량고·수비 기록소 중심 |
| 공현 | 같은 엔진의 8곳 배치. 강변 시장·나루 창고·수운 관청·호송 군영 중심 |

형양에는 객사–시장–창고–동문, 객사–민가–사당–문서고–관청, 관청–병영–동문 등의 연결이 있다. 연결되지 않은 곳은 바로 이동할 수 없다. 정보나 지도 물품으로 찾는 성외 장소도 있다. 성고·공현은 장소와 도로 배치가 다르며, 새로운 도시를 늘릴 때 공통 화면을 다시 작성할 필요가 없다. 역사 지명은 기존 자료를 사용하지만 도시 내부 배치와 사건은 게임용 창작이다.

성벽, 큰길, 골목, 건물 지붕, 수레·인물 실루엣을 코드로 그린 조감도다. 위치 표식과 선택 경로, 위험·협력 상태, 주야 조명이 연결된다. 드래그, 확대·축소, 방향키와 중앙 정렬은 카메라만 바꾸며 주인공을 이동시키거나 시간을 소비하지 않는다.

## 시간·사건·실패

준비 시간은 42칸, 하루는 6칸으로 아침·낮·밤을 표현한다. 도로 이동과 장소 진입, 사건 접근에 표시된 시간이 소비된다. 피로가 높으면 이동 시간이 늘고, 밤의 위험 구역은 노출을 더한다. 휴식은 시간 2를 쓰고 피로와 노출을 줄인다. 인물 위치는 시드로 시작 위치를 정하고 일정에 따라 바뀌지만, 진행 중인 만남은 중간에 끊지 않는다. 소문과 위치 단서를 통해 다음 장소를 확인한다.

10개 기본 장소 사건과 실패 후속 사건 2개를 데이터로 정의했다. 대화·조사·거래·카드 계열·물품·동행자 조건에 따라 서로 다른 접근법을 쓴다. 시장은 조사→거래 또는 설전→호위 문제로 이어지는 복합 사건이다. 관청·사당·시장에는 설전 접근이, 병영·시장·성외에는 대결 접근이 있다. 승리를 등용으로 바로 바꾸지 않는다.

실패 시 피로·노출·일시 폐쇄·구역 피해가 남고 중재나 경계 후속 사건이 열린다. 일부 위험한 강행은 실패가 명확한 선택이며 무료 보상으로 바뀌지 않는다. 남은 시간이 3 이하이고 발견한 계획이 없으면 채무 2·노출 2를 감수하는 긴급 민회 준비를 선택할 수 있다. 최종 관문 실패의 재기는 해결 사건과 보상을 초기화하지 않는다.

## 인재·성장·카드·물품

진궁·장료·곽가의 기존 주인공 구조와 원화를 사용한다. 전위·조인·정보·순욱·노숙 및 일반 인재 3명의 이동 경로가 도시 장소와 연결된다. 실제 장소에서 만난 뒤 부탁 수행, 임시 카드 또는 관계 협력, 실적·신뢰 조건, 등용을 거친다. 개인 카드는 보관함에 추가되며 별도로 덱에 편성한다.

탐색 동행은 처음 1명, 주인공 성장 후 2명이다. 동행하지 않는 등용 인재는 군량을 들여 장소 조사에 파견할 수 있다. 파견 완료는 실제 시간 진행 때 처리하며, 동행과 파견을 동시에 할 수 없다. 함께한 사건은 경험과 관계 기록을 남긴다. 합동 카드의 기존 두 인재·신뢰·실적·비용 조건을 유지한다.

주인공 성장은 사건 경험 후 한 번 선택한다. 통찰은 정보 카드를 강화하고 중요 물품 칸을 늘린다. 결단은 출신 부담 카드를 강화된 선언으로 교체한다. 두 분기 모두 동행 한도를 늘린다. 인재는 기존 경험 기반 숙련·권한 분기를 쓰며, 강화·교체와 권한 의무가 연결된다.

카드는 준비력과 소유자 조건을 사용한다. 정보 카드는 인물 위치·비밀 장소를 밝히고, 인맥 카드는 이동을 돕고, 사건이 요구하는 계열 카드를 내면 새로운 접근법이 열린다. 아이템은 소개장·장부·인장·군량 표·치료 물자·지도의 6종이다. 일반 물품 3칸과 중요 물품 2칸을 분리하고, 용량이 차면 정리 후 대기 물품을 받는다. 증거·권한은 관련 접근에 사용되고 소비되므로 카드와 역할이 다르다. 출처와 사용처를 화면에 표시한다.

각 인재에게 기존 고유 부탁을 첫 사건으로 연결하고, 두 선택지를 가진 후속 개인 사건을 추가했다. 순욱의 ‘추천서에 없는 이름’, 전위의 ‘두 갈래 호위’, 정보의 ‘밀린 품삯’, 하남 서리의 기록 판단, 향촌 훈련관의 귀향 문제 등 8명 모두에게 후속 사건이 있다. 실제 카드 사용 증거 또는 물자 희생으로 해결하며 신뢰·경험과 약속·부채·도시 집단 변화가 남는다. 인재별 후속 사건은 한 번만 처리한다. 이는 짧은 두 사건의 수직 단면이며 장편 개인 서사 전체를 뜻하지 않는다. 현재 동료 관계는 신뢰·경쟁 두 유형이며 더 복잡한 갈등 서사와 비용 보정은 확장 범위다.

## 설전·대결·거병과 내정

설전과 무장 대결은 기존 실제 규칙 엔진을 사용한다. 주인공, 준비 카드의 논거·전술, 동행 지원, 정보·물품과 자원을 반영한다. 카드 사용만으로 설전 라운드를 끝내지 않으며 별도 라운드 종료와 반론 표시가 있다. 결과는 사건 해결·관계·노출·후속 사건·도시 상태로 이어진다.

민회·군영·내응 계획은 관련 사건에서 발견한다. 준비 패널에는 잠긴 계획의 방향을 표시한다. 대표·보좌 선택과 정제 뒤 실제 설전, 대결 또는 두 관문을 실행한다. 성공 후 교리를 선택하면 같은 도시 지도가 운영 화면으로 바뀐다.

| 장소 | 거병 전 결과와 거병 후 연결 |
| --- | --- |
| 관청 | 문서·관리 협력 → 인사·정책·문서고 기능 |
| 시장 | 상단 협력·장부 분쟁 → 상단 관계·객사 시설·교역 |
| 병영 | 수비대 인정·지휘권 → 훈련 시설·모병·군단 편성 |
| 창고 | 비축 협력 → 공동 창고·군량·원정 보급 |
| 민가·사당 | 주민 보호와 약속 → 집단 관계·구휼·도시 의무 |
| 성문 | 통행·내응 → 치안·방어·전도와 출진 |

도시 시설 한도 3개, 담당·자원·행정력 조건은 기존 규칙을 사용한다. 손상 장소는 거병만으로 복구되지 않는다. 거병 전 도시의 구역·집단·약속을 유지하고, 시설 전환은 한 번만 처리한다. 지도에서 해당 장소의 행정 카드를 실행하고 장수를 도시에 임명하거나 군단으로 편입할 수 있다. 전도에서 실제 예비병·군량·금고를 소비해 첫 원정으로 이어진다.

## 저장·연출·악용 방지

캠페인 저장 외피 버전 7을 유지하고 선택적 탐색 상태 버전 1을 추가했다. 위치·카메라·인물 일정·시간·사건 단계·아이템·파견·성장·계획·RNG·의미 이벤트를 저장한다. 사건 객체의 현재 장면과 영구 처리 기록을 복원 후 다시 연결해 중복 보상을 막는다. 잘못된 저장은 기존 내용을 삭제하지 않고 거부한다.

규칙 엔진은 이동 비용 납부, 시간 경과, 발견, 카드·물품 사용, 관계 변화, 등용, 성장, 장소 확보 등의 의미 이벤트를 기록한다. UI는 그 기록을 표시하며, 연출 넘기기는 보상을 다시 계산하지 않는다. 사건 일회성 기록, 입력 리비전, 물품 UID, 파견 일회성 기록, 거병 전환 표식으로 반복 지급을 막는다. 미리보기는 복제 상태에서 수행한다.

## 에셋·화면 검증의 한계

기존 진궁·장료·곽가 초상과 배경 원화를 재사용했다. 도시 지도와 건물은 코드 기반 벡터이며, NPC는 일관된 실루엣·이름 인장을 사용한다. 새 NPC 최종 원화나 별도 포즈 원화를 제작한 것으로 보고하지 않는다. 상태별 조명·크기·등장 연출과 결과 기록이 연결돼 있지만 상용 게임 수준의 최종 미술·음향 검수는 남아 있다.

실제 브라우저, 모바일 터치, 폰트 실가독성, 화면 겹침, GPU 성능, 사용자 재미는 **미검증**이다. DOM은 버튼과 상태 연결만 검증한다. 자동 정책은 흐름과 저장 재현을 확인하고 선택 편향을 측정하며 재미·공정한 밸런스의 증거가 아니다.

## 객사 패널 표시 수정

인물·동행, 카드 보관함, 휴대품, 거병 준비, 소문·기록 버튼은 기존에도 패널 상태를 바꿨지만, 긴 장소 장면 아래에 패널을 배치하고 초점 이동 시 스크롤을 막아 클릭 결과가 현재 화면에 드러나지 않았다. 패널을 상단 버튼과 기록 알림 바로 아래, 장소 장면 위로 옮겼다. 현재 장소와 사건은 유지된다.

이번 수정의 공개 DOM 검증에서 객사 진입 후 다섯 버튼을 차례로 눌러 제목·펼침 상태·키보드 초점·장면보다 앞선 배치를 확인했다. 접기와 Escape 닫기, 시간·자원·저장 상태가 바뀌지 않는 것도 확인했다. 같은 테스트의 거병·내정·첫 원정·저장 복원까지 통과했고 타입 검사와 배포 빌드도 통과했다. 아래 전체 320개와 규칙 89개, 자동 정책 수치는 패널 수정 전 결과이며 이번 수정에서 다시 실행하지 않았다. 실제 브라우저 검증은 미검증이다.

| 자동 정책 | 24회 중 창설 24회 | 조건부·불완전 성공 5회 포함 |
| 저장·재현 | 2542회 복원, 오류 0 | 동일 시드의 저장 유무 재현 일치 |
| 실제 브라우저 | 미검증 | 정책 재시도·우회 없음 |
| 실제 모바일·사용자 재미 | 미검증 | 자동 결과로 대체하지 않음 |

자동 정책의 첫 원정 출발은 22회이며, 실제 행정 명령을 실행한 진행은 24회다. 출진하지 못한 진행을 출진 성공으로 세지 않았다. 평균 방문 장소는 6.08곳, 평균 노출은 2.92다. 이 표본에서 한 번도 방문하지 않은 장소 ID: outside. 따라서 모든 사건 경로를 자동 정책이 포괄한다고 주장하지 않는다.

Vite는 단일 스크립트 500 kB 초과 경고를 출력했다. 빌드는 성공했지만 실제 기기 로딩·프레임·코드 분할은 추가 확인 대상이다.

자세한 장소·인재·카드·아이템·성장·계획 선택률과 시드별 행동 기록은 [자동 진행 원본](verification/city-exploration.json)에 있다. 순욱은 첫 만남의 확정 단서이므로 선택률이 높다. 인재 고정 선택과 경로 우열은 더 다양한 정책·사람 플레이로 검토해야 한다.
