## 2. 세션 구성
### 세션 A: 첫 플레이
목표: 아무 정답 안내 없이 거병까지. 첫 협력 인재·거병 계획은 자유 선택.
관찰: 장소 이동과 진입을 이해하는가 / 의뢰 목표를 찾는가 / 카드 편성을 자발적으로 여는가 / 표식을 이해하는가 / 설전 논거를 보호하는가 / 대결에서 거리·자세·빈틈을 확인하는가 / 결과 등급을 납득하는가.

### 세션 B: 다른 빌드
첫 판과 다른 주요 인재 또는 관문. 관찰: 다른 카드를 선택하는가 / 같은 장소를 다른 방식으로 해결하는가 / 인재 차이가 덱 차이로 느껴지는가 / 다른 관문을 선택할 이유가 있는가.
(「새로 시작」으로 같은 프리셋을 다시 시작합니다. 이전 로그를 먼저 내보내 두세요 — 새로 시작하면 로그도 새로 만듭니다.)

### 세션 C: 전위 경로
뒤뜰 시험 → 호위 대표 → 군영 장악. 관찰: 승리와 기술 인정의 차이를 이해하는가 / 승부수 경고를 읽는가 / 빈틈을 만든 뒤 승부수를 쓰는가 / 준비 전술을 기억하고 쓰는가 / 준비력 고갈을 납득하는가.

## 3. 기록 항목 (로컬 로그, `docs/playtest/log-format.md`)
- 탐색: 방문 장소·이동 경로·현재 목표 확인(거병 준비 패널 열람)·추천 경로 열람·잘못된 장소 왕복(요약에서 감지)·준비력·시간 소비(원인 분류).
- 덱: 카드 획득·편성·제외·보관함 열람·사용 카드·손에 있었으나 미사용 카드·표식 생성·소비·책략 발동.
- 설전: 논거 선택·공격 대상·보호·숨은 논거 공개·세부 수치/조항/논박 기록 열람·예상 등급 변화·최종 제안·결과 등급·놓친 조건.
- 대결: 카드 순서(거리·자세·빈틈·기세 포함)·준비 전술 사용·상대 의도(합 기록에 남음, 간보기로 공개한 의도 포함)·승부수 경고 노출(카드 미리보기 열람 시)·빈틈 없는 승부수·과잉 무력·결과 등급·부상.
- 거병: 선택 계획·남은 시간·인재·최종 덱·정책·의무·현안·부담 결산.
- 화면 열람은 `kind: 화면`으로, 거부된 명령은 `kind: 거부`로 남습니다.

## 4. 설문 (핵심 8문항, 1~5 + 짧은 의견)
1. 다음에 무엇을 해야 하는지 알 수 있었는가?
2. 카드 조합을 스스로 발견했다고 느꼈는가?
3. 인재 선택이 덱과 해결 방식에 영향을 줬는가?
4. 설전에서 어떤 논거를 지켜야 하는지 이해했는가?
5. 대결에서 거리·자세·빈틈을 고려했는가?
6. 결과 등급이 나온 이유를 이해했는가?
7. 거병 준비 과정이 길거나 반복적으로 느껴졌는가?
8. 다른 인재와 거병 계획으로 다시 해 보고 싶은가?

추가 상세 문항 8개는 별도 펼침 영역(카드 선택 난도·표식·의뢰 목표·준비 전술·승부수 경고·관문·부담 결산·추천 경로 시점).

## 5. 관찰자 기록
게임 안 「설문·기록」 화면과 덱·책략 패널의 「관찰자 기록」에서 태그 버튼 + 메모. 종이 양식은 `observer-form.md`. 진행을 막지 않도록 한 번 누르면 행동 번호·캠페인 시간과 함께 저장됩니다.

## 6. 내보내기
「설문·기록」 → 로그 JSON / 읽을 수 있는 요약(.md) / 요약 복사. 모바일에서는 공유 창(지원 시) 또는 다운로드, 막히면 요약 미리보기에서 복사.

## 7. 결과 해석 기준
즉시 수치 조정 근거가 **아닌** 것: 한 번의 패배, 한 번의 낮은 등급, 자동 정책과 다른 행동, 추천 경로를 쓰지 않음, 강한 카드를 잘못 씀.
우선 수정 후보: 세 명 이상이 같은 규칙을 오해 / 결과 등급 이유를 대부분 이해 못 함 / 같은 카드가 반복적으로 미사용 / 준비 전술을 대부분 잊음 / 특정 관문만 압도적으로 선택 / 첫 판에 거병 계획을 못 찾음 / 같은 장소를 목표 없이 반복 왕복 / 두 번째 플레이 의사가 낮음.
