# 거병 카드 엔진 (표식·사건 퍼즐·빌드 연결)

새 게임(도시 탐색)에서만 작동합니다. 엔진 이전 저장(`raising.engine` 없음)은 기존 규칙을 그대로 씁니다.

## 2차 조정 (시작 덱·첫 협력·조기 책략·관문 전환·계측)
- **시작 덱 7장**: 공통 3장(수비 교대 조사·사재 출연·격문 배포 — 조사·거래·설득 튜토리얼 동사) + 주인공 고유 1장(진궁 「조건 장부」, 장료 「군영 명령」, 곽가 「서신망」) + 출신 1장 + 도시 1장 + 부담 1장. 「곡물 매입」은 시작 덱에서 뺐습니다(필수 접근법·의뢰가 이 카드에 의존하지 않음을 테스트로 확인).
- **첫 협력**: 순욱(추천서)·전위(수레 호위)·노숙(두 장부) 의뢰를 처음 수락하면 그 인재의 전용 카드 4장 중 최대 2장을 공통 카드와 **교체**합니다(덱 크기 유지, 빠진 카드는 보관함). 순욱: 문서 정리·정론 제기·논거 보호·부담 정제 / 전위: 방비 태세·기세 돋우기·반격·직접 해결 / 노숙: 거래 주선·장부 대조·비용 전환·중재. 교체 카드는 다음 장소 첫 손패에 들어옵니다. 아무것도 고르지 않고 닫으면 다음 인재 의뢰로 미뤄집니다.
- **조기 책략**: 첫 협력 때 책략 3개 중 1개(순욱: 공론의 조항·약속의 제도화·짐을 진 맹세 / 전위: 반격의 진형·민심의 진군·짐을 진 맹세 / 노숙: 장부의 그물·밀서와 인맥·짐을 진 맹세).
- **재설계 책략**: 여러 손의 일 → 「공론의 조항」(설득 카드의 소비·후속 → 장애 +1·조항 초안, 설전 덱에 「조항 정리」), 공개 기치 → 「반격의 진형」(방비 소비 → 장애 +1·기세 +1), 약속의 제도화(약속 소비마다), 소진의 결단(부담 카드 포함), 장부의 그물(카드 자체 장부 소비 포함), 짐을 진 맹세(부담 생산을 보급·약속으로 바꾸고 부담 카드를 소멸).
- **새 표식 방비**: 전위 계열이 만들고 반격 카드·호위 공백 장애가 소비합니다.
- **관문 전환**: 민회 = 서로 다른 인재·명분→지지 연쇄·공론(시작 집중)·조항 초안 → 최종 조항(정책/의무). 군영 = 방비 생산(시작 방비)·기세·반격 횟수(반격 태세 추가 피해)·전술 → 압승/신승. 성문 내응 = 설전 등급 × 내부 협력(지원 제거)·단서(첫 합 기습)·내부 협력/정보 연쇄(시작 기세)·우회로 단계 전환. 대결 생략은 설전 성공 + 우회로/포섭 + 내부 협력 4 이상일 때만.
- **부담 생성**: 책임 분담 계약은 「후원 청구서」 부담 카드를 보관함에 남깁니다. 부담·약속 칸은 2장.
- **계측**: 카드별 사용·미사용, 표식, 책략 발동, 보상 선택·거절, 덱 교체, 사건별 카드 수, 설전·대결·전투 순서, 철회·취소, 결과 등급, 실패 후 선택을 저장 기록에 남기고 「덱·책략」 서랍의 「디버그 리포트 저장(로컬)」으로 이 브라우저(localStorage)와 JSON 파일로만 저장합니다. 외부 전송 없음.

## 카드 공통 문법 — `src/data/card-grammar.ts`
모든 거병 카드: 계열(명분·정보·인맥·군사·물자·계책), 행동(조사·설득·준비·동원·거래·결단), 장애 힘, 생산 표식, 소비(표식 → 효과), 후속 조건(직전 카드의 행동·계열), 활동별 변형(탐색·설전·대결·전투·내정), 소유자, 강화 분기(강행·정밀), 변환 규칙.
표식 10종: 단서·장부·지지·내부 협력·경계·보급·기세·약속·부담·공론(각 최대 6, 경계 최대 8).

카드 사용 순서(`engineAfterPlay`, `playRaisingCard` 안): 강화 → 카드 소비 → 후속 → 인재 원칙 → 책략 → 장애 타격(열쇠 표식은 **이전에 쌓인 것만** 소비, +1) → 생산 → 드로우(방문당 3)·준비력(방문당 2) 상한.
미리보기는 같은 함수를 복제 상태에서 실행합니다.

## 장소 사건 퍼즐 — `src/data/card-puzzles.ts`
| 사건 | 장애 | 해결 방식 |
|---|---|---|
| 곡물 창고 수레 통행 | 장부 불일치·호위 공백·막힌 통로·책임자 경계 (경계 한도 5) | 장부 설전 / 통행권 대결 / 우회로 / 보증 계약 / 책임 분담 계약 / 단기 계약(부분 성공) |
| 순욱 추천서 의뢰 | 기록 공백·서리의 경계·피난민 불신 | 문서 대조 완전 검증 / 서리 설전 / 조건부 보증 / 공개 고발 |
| 병영 장악 준비 | 지휘권 불신(3)·군기 해이·수비대 경계 (한도 6) | 훈련 대표 대결 / 진형 증명 / 수비대 포섭 / 보급 약속 |

장애는 맞는 행동의 카드로만 줄고, 조사 대상·증거 아이템·노숙 공동 대조는 표식을 남깁니다. 경계가 한도에 닿으면 실패(출입 3시간 봉쇄·노출·의뢰 `blocked`), 봉쇄가 풀리면 경계가 낮아진 채 다시 시도(실패 후속). 손패 정리는 시간 1(방문당 1회).
해결 결과는 설전 논거·전투 임시 카드·관문 규칙·거병 후 정책/의무(`legacy`)로 남습니다.

## 인재 4명 — `src/data/talents.ts`
순욱(공론의 인선 ↔ 인선의 저울), 전위(선봉 호위 ↔ 호위의 철칙), 노숙(양측의 계산 ↔ 중재의 장부), 정보(분산 보급 ↔ 노장의 셈). 원칙은 **정식 등용 + 동행** 중에만 작동. 각자 역할 1·고유 2·보좌 1·합동 연결. 성장은 추가·강화·교체·원칙 변화 중 하나(`engine:growth:<id>:<mode>`).

## 활동 덱 12장
주인공 4 · 출신·도시 2 · 인재 4(인재당 2) · 지역·물품 1 · 부담·약속 1. 등용·보상 카드는 보관함으로 가며 편성은 지도에서 직접 합니다. 동행하지 않는 인재 카드는 편성·사용 불가.

## 책략 8종(2칸, 교체 자금 1·시간 1) — `src/data/stratagems.ts`
밀서와 인맥(정보→인맥), 민심의 진군(지지→군사), 짐을 진 맹세(부담 사용), 여러 손의 일(다른 인재 연속), 약속의 제도화(약속→정책), 소진의 결단(소멸→드로우), 공개 기치(경계 비용), 장부의 그물(장부→단서). 주요 사건 보상에서 2개 중 고릅니다.

## 연결
- 설전: 해소한 장애·책임자 관계·증거 아이템·동행 인재 → 지속 논거(요구 −1·신뢰 +1·부담 한도 +1). 퍼즐·계획 화면에 미리 표시.
- 대결: 선제(수읽기·선제 돌격·방비 진형)·대응(보좌 개입·반격 태세·보급 회복)·승부수(결사 일격·허점 폭로·맹약의 증언). 덱 계열이나 동행 인재가 있어야 고를 수 있음.
- 군진 전투: 호위 계약→방진, 짐꾼 증언→양동, 비축 군량→징발, 우회로→매복, 장수 신뢰→반격 태세, 책임 분담→부담, 남은 장애→동요. 전투 전 변환 목록 표시, 전투 후 사라짐.
- 관문: 민회(명예 요구 +2, 참여 인재·명분→지지 연쇄로 감소), 군영(병영 퍼즐 미해결 장애가 상대 체력을 올림, 기세·보급 생산이 시작 조건), 성문 내응(설전 결과가 후속 대결 조건으로 전환, 우회로·포섭·내부 협력 4 이상이면 성공 시 대결 생략). 군영·내응은 전술 3장 편성 필수.
- 보상: 카드 3장 중 1(보관함) / 받지 않기 / 강화 / 제거 / 인재 관계 / 책략 / 아이템 / 자원. 휴식(`rest:<mode>`): 피로 회복·제거·강화·인재 대화, 하루 1회.
- 부담: 부담 카드는 장애를 줄이지 못하지만 부담 표식을 남기고, 정보 원칙·짐을 진 맹세·진궁의 불리함 전환·분산 군량망이 이를 보급·약속·단서·준비력으로 바꿉니다.
