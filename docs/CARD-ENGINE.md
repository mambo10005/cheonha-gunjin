# 거병 카드 엔진 (표식·사건 퍼즐·빌드 연결)

새 게임(도시 탐색)에서만 작동합니다. 엔진 이전 저장(`raising.engine` 없음)은 기존 규칙을 그대로 씁니다.

## 4차: 논박진(설전)과 대결 덱 — 카드·인재 추가 없이 기존 사건에 적용
3차의 결과 등급·조항·대결 목표·부상·난도·성문 장애·거병 후 현안은 그대로 두고, 설전과 무장 대결의 실제 플레이를 덱 전투로 바꿨습니다. 진행 중이던 구버전 설전·대결 저장은 기존 규칙으로 끝까지 진행되고, 새로 시작하는 카드 엔진 설전·대결부터 새 규칙을 씁니다(엔진 이전 저장·원정 설전은 기존 반론 규칙).

### 논박진 (`src/core/debate-field.ts`, `src/data/debate-field.ts`)
- **전장**: 내 핵심 입장 1 + 보조 논거 최대 3, 상대 핵심 주장 1 + 보조 논거 최대 3, 청중 논거 최대 2, 숨은 논거 최대 2. 논거는 내구·보호·숨김/공개 상태를 갖는 대상이며, 정의(태그·지속 효과·반응·대상 규칙·연결 요구·연결 조항)는 데이터에 둡니다. 자리가 차면 교체·즉시 효과·취소 중 하나를 골라야 하고, 가장 오래된 논거를 자동으로 버리지 않습니다.
- **기존 수치와 연결**: 요구의 일부(기본 −1)를 상대 논거로 옮겨, 상대 보조 논거가 살아 있는 동안 연결된 요구가 오릅니다(무너뜨리면 정확히 되돌림). 신뢰·부담·집중·라운드·등급·조항은 그대로 쓰고, 청중의 의심은 신뢰 증가를 깎습니다.
- **네 논법**(기존 카드의 계열별 전환): 정론(증거 논거 배치·보호·잠금 해제), 압박(겨눈 논거 논박 3·무너뜨리면 의도 지연·압박 증가·부담/청중 반응), 계책(숨은 논거 공개·공격 대상 돌리기·의도 순서 조작·약한 상대 논거를 「돌려쓴 조건」으로 전환), 중재(양측 보호·조급함/청중의 의심 감소·부담 감소). 인재 개인 카드는 설전에서 문서 정리·정론 제기·논거 보호·장부 대조·중재·전위의 보증으로 바뀝니다.
- **상대 의도**: 원형별 의도 덱을 시드로 섞어(첫 의도 고정) 라운드마다 하나를 실행합니다. 대상과 수치를 보여 주고, 일부(숨은 주장·계약 비용)는 정보 카드로 확인합니다. 「예고에 답하다」 등의 방어는 의도 수치를 깎습니다.
- **원형**: 관리형(공식 권한·문서 절차, 문서 없으면 조항 잠금, 서리의 모순 공개 시 핵심 −3) / 상단형(기존 계약이 라운드마다 비용 상승, 증인 우선 공격, 압박에 부담, 숨은 창고 외상) / 향촌형(주민 안전·부역 우려, 압박하면 청중의 의심) / 군사형(지휘권·병사 안전, 4라운드, 준비한 논거 공격, 결과가 후속 대결로 직접 전환) / 민회(향촌·관리, 창고 사건이 남으면 상단까지 함께). 원형마다 부분 성공 조건이 다릅니다.
- **덱 순환**: 10~12장(증거·인재 지원 카드 우선, 요구 축마다 점수 카드 보장), 시작 손패 5(준비한 증거 2장 포함), 집중 3, 라운드 끝에 남은 카드 버림, 증거·지원 카드는 소멸.
- **탐색 성과 → 증거 카드**: 퍼즐 장애 해소·아이템·조항 초안·대결 결과가 「출입 장부」「짐꾼의 증언」「책임자의 증언」「구휼 장부 대조」「피난민 명부 동의」「추천 서신」「관인」「조항 초안」「전위의 보증」「위신」 등 증거 제시 카드가 됩니다.
- **인재 참여**: 실제로 동행·관문에 참여한 인재만 원칙 1개와 설전당 1회 지원 카드(순욱 「추천의 보증」, 노숙 「양측의 계산」, 전위 「전위의 보증」)를 줍니다.
- **등급·조항 연결**: 문서 보존 = 문서 논거 생존, 상단 신용 = 숨은 외상 공개, 주민 부담 제한 = 약속 또는 짐꾼의 증언·조항 초안·드러난 징발의 기억, 창고 공개 = 대책 문서나 장부 논거, 출입권(새 조항) = 출입 장부 생존 → 성문 감시 해결. 유리한 합의에 「핵심 입장 유지·위험 상대 논거 1개 이하」, 탁월한 합의에 「핵심 증거 논거 생존·위험 상대 논거 제거·청중의 의심 없음」이 더해지고, 결과 화면에 어떤 논거가 어떤 조항·결과를 만들었는지 표시합니다.

### 대결 덱 (`src/core/duel-deck.ts`, `src/data/duel-cards.ts`)
- 대결 2판의 거리·자세·빈틈·기세·상대 지원·과잉 무력·목표 등급을 그대로 쓰고, 행동 버튼을 카드로 바꿨습니다. 덱 9~12장(기본 8 + 활동 덱 계열 변형 1 + 대결 전술 3 + 인재 지원 1), 합마다 손패 4·전술력 3, 남은 카드 버림, 덱이 비면 재섞기, 승부수 전술은 소멸, 부상은 「욱신거리는 상처」 부담 카드를 넣습니다.
- 카드마다 produces/consumes/followup/거리·자세 요구/반응을 데이터로 둡니다. 연쇄 예: 간을 보다 → 한 걸음 내주기 → 수세 전환 → 받아 흘리기(상대 공격을 모두 막으면 빈틈·반격) → 다음 합 파고들기(빈틈이면 12 깔끔한 제압) / 거리 좁히기 → 공세 전환 → 방비 깨기(상대 자세 무너짐) → 파고들기.
- **상대 원형 덱**: 맹공형(호위 대표), 반격형(뒤뜰의 전위: 연속 공격하면 반격 태세), 기교형(성문 감시가 남으면: 속임수로 수세 봉쇄, 간보기로 무력화), 지구형(성문 수비: 합마다 방비 +1), 지휘형(군영: 병사 지원 카드·지휘로 지원을 다시 부름). 상대 의도는 원형 덱에서 시드로 뽑고 원형 규칙이 덮어씁니다.
- **인재 지원**(참여할 때만): 전위(첫 방비 파괴·받아 흘리기 성공 시 「맞받아치기」 생성 / 「철위의 결집」), 곽가(숨긴 의도 무효 / 「기미」), 순욱(합 제한 +1 / 「정식 조건」: 무승부를 한 등급 높게, 공격 보너스 없음), 노숙(계약 대결 패배를 조건부 인정 / 「계산된 양보」).
- **탐색 → 대결 전환**: 수비 교대 조사 → 상대 첫 의도 공개, 짐꾼의 증언 → 첫 피해 −3, 치료 물자 → 최초 부상 제거, 전위의 보증 → 시작 방비 +3, 비밀 통로 → 시작 거리 선택, 병사 지지 → 상대 지원 약화. 시작 전 「준비 전술·인재 지원」에 덱에 들어간 방식이 표시됩니다.
- 대결 전술 3장은 덱에 더해지는 카드라 고르지 않아도 기본 덱으로 싸울 수 있습니다(전에는 필수).

### 설전 ↔ 대결
- 군사형 설전 → 성문 후속 대결: 「성문의 지휘권」 논파 → 지휘 카드 제거, 「병사 안전」 제거 → 병사 지원 카드 −1, 「숨은 지시」 공개 → 첫 의도 공개, 핵심 입장 유지 → 시작 기세 +1, 강한 압박 → 상대 기세 +1.
- 대결 → 이후 설전: 뒤뜰 기술 인정 → 「전위의 보증」 증거, 호위 대표 인정 이상 → 「위신」 증거, 과잉 무력 → 다음 설전 청중 「청중의 경계」, 중상 → 「부상 책임」. 보상이 아니라 다음 시스템의 조건으로만 남습니다(청중 논거는 한 번 쓰면 사라짐).
- 성문 장애: 감시 미해결 → 첫 의도 숨김·감시 카드(기교형), 단서 → 첫 감시 카드 무효, 지휘관 미해결 → 지휘 카드·상대 시작 방비 4(약화 2, 무력화 시 필살 카드 제거), 병사 지지 미해결/일부 → 병사 지원 카드 2/1장, 명분·신뢰 → 무승부도 조용한 개방, 비밀 통로 → 시작 거리. 체력을 올리는 보정은 쓰지 않습니다.
- 성문 내응 설전 상대는 카드 엔진에서 「이익·안전」을 따지는 내부 협력자로 바꿨습니다(노숙 빌드의 실리 카드가 쓰이도록).

## 3차 조정 (결과 등급·조항·부상·의무·후속 상태) — 카드·인재 추가 없음
- **설전 결과 등급** (`src/core/debate-grade.ts`, `src/data/clauses.ts`): 숨은 점수 대신 등급별 필수 조건을 명시합니다. 결렬 < 조건부 합의(부분 합의) < 일반 합의(완전 합의) < 유리한 합의(+ 비용 아닌 조항 1개·최종 신뢰 요구+1·최종 부담 1 이하) < 탁월한 합의(+ 고급 조항·논거 2개 보존·비용 조항 없음·라운드 여유 1·맥락별 특별 목표). 설전 화면에 "지금 최종 제안하면" 받을 등급과 조건별 충족/미충족, 얻지 못한 조항의 이유가 보이고, 관문 결과에는 탁월한 합의 미충족 조건이 남습니다.
- **조항 7개**: 공동 통치(고급: 명예 요구+1·공론 4·사적 이해 1 이하), 문서 보존(고급: 문서 계열 논거 2회·장부 논거 보존), 주민 부담 제한(부담 1 이하·안전·지킬 약속 1), 상단 신용, 창고 공개, 비용 조항 군량 징발(군량 담보 약속 또는 부담 한도)·권한 위임(위임 약정). 조항마다 즉시 효과·거병 후 정책·의무·집단 관계·시설 보존·인재 합류·후속 사건·충돌을 가지며, 같은 성공이라도 조항에 따라 세운 도시의 정책·의무·주민 관계·관청 손상이 달라집니다. 단호한 질문 2회 이상의 강한 압박은 거병 후 불신 현안(질서 −5·주민 −1)을 남깁니다.
- **민회 공론/사적 이해**: 같은 인재 카드를 연달아 쓰면 사적 이해 +1(민회 명예 요구 2마다 +1, 공동 통치 차단), 서로 다른 인재를 이으면 공론이 쌓여 고급 조항을 엽니다.
- **대결 2판** (`src/core/duel.ts` `enableDuelV2`, `src/data/duel-objectives.ts`): 우선 전위 뒤뜰 시험(연습)·창고 호위 대표·군영 관문·성문 내응 후속 대결에만 적용. 거리(근·중·원), 자세(공세·수세·유인), 빈틈, 상대 지원, 기세. 행동 계열은 간보기(지원 1 제거·다음 행동 공개)·보법(들어가기/물러서기)·공세·수세(완전 방비 → 반격·빈틈)·유인(공격을 근거리 빈틈으로)·승부수(근거리·기세 2, 빈틈 없이 쓰면 공격을 맞받아 반격 4). 반격 추가 피해가 준비된 방비는 지켜보던 병사 지원도 하나 흩어지게 합니다. 빈틈 없이 한 번에 18 이상 또는 마무리 초과 8 이상은 과잉 무력.
- **대결 목표(DuelObjectiveDefinition)**: 목표 종류·최소 결과·안전 제압 조건·과잉 무력 조건·합 제한·부상 허용·관계 효과·부분 성공·후속 규칙·등급. 호위 대표(완벽한 인정/인정/조건부 인정 — 조건부면 계약 인원이 줄고 책임이 남음, 인정 이상이면 공동 호위 전투에 「호위 편성」), 연습(기술 인정/성실/미숙, 반복 보상 없음), 군영(완전 장악/장악/명목상 장악 — 정책·병사 불만으로 이어짐), 성문(조용한 개방/개방/강제 개방).
- **관문 난도 프로필** (`src/data/gate-profiles.ts`): 관대·표준(검토 중)·가혹. 체력 배율 대신 설전 라운드·정예 반론, 대결 상대 순서·지원·시작 거리·합 제한, 조항 요구(공론·문서 횟수)를 바꿉니다. 기본은 표준이며 사람 플레이 전 확정하지 않았습니다. 계획 화면에서 바꿀 수 있습니다.
- **성문 내응 세 장애**: 감시(단서 4 또는 비밀 우회로 → 첫 합 기습), 지휘관(장부 3 + 설전 완전 합의 → 무력화, 둘 중 하나 → 약화·상대 승부수 제거), 병사 지지(내부 협력 2 → 지원 제거, 설전 완전 합의 또는 지지·공론 3 → 지지). 셋 모두 해결하면 대결 생략, 일부면 지원·의도·거리·체력이 다른 대결, 남은 장애는 거병 후 치안·충성·지휘관 현안. 비밀 우회로가 있으면 시작 거리를 고릅니다.
- **공동 호위 전투 편성**: 호위 대표의 인정(대결 등급 인정 이상)이면 시작 전열 방비 3 + 첫 방비 카드 때 「반격」 카드 1장 생성(한 번). 계약은 기존처럼 방진 카드. 적 수는 줄이지 않았습니다.
- **부담 빌드 안정성**: 첫 손에 부담 카드가 2장 이상이면 1장만 남기고 덱 아래로 돌립니다.
- **사람 플레이 시험 묶음**: `docs/PLAYTEST.md` 참고.

## 2차 조정 (시작 덱·첫 협력·조기 책략·관문 전환·계측)
- **시작 덱 7장**: 공통 3장(수비 교대 조사·사재 출연·격문 배포 — 조사·거래·설득 튜토리얼 동사) + 주인공 고유 1장(진궁 「조건 장부」, 장료 「군영 명령」, 곽가 「서신망」) + 출신 1장 + 도시 1장 + 부담 1장. 「곡물 매입」은 시작 덱에서 뺐습니다(필수 접근법·의뢰가 이 카드에 의존하지 않음을 테스트로 확인).
- **첫 협력**: 순욱(추천서)·전위(수레 호위)·노숙(두 장부) 의뢰를 처음 수락하면 그 인재의 전용 카드 4장 중 최대 2장을 공통 카드와 **교체**합니다(덱 크기 유지, 빠진 카드는 보관함). 순욱: 문서 정리·정론 제기·논거 보호·부담 정제 / 전위: 방비 태세·기세 돋우기·반격·직접 해결 / 노숙: 거래 주선·장부 대조·비용 전환·중재. 교체 카드는 다음 장소 첫 손패에 들어옵니다. 아무것도 고르지 않고 닫으면 다음 인재 의뢰로 미뤄집니다.
- **조기 책략**: 첫 협력 때 책략 3개 중 1개(순욱: 공론의 조항·약속의 제도화·짐을 진 맹세 / 전위: 반격의 진형·민심의 진군·짐을 진 맹세 / 노숙: 장부의 그물·밀서와 인맥·짐을 진 맹세).
- **재설계 책략**: 여러 손의 일 → 「공론의 조항」(설득 카드의 소비·후속 → 장애 +1·조항 초안, 설전 덱에 「조항 정리」), 공개 기치 → 「반격의 진형」(방비 소비 → 장애 +1·기세 +1), 약속의 제도화(약속 소비마다), 소진의 결단(부담 카드 포함), 장부의 그물(카드 자체 장부 소비 포함), 짐을 진 맹세(부담 생산을 보급·약속으로 바꾸고 부담 카드를 소멸).
- **새 표식 방비**: 전위 계열이 만들고 반격 카드·호위 공백 장애가 소비합니다.
- **관문 전환**: 민회 = 서로 다른 인재·명분→지지 연쇄·공론(시작 집중)·조항 초안 → 최종 조항(정책/의무). 군영 = 방비 생산(시작 방비)·기세·반격 횟수(반격 태세 추가 피해)·전술 → 압승/신승. 성문 내응 = 설전 등급 × 내부 협력(지원 제거)·단서(첫 합 기습)·내부 협력/정보 연쇄(시작 기세)·우회로 단계 전환. 대결 생략은 설전 성공 + 우회로/포섭 + 내부 협력 4 이상일 때만.
- **부담 생성**: 책임 분담 계약은 「후원 청구서」 부담 카드를 보관함에 남깁니다. 부담·약속 칸은 2장.
- **계측**: 카드별 사용·미사용, 표식, 책략 발동, 보상 선택·거절, 덱 교체, 사건별 카드 수, 설전·대결·전투 순서, 철회·취소, 결과 등급, 실패 후 선택을 저장 기록에 남기고 「덱·책략」 서랍의 「디버그 리포트 저장(로컬)」으로 이 브라우저(localStorage)와 JSON 파일로만 저장합니다. 외부 전송 없음.

## 카드 공통 문법 — `src/data/card-grammar.ts`
모든 거병 카드: 계열(명분·정보·인맥·군사·물자·계책), 행동(조사·설득·준비·동원·거래·결단), 장애 힘, 생산 표식, 소비(표식 → 효과), 후속 조건(직전 카드의 행동·계열), 활동별 변형(탐색·설전·대결·전투·내정), 소유자, 강화 분기(강행·정밀), 변환 규칙.
표식 10종: 단서·장부·지지·내부 협력·경계·보급·기세·약속·부담·공론(각 최대 6, 경계 최대 8).

카드 사용 순서(`engineAfterPlay`, `playRaisingCard` 안): 강화 → 카드 소비 → 후속 → 인재 원칙 → 책략 → 장애 타격(열쇠 표식은 **이전에 쌓인 것만** 소비, +1) → 생산 → 드로우(방문당 3)·준비력(방문당 2) 상한.
미리보기는 같은 함수를 복제 상태에서 실행합니다.

## 장소 사건 퍼즐 — `src/data/card-puzzles.ts`
| 사건 | 장애 | 해결 방식 |
|---|---|---|
| 곡물 창고 수레 통행 | 장부 불일치·호위 공백·막힌 통로·책임자 경계 (경계 한도 5) | 장부 설전 / 통행권 대결 / 우회로 / 보증 계약 / 책임 분담 계약 / 단기 계약(부분 성공) |
| 순욱 추천서 의뢰 | 기록 공백·서리의 경계·피난민 불신 | 문서 대조 완전 검증 / 서리 설전 / 조건부 보증 / 공개 고발 |

장애는 맞는 행동의 카드로만 줄고, 조사 대상·증거 아이템·노숙 공동 대조는 표식을 남깁니다. 경계가 한도에 닿으면 실패(출입 3시간 봉쇄·노출·의뢰 `blocked`), 봉쇄가 풀리면 경계가 낮아진 채 다시 시도(실패 후속). 손패 정리는 시간 1(방문당 1회).
해결 결과는 설전 논거·전투 임시 카드·관문 규칙·거병 후 정책/의무(`legacy`)로 남습니다.

## 연결
- 설전: 해소한 장애·책임자 관계·증거 아이템·동행 인재 → 지속 논거(요구 −1·신뢰 +1·부담 한도 +1). 퍼즐·계획 화면에 미리 표시.
- 대결: 선제(수읽기·선제 돌격·방비 진형)·대응(보좌 개입·반격 태세·보급 회복)·승부수(결사 일격·허점 폭로·맹약의 증언). 덱 계열이나 동행 인재가 있어야 고를 수 있음.
- 군진 전투: 호위 계약→방진, 짐꾼 증언→양동, 비축 군량→징발, 우회로→매복, 장수 신뢰→반격 태세, 책임 분담→부담, 남은 장애→동요. 전투 전 변환 목록 표시, 전투 후 사라짐.
- 관문: 민회(명예 요구 +2, 참여 인재·명분→지지 연쇄로 감소), 군영(병영 퍼즐 미해결 장애가 상대 체력을 올림, 기세·보급 생산이 시작 조건), 성문 내응(설전 결과가 후속 대결 조건으로 전환, 우회로·포섭·내부 협력 4 이상이면 성공 시 대결 생략). 군영·내응은 전술 3장 편성 필수.
- 보상: 카드 3장 중 1(보관함) / 받지 않기 / 강화 / 제거 / 인재 관계 / 책략 / 아이템 / 자원. 휴식(`rest:<mode>`): 피로 회복·제거·강화·인재 대화, 하루 1회.
- 부담: 부담 카드는 장애를 줄이지 못하지만 부담 표식을 남기고, 정보 원칙·짐을 진 맹세·진궁의 불리함 전환·분산 군량망이 이를 보급·약속·단서·준비력으로 바꿉니다.
