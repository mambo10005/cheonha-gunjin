# 천하군진 — 카드 거병 구현과 검증

> 이전 시작 방식의 기록입니다. 현재 새 캠페인은 [도시 탐색형 거병](PROLOGUE.md)과 [시드 131001 안내](PROLOGUE-PLAY-GUIDE.md)를 따릅니다. 이전 저장은 이 문서의 기존 규칙으로 계속합니다.


2026-10-10 현재 체크아웃 기준. 이번 변경은 기존 통합 캠페인의 거병 준비를 교체한다. 새 게임을 만들지 않았다. 시작 도시 → 카드 거병 → 세력 창설 → 내정 → 병력·군량 적재 → 기존 원정 → 도시 편입의 같은 저장 상태를 사용한다. 현재 캠페인의 승리 범위는 하남 세 도시의 지역 패권이며, 전국 천하통일은 아직 구현되지 않았다.

## 기존 구현 분석

| 확인 질문 | 변경 전 코드의 상태 | 이번 변경 |
|---|---|---|
| 거병이 임계치 판정인가 | 자금 4·군량 8·병력 12·지지 3·거점·인재 2명을 충족하면 창설 | 새 거병에서는 실전 관문 결과를 창설 조건으로 사용 |
| 행동이 고정 목록인가 | 탐문·차입·매입·모집·향촌·거점·회피 반복 | 6단계 경로, 손패, 장소 사건과 선택 보상 |
| 설전·대결이 연결됐는가 | 원정 활동에는 있었으나 초기 창설 관문에는 없었음 | 기존 설전·대결 엔진에 준비 카드·실제 군량·지원 반영 |
| 카드와 관계가 남았는가 | 준비 덱 자체가 없었음. 자원·인재·창설 방식 일부만 전달 | 카드별 데이터에 내정·전투·설전·정책·의무·소모 운명 정의 |
| 성공 때 자원을 생성했는가 | 기존 창설 방식에 병력·자금 보너스와 차입 처리 존재 | 기존 보너스를 대체하고 잔여 장부를 권위 있는 값으로 사용. 대결 승리 병력 보너스만 명시 |

| 대결 결과가 창설에 반영됐는가 | 준비 단계와 연결되지 않았음 | 승패·기권·부상·실전 지원이 결과 등급과 도시 상태에 반영 |
| 도시별 지역 집단 표현 가능한가 | 도시 정의·집단 관계·후보 인재·약속·시설이 있음 | 도시별 시작 카드·비축·지역 역할 연결. 상세 대사는 아직 공통 역할 중심 |

## 거병 런

형양·성고·공현 중 시작 도시, 출신 3종, 대표 3명, 보좌 3종을 선택한다. 10장 시작 덱과 초기 거병 책략을 받고, 6개 단계에서 각 3개 경로 중 하나를 방문한다. 3개 장소 이후에는 조기 관문도 가능하다. 일반 장소 8종, 정예 2종, 휴식·정제 2종이다. 장소마다 사용 계열·위험·인물 역할·유료 사건·보상 계열이 다르다.

각 장소의 손패는 4장, 준비력은 3이다. 카드 사용 후 버림, 뽑기 소진 시 재섞기, 일부 카드는 해당 런에서 소멸한다. 단계 종료 버튼을 눌러야 미사용 손패를 버리고 군량 1·노출 1을 정산한다. 일반 장소는 진행 2, 정예는 진행 3이 필요하다. 신중한 접촉은 진행 2, 장소별 유료 선택은 진행 3이다. 손패가 맞지 않을 때 추가 접촉을 1회 사용할 수 있으며 준비력 1과 노출 1을 낸다.

한 보상에서 카드 3장 중 1장, 받지 않기, 자금·군량, 강화, 제거, 개조, 책략, 협력 중 하나를 고른다. 후보는 노드 계열·출신·부족한 군량 등의 가중치를 사용한다. 모든 후보를 현재 빌드의 정답으로 보장하지 않는다. 보상 후보·UID·선택 토큰이 저장되므로 불러오기로 다시 굴리지 않는다.

## 시작 덱과 인물

| 출신 | 방향 | 시작 책략·부담 |
|---|---|---|
| 재야 명사 | 명분·추천·보호 서약 | 민심 규합, 자금 부족 |
| 향촌 의용군 지도자 | 수레·훈련·군사 | 의용군 맹약, 행정 기반 부족 |
| 지방 관리 | 문서·정보·연락 | 내응의 문, 기존 질서의 부담 |

공용 4장(격문·군량·자금·보좌 카드), 출신 2장, 도시 1장, 대표 2장, 부담 1장으로 총 10장이다. 대표는 진궁(조건과 명분), 장료(군사 동원과 훈련), 곽가(정보와 연쇄)다. 대표의 고유 카드와 지속 효과가 다르다. 시작 이후 대표 변경으로 고유 카드를 추가 복제할 수 없다.

보좌는 전위 호위대(물자 이후 훈련, 대결 대리), 곽가 문객(정보 이후 명분, 정보 논거), 정포 물류 연락(자금 이후 군량, 물류 카드)이다. 같은 장수가 대표와 협력에 겹쳐도 실제 장수를 두 번 생성하지 않는다.

## 카드·책략·협력

카드는 총 **40장**: 공용 12, 계열 18, 대표 고유 6, 부담 4. 계열은 명분·인맥·군자금·군량과 물자·군사·정보와 계책·약속의 7종이다. 효과는 타입으로 정의하고 원인, 발동 시점, 우선순위, 단계당 제한을 기록한다.

거병 책략 슬롯은 2개, 일반 6개·희귀 2개다. 군량 → 군사는 의용군 맹약의 추가 병력을, 정보 → 인맥은 내응의 문의 경로 공개를, 서로 다른 명분 연속 사용은 격문의 연환의 설전 비용 할인 준비를 만든다. 희귀 책략은 정보 → 물자에서 추가 뽑기, 약속 → 인맥에서 준비력 회복을 제공한다. 빈 군영 장악은 실제 대결의 첫 기세 소비 뒤 기세 1을 회복한다. 발동 제한이 있어 반복 제출로 무한 회복하지 않는다.

협력은 핵심 2명과 지역 지원 1개를 사용한다. 전위·곽가·정포·현지 서리로 이어지는 네 핵심 역할, 향촌 대표단·상단 출자자의 두 지역 역할이다. 준비 도중에는 정식 장수 명단을 늘리지 않으며, 창설 결과에서 합류 조건을 적용한다. 지역 지원은 주민·상단 관계와 채무로 남는다. 기존 슬롯이 차면 교체할 대상을 명시해야 하며 시작 보좌는 유지된다.

강화는 광포(지지와 노출), 정론(명분·정보·노출 완화) 두 분기다. 곡물 매입에는 대량 매입(자금 2 → 군량 7, 소멸)과 분산 매입(자금 1 → 군량 3, 비소멸)의 다른 규칙이 있다. 개조는 첫 손 등장, 비용 1 감소와 소멸, 사용 후 1장 뽑기의 세 종류다. 강화·개조와 카드 제거는 실제 카드 UID와 더미를 변경한다. 대표 고유 카드 제거는 제한한다.

준비력 최대 5, 손패 최대 8, 덱 최대 30, 장소당 제출 최대 12장으로 0비용 드로우 연쇄를 제한한다. 미리보기는 복제 상태에 동일 처리기를 적용하며 원본 RNG를 소비하지 않는다. 모든 선택은 상태 버전을 확인해 오래된 화면의 재입력을 막는다.

## 최종 계획과 실제 관문

| 계획 | 준비의 역할 | 결과의 차이 |
|---|---|---|
| 민회와 격문 | 명분·지지가 설전 요구를 낮춤. 준비 논거·보좌·실제 군량 사용 | 주민 관계와 초기 안정 유리, 병력은 적고 약속이 남을 수 있음 |
| 군영 장악 | 훈련·물자가 실제 기세·방비·전술을 준비. 대표 또는 협력자 대리 | 대결 승리 병력 4명 합류, 도시 안정·민생 손실 |
| 성문 내응 | 정보·인맥으로 설전과 대결을 연결 | 설전 완전 협력·정보 6·인맥 4·노출 12 미만이면 충돌 없이 인수. 나머지는 실제 대결 |

계획은 준비도 8을 기준으로 부족분을 계산한다. 자원 하나가 부족하다고 선택을 막지 않고 상대 요구 또는 체력을 강화한다. 노출 8부터 관문 강화, 12부터 공개 경로 하나 폐쇄, 18부터 조기 계획을 권고한다. 18은 자동 강제 종료가 아니다. 계획 확정 후 취소·환급은 없다.

설전은 기존 장수별 설전 덱을 사용하고 거병 카드에서 매핑된 임시 논거를 최대 12장 넣는다. 실제 준비 군량을 설전 군량 장부에 연결한다. 현재 요구 축·집중·신뢰·부담, 라운드 종료, 최종 제안, 공개 반론 기록을 표시한다. 상대는 향촌·관리 민회와 관청 내부 협력자의 두 역할이다.

대결은 기존 지휘권 경쟁과 관문 호위 패턴을 재사용한다. 준비 카드가 장착 전술 최대 2개, 훈련이 시작 기세·방비를 바꾼다. 정보 3 이상이면 상대 순서를 고정한다. 시작 단계에서 대표 또는 실제 핵심 협력자의 대리를 선택한다. 기존 기본 행동 4종과 획득 전술을 사용한다. 부상은 다음 대결 체력과 합류 후 피로로 남는다.

복합 거병에서는 설전 완전 협력·조건부 협력·결렬을 대결 지원 2·1·0으로 전달해 상대 체력을 바꾼다. 대결 패배·기권은 앞선 설전 성공으로 상쇄되지 않는다. 설전이 부족해도 대결 승리로 조건부 거병이 가능하다. 일반 원정 활동 보상을 받는 흐름을 호출하지 않아 두 관문 보상을 중복 획득하지 않는다.

## 결과와 도시로의 전달

대성공·성공·조건부 성공·불완전 거병·도피·기반 상실을 구분한다. 조건부·불완전 결과는 채무 2와 권한 의무를 추가한다. 실패했어도 약속과 지지가 남으면 불완전 장악으로 이어지고, 청사·성문 피해와 잔당 과제가 생긴다. 그 외 실패는 도피한다. 패배는 병력 30% 손실과 부상을 남긴다.

도피 후 재기는 **같은 지역에서 1회** 가능하다. 카드·강화·단서·협력·약속을 유지하되 자금·병력 절반을 잃는다. 소멸 카드는 되살리지 않는다. 두 번째 도피 또는 잔여 기반 상실은 캠페인 실패로 끝난다. 다른 지역으로 실제 이동하는 도피 경로는 아직 없다.

창설은 한 번만 도시를 생성한다. 남은 준비 자금은 금고, 군량은 도시 비축, 병력은 예비병이 된다. 대결 승리 보너스는 별도로 표시하고 200명 상한을 지킨다. 창설 방식의 이전 고정 보너스를 중복 지급하지 않는다. 안정·민생·집단 관계·시설 피해·약속·채무·합류 장수·피로를 각각 실제 도시·캠페인 상태에 전달한다.

각 카드의 `fate`가 기존 내정·전투·설전·정책 ID를 참조한다. 예: 곡물 매입 → 창고 감찰, 군영 구령 → 반격 태세, 격문 → 권한 문서, 향촌 대표 → 향촌 중재. 정책은 도시 슬롯이 허용할 때 3턴 적용한다. 같은 전환 결과는 거병에서 종류별로 한 번 전달하며 카드 수집 복제로 보상 수량을 불리지 않는다. 소모된 준비 계획은 기록에 남기고 지속 성장 대상으로 설명하지 않는다. 사용한 약속·차입의 의무는 사용 시 생성되어 캠페인 장부에 남는다.

원정용 전투·설전 카드와 내정 카드는 서로 다른 덱을 유지한다. 협력자는 실제 임명·군단·대기 상태 중 하나로 사용된다. 첫 원정은 도시 예비병과 군량을 실제 차감하며 기존 전투·설전·외교, 점령, 공통 도시 턴을 사용한다.

## 저장 호환

CampaignState 저장 버전 7 안에 선택적 거병 상태 버전 1을 추가했다. 루트 저장 키는 `cheonha-gunjin.campaign`이다. 거병 상태에는 시드·RNG·경로·더미·UID·강화·개조·보상 후보·책략·협력·계획·진행 중 설전/대결·결과·전환 여부가 포함된다.

기존 준비 저장은 자동으로 덮어쓰지 않고 **현재 준비를 카드 거병으로 전환** 버튼으로 가져온다. 기존 자원과 장수를 보존하고 한 번만 시작 덱을 추가한다. 기존 전략·원정 저장은 그대로 이어간다. 손상된 새 상태는 로드 거부하고 원본 저장 문자열을 보존한다. 원정 시드가 출진 때 바뀌므로 거병 시드 검증은 변하지 않는 캠페인 시드를 사용한다.

- 자동 테스트: 거병 구현 당시 277개 통과. 이후 시작 화면 개선을 포함한 현재 전체 278개 통과. 거병 규칙 26개, 새 거병 공개 빌드 DOM 3개와 기존 회귀 검증을 포함한다.
- 타입 검사·Vite 배포 빌드: 통과.
- 거병 DOM: JSDOM에서 배포 코드를 실행해 6개 준비 거점, 획득·강화·제거·협력, 카드 예상과 실제 일치, 설전, 창설, 내정 임명·카드·모병, 출진과 저장 복원을 확인했다. 별도 대결 DOM은 대리·전술·각 턴 복원·승리·창설, 기존 준비 변환 DOM은 자원 보존을 확인했다.
- 규칙 통합: 거병 이후 출진·진행 중 매 행동 저장·점령·공통 턴·지역 패권의 저장 유효성을 확인했다.
- 실제 브라우저 렌더링·데스크톱/모바일 레이아웃·사용자 플레이·재미: **미검증**. 브라우저 정책 차단을 재시도하거나 우회하지 않았고 보안 설정을 변경하지 않았다.

153회 자동 플레이는 매 행동 저장 후 **불러온 상태로 다음 행동**을 했다. 126회는 시드 121001~121002 × 도시 3 × 출신 3 × 정책 7에 대표·보좌를 순환 배치했다. 추가 27회는 시드 121003 형양에서 출신 3 × 대표 3 × 보좌 3의 균형 정책이다. 전체 조합의 완전한 곱집합 검증은 아니다.

이번 관측은 창설 153/153, 대성공 59·성공 17·조건부 성공 77, 저장 복원 실패 0·진행 오류 0이었다. 제거 135회·건너뛰기 128회·도피 후 재기 2회가 기록됐다. 불완전 거병과 최종 기반 상실은 이 자동 표본에 없으며 별도 규칙 테스트로 확인했다.

정책은 명분·군사·정보·균형·저노출·조기거병·무작위 7종이다. 결과 원자료는 [raising.json](verification/raising.json). 보고서의 `success`는 조건부 창설까지 포함한 창설 여부이며 완전 승리율이 아니다. 자동 정책은 사건 선택과 보상 행동이 제한되어 모든 카드·개조·책략 조합을 탐색하지 않는다. 카드 제거·받지 않기를 실행했다는 사실은 그 선택이 최선이거나 재미있다는 증거가 아니다. 군사 정책의 높은 안정성과 일부 대표의 조건부 비중은 후속 밸런스 점검 대상이다.

## 변경 파일과 남은 범위

주요 새 파일: `src/core/raising-types.ts`, `raising.ts`, `raising-validation.ts`, `src/data/raising.ts`, `src/ui/raising-screen.ts`, `raising-screen.css`, `src/sim/raising-policy.ts`, `raising-benchmark.ts`, `tests/raising.test.ts`, `raising-ui.test.ts`. 기존 `world-types.ts`, `world.ts`, `world-validation.ts`, `save-validation.ts`, `world-screen.ts`, `world-campaign.ts`, `world-ui.test.ts`, package.json을 연결했다.

형양을 기준 도시로 검증하고 성고·공현은 데이터 기반 시작 차이와 자동 플레이를 제공한다. 추가 두 도시의 독립적인 고품질 사건·인물 연출은 남아 있다. 네 번째 상단·물류 전용 출신/최종 계약 관문, 관청 접수 별도 계획, 전국 지도 확장, 양방향 복합 관문의 별도 순서, 지역 간 도피 이동, 완전한 부분 구역 소유권은 미구현이다. 현재 부분 장악은 시설 피해·잔당·의무로 표현한다. 대표·보좌 성장의 더 많은 분기와 신규 대결 행동, 모든 카드별 전용 강화 연출도 남아 있다.

현재 구현은 3개 출신·3개 계획의 카드 수집 → 실제 관문 → 도시·첫 원정 연결 수직 단면이다. 자동 검증 통과를 상용 품질·재미·균형의 완료로 보고하지 않는다. [시드 121001 수동 실행 안내](RAISING-PLAY-GUIDE.md)에 사용자 검증 순서와 기록 양식을 제공한다.
