# 천하군진 설전 덱 구축 수직 단면

2026-10-09 / 앱 0.5.0 / 원정 저장 버전 5. 기존 게임과 시네마틱 장면을 유지하면서 설전 하단을 실제 손패로 교체했다. 이번 완성 단위는 곽가·진궁 두 원형이다. 요청 전체의 4원형·대형 풀·우두머리·메타 해금까지 완료했다고 주장하지 않는다.

## 기존 시스템 분석과 변경

기존 규칙은 4회 동안 고정 논거 8개를 계속 선택하고 매 선택이 한 회차였다. 한 번 생성하는 반론은 2회 뒤 요구 +1이었다. 장수는 적성/특성 보너스였으며 설전 카드 인스턴스·더미·원정 카드 성장은 없었다. demands/negotiation의 이익·안전·명분·권한·신뢰·부담, 실제 원정 군량 지불, 협정/영입/보급 수락, 관계·원정 지도·시드 RNG·복제 미리보기·시네마틱 재생기는 재사용했다.

새 규칙은 원정 전용 군단 설전 덱을 두고, 시작 9장·손 4장·라운드 집중 기본 3·최대 5라운드다. 곽가만 첫 라운드 집중 +1로 적성을 제한 반영한다. 카드를 여러 장 써도 라운드는 지나지 않는다. 라운드 종료 때 상대가 반론을 적용하고 남은 손을 버리며 새로 4장 뽑는다. 드로우가 비면 버림패를 같은 RNG로 섞고 소멸 카드는 돌아오지 않는다. 현재 손/더미 수는 항상 표시하고 순서는 미공개다.

기존 버전의 진행 중 설전은 그대로 완료할 수 있게 보존한다. 전용 회귀 버튼 31001/51001도 기존 규칙을 명시 유지한다. 새 일반 원정과 전용 61001은 카드 덱 규칙을 쓴다. 기존 회귀 테스트가 새 규칙을 검증한다고 혼동하지 않는다. 작업 시작 시 기존 144개 테스트를 직접 실행해 144 통과를 확인했다.

## 두 대표의 시작 덱과 플레이 차이

공통 6장: 공적 근거 / 대책 문서 / 작은 보증 / 비용 떠안기 / 권한 문서 / 보급 경로.

| 대표 | 고유 3장 | 원칙 | 방식과 약점 |
|---|---|---|---|
| 곽가 | 기미를 읽다 / 예고된 허점 / 살아 있는 첩보 | 선견: 추가 반론 공개, 라운드 첫 정보→계책 카드 1장 | 반론을 읽고 정보→방어/안전 연계를 만든다. 실리 요구를 정보 카드만으로 채우기 어렵고 순서가 끊기면 고유 카드 효율이 낮다. |
| 진궁 | 불리함을 받다 / 조건 돌려쓰기 / 조항을 추리다 | 변통: 라운드 첫 부담 증가에 드로우 1·집중 +1 | 부담을 행동 기회로 바꾸고 실리→계책으로 다른 요구를 채운다. 부담 정리가 없으면 완전 합의가 막힌다. |

전체 데이터는 27장: 공용 8장, 추가 계열/약정 9장, 고유 6장, 방해 4장. 명분·실리·신뢰·압박·정보·계책 6계열이 서로 다른 자원/조건을 처리한다. 독립 대형 풀을 장수마다 복제하지 않았다. 다른 장수는 공용 원형 fallback을 쓸 수 있지만 전문 원형 완성으로 표시하지 않는다. 진궁의 최종 초상 원화는 이전 시네마틱 단계와 동일하게 실루엣이다.

같은 대표도 인장/보상/강화/제거/개조로 다른 빌드를 만든다. 예:

- 곽가 정보 순환: 상황 조사 → 논점 잇기. 기본 안전에 정보 연계 안전 +2, 선견 드로우, 허실의 인의 추가 기본 수치·소멸이 이어진다.
- 진궁 부담 전환: 불리함을 받다 → 신뢰 장부. 변통이 드로우/집중을 만들고 직전 부담 조건이 안전을 보강한다. 양보의 인을 더하면 안전 +2가 연쇄한다. 조항을 추리다로 부담과 방해를 정제한다.
- 공용 정론: 공적 근거의 정론 강화는 명분과 반론 방어, 연계 강화는 직전 정보일 때 신뢰를 만든다. 같은 카드라도 현재 덱의 정보 밀도에 따라 두 강화의 가치가 다르다.

주장만이 아니라 규칙 테스트에서 인장 있는/없는 같은 순서의 실제 수치 차이, 장수별 원칙 차이, 두 강화의 행동 차이, 대표 교체의 인스턴스 보존을 확인했다. 모든 빌드가 재미있거나 동등하다는 증명은 아니다.

## 인장·연쇄·악용 방지

인장 슬롯은 2개이며 현재 6종: 연환/공론/장부/반박/양보/허실. 세 계열 연속, 다른 계열 전환, 군량 지불, 반론 방어, 부담→신뢰, 정보→계책의 조건으로 발동한다. 공론은 서로 다른 계열 전환에 발동하는 첫 단면의 단순화이며 같은 요구 교차 사용 규칙으로 구현했다고 주장하지 않는다. 허실은 기본 수치만 추가하고 현재 카드를 소멸한다. 복사는 드로우·집중·복사·생성·회수·소멸 처리 자체를 복사하지 않는다.

카드 데이터의 타입 있는 Operation/Effect를 한 엔진에서 처리한다. 인장과 원칙은 발동 시점·조건·출처·순서·횟수 제한을 갖는다. 인장은 라운드당 1회, 처리 예산 48·깊이 6·라운드 카드 12회·손 상한 8·설전 생성 카드 40·원정 덱 20이다. UI 입력은 회차 대신 개별 처리 revision을 확인하므로 같은 카드가 다시 뽑혀도 낡은 버튼 입력을 재적용하지 않는다. 끝없는 0비용 드로우나 복사 재귀가 불가능하도록 제한했다.

## 반론과 합의

| 상대 | 공개된 규칙과 대응 |
|---|---|
| 상단 | 첫 이익 요구 증가, 의심·부담 상한·재검토·지연 패턴. 실리만 반복하기보다 방어/신뢰 연계를 준비한다. |
| 향촌 | 안전 요구·재검토 중심. 압박 수치 효과 −1이며 면역은 아니다. 신뢰/안전으로 우회한다. |
| 재야 인재 | 명분·권한 요구와 재검토/지연/의심. 기본 제안 또는 일반 설전도 선택 가능. |
| 선택적 정예 공개 변론 | 같은 계열 연속 수치 −1, 각 반론에 방해 카드 생성, 더 높은 요구. 무조건 수치만 증가한 상대가 아니다. |

다음 반론은 공개하고 선견/조사로 그다음을 공개한다. 아직 순서를 모르는 반론의 가능한 종류와 정예 제약은 시작 로그/규칙에서 공개한다. 현재 단면은 강한 반론을 별도 준비 단계로 나누지 않고 모두 같은 라운드 반론 처리다. 방어는 다음 반론을 차단하는 범용 토큰이며 종류별 정확 대응을 구현했다고 주장하지 않는다.

완전 합의는 모든 공개 요구·신뢰 3·부담 상한을 지킨다. 조건부 합의의 필수는 첫 요구와 신뢰 2, 부담은 상한 +1까지이며 거래별 추가 비용/예치/불리한 조건을 확인한다. 미결 조항이 남으면 완전 합의가 제한된다. 처음부터 이 판정을 표시한다. 결렬은 필수 미충족/신뢰 붕괴, 철회는 플레이어 중단이다. 최종 제안 버튼에 현재 예상 등급을 표시한다. 체력/공격력 승부로 바꾸지 않았다.

방해: 의심은 손의 신뢰 효과를 약화, 장황함은 손을 차지하며 처리하면 순환, 말꼬리는 반복 계열의 부담 증가, 미결 조항은 최종 조건부 제한. 정제 카드/개조는 이 카드를 소멸시켜 이득을 만들 수 있다. 모두 설전 임시 카드이며 영구 저주로 원정 덱을 오염시키지 않는다.

## 보상과 원정 연결

완전/조건부 합의 뒤 전문 카드 최소 1장과 섞인 2장 중 추가, 건너뛰기, 강화, 제거, 개조, 전수, 인장 장착/교체, 즉시 군량 중 하나만 고른다. 결렬/철회는 카드 보상 없이 기본 제안을 유지한다. 조건부의 대가는 뒤의 실제 거래 조건에 남는다. 후보는 생성 시 저장하므로 새로고침으로 다시 굴리지 않는다. 원정 위치별 토큰으로 같은 보상을 두 번 받지 못한다.

강화는 핵심 공적 근거·비용 떠안기의 두 분기만 구현했다. 개조는 집중 −1·소멸 / 첫 손 / 사용 후 드로우 / 버림패 방해 정리 4종, 카드별 허용 목록과 1개 제한이다. 인스턴스에 붙으므로 동일 카드의 다른 복사본에 공유되지 않는다. 전수는 공용 정보/신뢰 표식 화이트리스트, 원본 제거, 대상 1회 제한, 고유 원본 금지, 공용 최소 4장 유지다. 세 번째 인장 슬롯·희귀 인장은 아직 없다.

대표 변경은 공용·획득 카드/인장을 유지하고 고유 시작 3장을 교체한다. 빠짐/추가/원칙/덱 크기를 미리 보여 준다. 고유 카드의 강화·개조는 대표 교체 시 제외한다고 표시한다. 보좌는 군단의 조인/전위 중 대표와 다른 1명, 임시 지원 카드 1장과 설전당 조언 1회다. 모든 장수를 패시브로 합산하지 않는다.

군량 담보는 실제 원정 군량 2를 즉시 차감하며 실패/철회에도 환급하지 않는다. 다음 이동의 군량 1 약속을 이행하면 상단 관계 +1, 미이행이면 −1. 권한 약정은 이후 전투 카드 보상 1회 선택지를 제한하고 중복 지급하지 않는다. 기존 외교 협정의 활성 상태는 임시 권한 문서 1장을 제공한다. 보급·관계·후속 거래·협정의 원정 결과 처리는 유지했다. 의무의 상태와 이행/위반은 원정 이력에 남는다.

8층을 늘리지 않았다. 기존 보급/휴식에서 군량 2로 서원 학습을 선택해 설전 덱을 성장시킬 수 있다. 같은 장소 토큰을 사용하므로 보상 반복 획득은 금지한다. 학습 뒤 기존 보급/회복 선택으로 돌아온다.

## UI·저장·진입

기존 인물 무대·모션 감소·건너뛰기·고대비·글자 크기·수동 대사를 유지했다. 하단은 실제 손패/집중/더미이며 카드 선택 시 실행 엔진 복제본으로 기본 효과·원칙·인장·자원·반론·드로우/소멸 수·최종 결과를 표시한다. 미공개 드로우의 카드명과 순서는 표시하지 않는다. 기록은 실제 원인→효과 순서를 남긴다. 초점 복귀/키보드/모바일 가로 손패는 DOM과 CSS 구조로 확인했으며 픽셀 배치는 미검증이다.

저장 버전 5는 원정 덱·개조/강화/전수·대표/보좌·인장·약속·보상 후보/수령 토큰, 설전의 모든 더미/손·반론 순서·횟수/할인/방어·RNG·revision·선택 대사를 저장한다. settled는 규칙 처리가 끝났다는 영수 상태다. 연출 큐는 재생하지 않고 확정 상태에서 이어가므로 미처리 연출 때문에 규칙을 다시 적용하지 않는다. 버전 1~4는 원정을 보존하고 이전 진행 중 설전도 그대로 완료한다. 옛 규칙의 원정은 옛 입구를 유지하며 다음 새 원정부터 카드 덱을 사용한다.

Node >=22.18에서 저장소 폴더의 `npm ci`, `npm run dev`, 터미널의 Local 주소를 사용한다. 직접 file:// 접근이나 차단된 브라우저 재시도는 하지 않는다.

진입: 새 원정 → **설전 덱 원정 · 곽가/진궁 (61001)** → 기존 전투 교리 선택(재현 기준은 허점 공략) → 1층 상단 → 대표 선택 → 후원 설전. 일반 시드 입력란에 숫자만 입력하는 것과 전용 버튼은 다르다. 2층 보급에는 서원 학습, 3층 향촌, 4층 인재 일반/정예 설전, 이후 기존 전투·결전이 이어진다. 보좌는 펼친 준비 패널에서 선택한다. 높은 적성만 기본 선택값으로 정답 처리하지 않는다.

수동 확인: 두 대표에서 시작 고유 카드/원칙 확인 → 카드 한 장 실행 후 같은 회차 유지 → 라운드 종료/새 손 → 드로우·재섞기·소멸 → 연쇄 출처 → 최종 합의 → 성장 추가/건너뛰기/강화/제거 → 다음 설전 덱 유지 → 약속 후 이동/보상 제한. 진행 중·보상 화면에서 새로고침해 더미/후보/RNG/비용 불변을 확인한다. desktop1600×900/laptop1366×768/tablet820×1180/mobile390×844와 큰 글자/스크린리더/모션 설정은 사용자 브라우저에서 미검증이다. 콘솔 원문·대표·보좌·시드·카드 UID/순서·라운드/revision·기대/실제·이미지를 기록한다.

정적 화면 자료 6종은 public/verification/debate-deck에 있다. 실제 UI 렌더러의 HTML이며 결과/보상 fixture 수치 주입은 표시했다. 스크린샷이나 브라우저 실행 결과가 아니다.

## 자동 플레이 결과와 한계

12시드 × 2대표 × 5정책 = 120개 압축 원정, 각 상단/향촌/정예 3설전 = 360설전. 카드 획득/강화/인장 선택을 이어가며 즉시 요구·신뢰 안정·인장 연쇄·정제·무작위 유효 행동을 비교했다. 무작위 정책에는 별도 시드 정책 RNG를 사용하여 규칙 RNG를 미리보기로 소비하지 않았다.

모두 행동 상한 안에서 종료했다. 카드 선택 건수와 연속 반복 비율, 덱/라운드/합의 비율은 verification/deck-balance.json에 저장했다. 카드가 등장한 압축 원정의 완전 합의 비율은 deck-card-associations.json에 기록했으나 장수/정책/다른 카드가 섞인 상관이며 카드의 승리 인과 효과나 순위가 아니다. 이번 표본에서 미사용 카드는 challenge, authority, redress. 약한 카드와 특정 인장의 의존도를 더 조사해야 한다. 현재 보상 스킵은 정책들이 거의 택하지 않아 표본에서 0이며, 스킵이 구현되었다는 사실과 정책이 스킵 가치를 입증했다는 주장을 구분한다. 정제 정책도 초기 압박 카드가 없어 제거 기회가 적다. 제거는 구조와 실제 상태 변화 테스트로 검증했으며 장기 우월성을 통계로 입증하지 않았다.

별도 전체 원정 자동 실행에서 시드61001 두 대표 모두 8층 동탁전 도달 후 패배했다(전투 13턴). 이는 전체 원정 입구가 이어진다는 실행 결과이며 클리어/사람의 재미 검증이 아니다. 압축 표의 설전 성공률은 전체 원정 승률이 아니다. 곽가가 모든 정책에서 우월하지 않은 점은 확인했으나 모든 장수의 정답 여부나 균형을 단정하지 않는다.

## 검증 및 변경 파일

직접 실행 명령: `npm test`, `npm run build`, `npm run typecheck`, `npm run assets:check`, `node scripts/render-deck-fixtures.ts`, `node src/sim/debate-deck-benchmark.ts 12`.

규칙·악용·저장·시드·미리보기: 새 테스트의 카드 더미/비용/소멸/생성/복사/강화/개조/제거/전수/대표 교체/보좌/인장/순서/제한/반론/방해/합의/철회/원정 의무/보상 중복/재굴림/마이그레이션을 확인했다. DOM: 실제 선택·예측·취소·초점·금지 이유·한글 escape와 컴파일한 앱에서 두 대표 입구→카드 실행→새로고침→결과→보상 건너뛰기→원래 외교 화면을 확인했다. DOM은 실제 브라우저 레이아웃 테스트가 아니다.
