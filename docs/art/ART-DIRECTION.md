# 천하군진 시네마틱 설전 아트 바이블

기존 임시 SVG는 420×500 동일 도형/기본 얼굴이고 포즈는 CSS 이동뿐이다. 프레임 높이 285px, 모바일 155px가 상체의 시각적 비중을 낮춘다. 중앙은 speech/goal 박스, 손패는 4×2 배열, 상세는 최소 75px 문서 흐름 패널, 로그/설정도 뒤에 이어져 세로 길이가 누적된다. 새 설전은 무대 1개와 오버레이 1개로 재구성한다. 실제 화면은 브라우저 정책 때문에 관찰하지 않았으며 이 진단은 코드 분석이다.

독립적 미술 방향: 옻칠과 잿빛 비단을 기본 재질, 청동·봉니를 강조. 후한 말 회담의 소품과 공간, 회화적 얼굴·손·직물을 중심으로 한다. 특정 회사·게임 화풍, 화면, 얼굴, 배경을 참조하지 않는다.

곽가: 좁고 긴 실루엣, 옅은 회청 비단 안감과 짙은 먹청 겉옷, 높지 않은 검은 관모. 단정한 젊은 책사, 기록을 펼치는 손. 시선은 화면 오른쪽. 따뜻한 중앙 측광과 차가운 외곽광. 포즈 neutral/speak/press/countered/concede/victory. 동일 얼굴·옷·죽간을 유지. 성격은 역사 사실 설명이 아니라 게임 통찰 기능의 시각 표현.

상단 교섭관: 가상의 일반 인물, 곽가와 다른 둥근 얼굴·중년 표현·짧은 수염. 흙빛 자주와 회색 린넨, 둥근 직물 관모, 장부와 작은 인장함. 시선은 왼쪽, 묵직하고 실무적인 손동작. 특정 실존인을 재현하지 않음. 포즈 6종과 얼굴·의상 일관성을 유지.

다중 포즈 방식 A를 선택. 각 포즈에 고유 손/문서 동작을 생성하고 140ms 교차 페이드, 1~3% 이동, 얼굴 기준점을 통일한다. 리깅/Spine은 도입하지 않음. 얼굴을 변형하지 않는다.

군막 회담장: 천막의 광대한 내부, 보이는 후경 기둥/지도/막 자락, 중앙 중경 탁자/문서/등잔, 전경 어두운 천과 연기. 인물 자리 좌우는 낮은 대비, 중앙 글자 자리는 여백. 다른 장소는 독립 원화 완료 전까지 같은 무대 베이스의 장소별 소품·조명 변형으로 명시하며 별도 완성 배경으로 주장하지 않음.

현재 주요 인물 우선 완료, 진궁/향촌/선비는 품질이 통제된 무명 실루엣 fallback. 도형 얼굴을 계속 최종 화면에 쓰지 않음. 임시 표시 개발 모드에서만 표시. 생성 원화는 검수된 생성 에셋이며 전문 원화 최종 승인과 실제 화면 검수는 별도 상태로 기록.
