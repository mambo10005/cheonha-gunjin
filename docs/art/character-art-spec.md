# 인물 원화 사양

인물 초상은 장소의 인물 카드(가로가 좁은 카드에 위쪽 얼굴 중심으로 잘림), 대화 칸의 상대 초상, 설전·대결 상대 초상에 쓰인다.
기존 객사 인물 원화(`public/assets/inn/innkeeper-v1.webp`, `lusu-v1.webp` 등)와 같은 사양이다.

## 공통 사양

| 항목 | 값 |
|---|---|
| 형식 | WebP(권장) 또는 PNG. 파일 이름의 확장자는 manifest와 같아야 한다(현재 `.webp`). |
| 크기 | 1024×1536 |
| 비율 | 2:3 세로 |
| 배경 | 투명(알파 채널). 생성 도구가 투명 배경을 못 만들면 단색 어두운 배경으로 만든 뒤 배경을 지워 넣는다. |
| 구도 | 허리 위 또는 무릎 위 반신. 머리 전체가 보이고, 얼굴 중심이 가로 50%, 세로 위에서 15~25% 사이. 머리 위 여백 5% 이상. |
| 용량 | 400KB 이하. |
| 금지 | 글자·로고·워터마크·테두리·UI·현대 복식·애니메이션 화풍·실존 게임 캐릭터 디자인. |
| 화풍 | 기존 객사 인물과 같은 손그림 사실풍, 은은한 수묵 기법, 시대 복식의 질감, 따뜻한 측광. |

## 창고 책임자(`granary-keeper`)

| 에셋 ID | 최종 파일 경로 | 인물 |
|---|---|---|
| `granary-keeper.portrait` | `public/assets/runtime/characters/granary-keeper/portrait.webp` | 창작 인물 왕상. 사십대 후반 동아시아 남성, 검은 두건, 다듬은 콧수염과 짧은 턱수염, 바랜 갈색 관리 도포, 두 손에 대나무 장부, 허리에 청동 열쇠 꾸러미. 성실하지만 계산이 빠른 표정. |
