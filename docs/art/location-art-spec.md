# 장소 원화 사양

장소 장면 그림은 장면 상단의 큰 그림 영역(`.location-scene-visual`)에 `object-fit: cover`로 채워진다.
조사 대상 이름표(예: "짐 실은 수레")와 장소 이름표가 그림 위에 겹쳐진다.

## 공통 사양

| 항목 | 값 |
|---|---|
| 형식 | WebP(권장) 또는 PNG. 파일 이름의 확장자는 manifest와 같아야 한다(현재 `.webp`). |
| 크기 | 1920×1080 권장, 최소 1600×900. 기존 객사 원화는 1672×941이다. |
| 비율 | 16:9 가로. 생성 도구가 3:2(1536×1024) 등만 지원하면 16:9로 잘라 넣는다. |
| 배경 | 불투명. 투명 배경을 쓰지 않는다. |
| 용량 | 450KB 이하(WebP 품질 약 85). |
| 안전 영역 | 핵심 대상은 가운데 70% 폭 안에 둔다. 좁은 화면에서는 좌우가 잘린다. |
| 하단 여백 | 아래쪽 15%에 조사 대상 이름표가 겹치므로 중요한 얼굴·글씨를 두지 않는다. |
| 금지 | 글자·간판 문자·로고·워터마크·UI·현대 물건·애니메이션 화풍. |
| 화풍 | 기존 객사 원화(`public/assets/inn/interior-v1.webp`)와 같은 손그림 사실풍, 은은한 수묵 기법, 따뜻한 등불과 서늘한 안개, 어두운 비취·숯색 바탕. 190년 후한 말 화북 지방. |

## 곡물 창고(`granary`)

| 에셋 ID | 최종 파일 경로 | 장면 |
|---|---|---|
| `granary.yard` | `public/assets/runtime/locations/granary/yard.webp` | 앞마당. 높은 석축 위 목조 곡창 정면과 기와지붕, 흙담. 짐 실은 수레와 짐꾼, 자루 더미, 창을 든 호위, 상자로 막힌 좁은 통로, 처마 등불. |
| `granary.office` | `public/assets/runtime/locations/granary/office.webp` | 출입 관리소 실내. 죽간 장부가 쌓인 긴 책상, 벽의 청동 열쇠걸이, 붉은 인장 상자, 격자창 빛, 등불. |
| `granary.interior` | `public/assets/runtime/locations/granary/interior.webp` | 창고 내부. 높이 쌓인 곡물 자루, 큰 토기 독, 철띠와 자물쇠를 단 비축 구역 문, 높은 창의 빛줄기, 찢어져 곡식이 쏟아진 자루. |
| `granary.loading` | `public/assets/runtime/locations/granary/loading.webp` | 하역장. 두 흙담 사이 좁은 통로 끝의 성문 누각, 비탈 하역대와 자루, 통로를 지나는 수레와 짐꾼. |

인물(창고 책임자, 호위, 노숙 등)은 장면 그림에 크게 넣지 않는다. 인물은 별도 초상으로 표시된다. 배경의 작은 짐꾼·호위 실루엣은 괜찮다.
