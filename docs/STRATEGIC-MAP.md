# 천하군진 전략 지도 수직 단면

## 기존 화면 분석

지도 생성은 8층·22거점이다. 앞 7층은 3거점, 마지막 층은 낙양의 동탁이다. 인접한 열을 모두 연결하고 마지막 층으로 합류한다. 보통 지도에는 45개 연결이 있으며, 61001 전용 지도에는 앞층을 모두 연결해 57개 연결이 있다. 기존 화면은 연결을 모두 동일 점선으로 표시하고 같은 크기의 직사각형 거점을 사용했다. 현재 위치·미래·접근 불가능 상태를 흐림과 테두리로만 구분했다. 거점 클릭이 즉시 이동했고, 보상과 자원 변화는 비교 패널이 없었다. 우측에는 장수 능력 전체, 관계·협정, 기록을 계속 쌓았다. 별도 정찰 상태·지도 장수 능력은 현재 규칙에 없다.

## 구현 범위

- 상단 HUD: 군주·병력·군량·층·덱·통행 횟수·의무·범례·설정·규칙·포기.
- 중앙: 낙양 방면 비단/종이색 행군도, 실제 거점 지형에 대응하는 산·하천·농경지·성곽 먹선. 경로와 SVG 아이콘은 저장소에서 직접 제작했다.
- 현재 위치 군기, 방문 확인, 이동 가능 표식, 선택 인장, 부분 확인의 점선 표식, 협정 의무 봉니.
- 선택 패널: 유형·지형·실제 이동 자원 변화·편성 티어·보상 계열·빌드 연계·의무 충돌·3층 후속 분기·진군 확정.
- 가능한 세 경로 비교 카드. 임의 추천 점수 없이 실제 규칙 사실만 표시한다.
- 기록·범례·협정·세력·군단·설정은 고정 오버레이 서랍. 군단 무료 전환은 열당 2명 제한과 능력 발동 조건을 표시한다.
- 기본 카메라는 현재와 다음 2층, 전체 지도는 내부 스크롤, 결전 카메라는 마지막 3층. 그래프나 시드를 변경하지 않는다.
- 모바일에서는 지도와 하단 상세 시트를 세로로 분리해 겹치지 않게 했으며, 전체 지도·확정 버튼·군단·기록에 접근할 수 있다. 실제 기기 배치는 미검증이다.

## 이동·정보·저장

선택은 원정 상태를 변경하지 않는다. 미리보기는 structuredClone 후 실제 moveTo를 호출한다. 군량·병력·통행 협정·의무·관계 변화는 실제 엔진 결과를 읽는다. 성장 캠프가 이동을 가로채면 비용 0과 먼저 성장해야 한다는 안내를 표시한다. 무작위 선택 후보와 사건 결과는 공개하지 않는다.

기존 공개 정보인 유형·지형은 유지한다. 다음 이동 가능 거점과 현재 거점에서는 편성을 표시하고, 먼 미래에서는 부분 확인으로 표시한다. 보스의 기존 공개 특성은 초기부터 볼 수 있다. 새 유료 정찰이나 거짓 지도 특성을 추가하지 않았다.

진군은 버튼에 표시된 현재 층과 선택 좌표를 다시 확인한 뒤 한 번 처리한다. 상태와 저장을 먼저 반영하고 이동 피드백을 재생하므로 건너뛰어도 결과가 같다. 이동 연출은 확정 직전 현재/선택 거점의 실제 화면 좌표를 읽어 같은 곡선으로 군기 레이어를 재생한다. 상태 반영은 연출보다 먼저 끝난다. 화면 전환과 겹치는 군기 피드백의 실제 시각 품질은 미검증이다.

새 mapTrail은 실제 방문 좌표만 저장한다. 이전 저장에 필드가 없으면 그대로 허용하고 과거 경로를 추정해 채우지 않는다. 선택 노드와 대비·속도는 별도 UI 저장 키에 보관한다. 원정 버전 5 및 버전 1~4 변환 흐름은 유지한다.

## 연결선과 레이아웃

층별 6가지 열 순열을 동적 계획법으로 비교해 조합상 교차가 최소인 결정론적 좌표를 선택한다. 열 식별자·실제 간선·RNG는 보존한다. 방문은 굵은 실선, 현재 가능한 길은 옥색, 선택 이후는 점선, 미래는 가는 먹선이며 호버·포커스 시 인접 간선만 강조한다. 의무 관련 선은 별도 점선 패턴을 사용한다.

현재 기본 그래프는 이미 교차 최소 순서인 경우가 많고, 61001 완전 연결 지도는 순열만으로 교차 수를 줄일 수 없다. 교차 수가 반드시 감소했다고 보고하지 않는다. 기본 3층 카메라와 선 계층으로 한 번에 보이는 혼잡도를 줄였다. 실제 시각 혼잡 감소는 사용자 확인이 필요하다.

## 접근성

Tab/Enter 선택, 화살표로 이동 가능 거점 순회, Escape 취소, 명시적 포커스, 상태·유형·비용·보상 이름을 제공한다. 서랍은 dialog/aria-modal과 Tab 순환을 제공한다. 고대비, 보통/빠름/끄기, prefers-reduced-motion, 연출 건너뛰기를 지원한다. 텍스트 확대 시 카드와 상세는 줄바꿈/내부 스크롤을 사용한다. 픽셀 단위 겹침·화면 확대는 브라우저 미검증이다.

## 검증

실제 브라우저 접근·재시도·보안 설정 변경은 하지 않았다. DOM 검증은 실제 브라우저 시각 검증이 아니다.

- 규칙: 100개 시드의 유효 경로·고립 없음·결전 연결·동일 시드/좌표·교차 비증가, 정확한 비용·통행·군량 부족·지원, 성장 선행, 부분 정보, 의무 좌표, 불변 미리보기, 새/기존 저장, 잘못된 방문 경로 거부.
- DOM: 실제 번들에서 선택/취소, 키보드, 상태 불변, 선택 저장 복원, 서랍, 설정, 진군 1회, 오래된 버튼 중복 입력 방지. 기존 대결·설전·외교·성장 통합 테스트도 두 단계 진군으로 갱신했다.
- 전체 `npm test`: 180개 통과, 실패 0 (기존 172 + 지도 규칙 7 + 지도 번들 DOM 1). `npm run build` 성공. 원시 결과는 verification/map-final-test.log와 map-build.log를 기준으로 한다.
- 정적 화면 자료는 실제 렌더러에서 생성한 DOM fixture이며 스크린샷·픽셀 QA 결과가 아니다.

## 사용자 실행 및 체크리스트

Node 22.18 이상. package.json이 있는 폴더에서 npm ci, npm run dev. 터미널의 실제 Local 주소를 브라우저에 입력한다. 61001은 군주 선택의 '설전 덱 원정 · 곽가 (61001)' 전용 버튼으로 시작하고 교리를 고른다. 일반 시드 입력 71001과 조조로 시작하면 기존 일반 지도의 서로 다른 유형·지형 경로를 비교할 수 있다. 숫자 61001 입력만으로 전용 지도는 적용되지 않는다.

1. 출발 군영과 다음 이동 가능 3거점을 식별한다.
2. 거점을 선택해도 군량이 줄지 않고, 취소하면 선택만 해제되는지 확인한다.
3. 세 경로 비용·지형·보상·위험이 같은 화면에서 비교되는지 확인한다.
4. 확인 버튼을 눌러 미리보기 군량과 실제 값이 같은지 확인한다. 성장 선행 화면이면 이동 비용이 없고 성장 후 다시 이동한다.
5. 61001 상단 협정과 향촌 호송을 체결하고 5층 보급/6층 전투 의무 인장을 확인한다. 의무를 이탈하는 선택의 경고도 확인한다.
6. 다음 이동 가능 거점의 편성과 먼 미래의 부분 확인을 비교한다.
7. 전체 지도, 현재 위치, 결전 보기, 기록 필터, 군단 배치/열 가득 참을 확인한다.
8. 선택 후 새로고침/이어하기: 원정 수치와 선택 복원. 이동 후 새로고침: 방문 표시와 자원 복원. 기존 저장의 과거 경로가 임의로 생성되지 않는지 확인한다.
9. 1920×1080/1366×768/820×1180/390×844/360×640, 브라우저 확대 150%/200%, 고대비·연출 감소에서 버튼·텍스트·시트·노드 겹침을 점검한다.
10. 콘솔 오류와 화면 문제를 아래 양식으로 기록한다.

기록 양식: 버전 / 접속 주소 / 시드·진입 버튼 / 화면 크기·확대율 / 층·경로 / 재현 순서 / 예상 / 실제 / 콘솔 오류 원문 / 스크린샷 / 저장 복원 결과.

## 임시 미술과 남은 작업

임시 지도는 repo-native SVG다. 상용 수준 최종 원화·기기별 픽셀 QA·모바일 터치 정확도·군기 연출의 실제 시각 품질은 완료 주장에 포함하지 않는다. 정보 공개는 현재 공개 데이터의 UI 계층이며 별도 정찰 획득 시스템은 추가하지 않았다. 여러 지역·새 특별 간선·보스 변형은 이번 수직 단면에서 확장하지 않았다.

최종 아트 사양: 세로 1800×2500 원본, 좌우 8% 장식 안전영역, 가운데 84% 노드 영역, 배경/도로/하천/전경/조명/안개 분리, 모바일 900×1600 중심 크롭, 런타임 WebP 구역당 500KB 목표, SVG fallback. 현재 낙양 시나리오와 다른 지명을 확정 지리로 쓰지 않는다. 먼저 데스크톱·모바일 실제 플레이의 가독성을 확인한 뒤 최종 원화와 지역 확장을 진행한다.
