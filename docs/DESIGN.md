# 천하군진(天下軍陣) — 짧은 게임 설계서

> 삼국지 장수 조합형 덱빌딩 로그라이트. 이 문서는 프로토타입(v0.1)의 설계 판단을 기록한다.
> 인물의 성격·능력은 게임적 해석이며 역사 고증이 아니다. 사건은 “가상 전개” 또는 “역사 모티프”로 표시한다.

## 1. 핵심 설계안 3종 비교

| | A안 진형 지휘 (채택) | B안 장수 카드 덱 | C안 진형 족보 |
|---|---|---|---|
| 구조 | 장수는 전열/후열(2×2)에 상주하는 **규칙**, 전법 카드는 매 턴 쓰는 **명령**. 적은 의도에 **공격할 열**을 표시 | 장수를 영입하면 그 장수 전용 카드 3장이 덱에 섞임. 장수 자체는 패시브 1개 | 매 턴 장수 카드를 진형 칸에 놓아 족보(같은 세력·병종 등) 점수로 공격 |
| 재미의 선명함 | 상 — “어느 열을 막고, 어떤 장수 조건을 켤까”가 매 턴 분명 | 중 — 덱빌딩 위주, 장수 정체성은 카드에 묻힘 | 상 — 점수 폭발은 강렬하나 적 의도 대응이 약해짐 |
| 삼국지다움 | 상 — 진형·전열/후열·책사 후방 배치·계책으로 적 공격 돌리기 | 중 — 장수 이름 붙은 카드 게임이 되기 쉬움 | 중 — 세력 족보는 유명 조합 편중 위험 |
| 구현 난이도 | 중 | 하 | 중상 (족보 표·점수 균형) |
| 확장성 | 상 — 장수·카드·지형이 서로 독립적으로 늘어남 | 중 — 장수마다 카드 3장씩 필요 | 중 — 족보가 늘수록 조합 폭발 관리 어려움 |

**추천: A안.** 장수(누가·어떤 조건에서)와 전법(무엇을·언제)의 역할이 겹치지 않고, Into the Breach식 “보이는 위협에 대응하는 판단”과 Monster Train식 “배치 위치가 능력을 바꾸는 구조”를 삼국지의 진형·책사·계책으로 자연스럽게 옮길 수 있다. B안은 장수 영입이 덱 희석으로 끝나고, C안은 Balatro의 점수 쾌감은 크지만 “적의 의도를 계책으로 뒤집는” 핵심 재미 3번을 살리기 어렵다.

## 2. 먼저 해결한 설계 문제

- **A. 매 턴 가장 중요한 결정** — 한정된 지휘력(3)을 “적이 노리는 열을 막기 / 공격 / 의도 조작” 중 어디에 쓸지. 적 의도가 열(전열·후열·양 열)을 지정하므로 방비 카드 한 장도 어느 열에 쓸지 고민이 생긴다.
- **B. 장수와 전법의 차이** — 장수는 뽑히지 않는다. 진형에 상주하며 “카드를 쓴 뒤”, “열이 공격받을 때”, “적이 쓰러질 때”에 반응하는 규칙이다. 전법은 소모되고 순환하는 행동이다.
- **C. 중복 방지** — 장수는 덱의 **어떤 카드가 가치 있는지**를 바꾼다(전위가 있으면 방비가 반격이 되고, 방통이 있으면 화계가 2배가 된다). 카드 보상 3장 중 1장은 장수 성향에 맞춘 카드로 뽑아 두 축이 서로를 끌어당기게 했다.
- **D. 소재가 바꾸는 규칙** — 전열/후열 진형(책사는 후열, 맹장은 전열), 후열 피습 시 책사 동요, 계책(허보·이간계·교란)으로 적 의도 변경, 군량이 이동·회복·시장 화폐를 겸함, 지형 4종이 수치 규칙을 바꿈.
- **E. 강한 조합이 보이는 방식** — 로그와 장수 패널이 연쇄를 그대로 보여 준다: “여포: 기세 4! 창격의 피해를 한 번 더”, “육손: 불길이 번진다”, “전위 3 + 남은 방비 절반 6 = 9 반격”. 숫자뿐 아니라 **발동 장면**이 늘어난다.
- **F. 패배 원인 이해** — 모든 피해는 계산식(기본+가산×배수−방비)으로 로그에 남는다. 패배 화면은 피해 출처 상위, 전열/후열 피해 비교, 자기 능력(여포 불만·황개 고육계)으로 잃은 병력을 정리하고 대응 힌트를 준다.
- **G. 운이 나빠도 대응할 수단** — 다음 행동은 항상 공개(숨기는 적 없음), 카드 사용 전 미리보기, 열별 예상 피해 표시, 지도에서 적 편성·지형을 미리 확인, 보상 건너뛰기(군량 +2), 카드 제거(휴식·시장), 장수 재배치(지도 무료/전투 지휘력 1).

## 3. 구조와 통합·삭제한 요소

| 요소 | 역할 | 비고 |
|---|---|---|
| 군주 | 시작 장수·시작 덱·운영 규칙 | 조조: 영입 후보 +1, 장수 2명 이상이면 지휘력 +1, 첫 교대 무료 / 손권: 한 턴에 武·防·策 모두 쓰면 지휘력 +1 |
| 장수(최대 4, 열당 2) | 상주 능력, 열 조건 | 통솔·무력·지력 등 능력치는 **삭제** — 판단에 쓰이지 않음 |
| 전법 카드 | 武(공격)·防(방어)·策(계책) + 태그(기병·화공·계책) | 병종은 독립 시스템 대신 **카드 태그**로 통합 |
| 보물 | 원정 내내 지속되는 규칙 변경 10종 | 군사 교리와 보물을 하나로 통합 |
| 병력 | 원정 체력 | 전투 간 유지 |
| 군량 | 이동 비용·휴식·시장 화폐·징발 | 금(돈)을 **군량에 통합** — 모든 경제 선택이 같은 자원을 놓고 경쟁 |
| 지휘력 | 전투 중 카드 비용 | 매 턴 3 |
| 기세 | 이번 턴에 쓴 카드 수 | 사기 시스템을 **턴 단위 연쇄 카운터로 축소** (여포·돌격·무장 대결·전고가 사용) |

## 4. 전투 규칙 요약 (구현: `src/core/combat.ts` 머리말)

- **카드 처리**: 지휘력 지불 → 기세 +1 → 효과를 적힌 순서대로(대상이 쓰러졌으면 그 효과는 무효, 로그 기록) → 장수 능력(전열→후열, 배치 순) → 군주 규칙 → 버림패/소멸.
- **재발동**: 여포는 피해 효과만 한 번 더 처리하며, 재발동이 다시 장수 능력을 부르지 않는다.
- **적 턴**: 왼쪽부터 방비 소멸 → 화상 피해(방비 무시) 후 화상 −1 → 혼란이면 행동 취소 → 의도 실행 → 그 열의 반격.
- **사망 처리**: 즉시 쓰러짐 → 남은 화상 기록 → (보스면 나머지 도주) → 육손 확산 → 장료(기병 처치 보상) → 승패 판정. 연타 중 공격자가 쓰러지면 남은 타격 취소.
- **무한 방지**: 지휘력·카드 획득 능력은 모두 턴당 횟수 제한(곽가 1, 장료 2, 손권 1, 전고 1). 징발은 군량, 고육계는 병력이라는 유한 자원을 쓴다. 추가 안전장치로 한 턴의 처리 예산(400)을 넘으면 연쇄를 멈추고 경고한다. 강한 조합 자체(여포 재발동, 방통 2배)는 상한 없이 둔다.

## 5. 빌드 방향 6종

| 빌드 | 핵심 원리 / 구성 | 완성 전 약점 → 완성 후 장면 | 섞임 / 어려운 적 / 대체 |
|---|---|---|---|
| ① 방어·반격 ✅ | 전열 방비를 반격으로 전환. 전위(반격 3+남은 방비 절반), 조인(방비 이월), 학소(반격마다 방비), 반격 태세·철벽·수성·역습 | 공격력 부족, 느림 → 동탁의 강타를 철벽으로 받고 남은 방비로 반격 10+, 다음 턴 역습으로 방비만큼 일격 | 화공(방어하며 화상 누적) / 후열을 노리는 서량 기병, 공격하지 않고 강화하는 술사 / 조인 대신 철갑 보물, 전위 대신 반격 태세 다수 |
| ② 화공·지속 피해 ✅ | 화상 누적·증폭·확산. 황개(화공마다 화상 3, 병력 −2), 방통(전원 화상이면 2배), 육손(사망 시 확산), 정보(화상 대상 +2), 화계·동남풍·유황 투척 | 즉발 피해가 낮아 초반 위험 → 화계 → 동남풍 → 한 마리가 쓰러지며 불길이 번져 적진 전체가 연쇄 붕괴 | 계책(혼란으로 시간 벌기) / 장보(요술로 화상 제거), 하천 지형(화상 절반), 동탁 2단계(화상 털어냄) / 기름 항아리 보물 |
| ③ 기병·기세 ✅ | 한 턴에 많은 카드 → 기세 → 폭발. 여포(3번째 武부터 재발동, 기세<3이면 병력 −3), 장료(기병 처치 시 지휘력+카드), 마초, 돌격·무장 대결·추격·철기 돌파·군령·징발 | 손패가 나쁘면 여포 불만으로 자해 → 군령·징발로 카드 6장, 여포 재발동 돌격이 기세×2씩 커지며 장료가 처치마다 지휘력을 되돌림 | 군량 운영(징발 연료) / 방패병(높은 방비), 성채 지형 / 공성추로 방비 제거, 서량마 |
| ④ 계책·의도 조작 ✅(부분) | 적 의도를 바꿔 피해를 0으로 만들고 적끼리 싸우게 함. 곽가(계책 시 지휘력+카드), 진궁(策 후 武 강화), 허보·이간계·교란 | 계책 카드는 직접 피해가 없어 느림 → 동탁의 공격을 이간계로 친위병에게 돌리고, 허보로 방비 쌓인 열로 유도 | 방어(유도한 열에서 반격) / 단일 보스(이간 대상 없음), 양 열 공격(허보 불가) / 교란 다수 |
| ⑤ 군량 운영·장기전 (설계만) | 군량을 전투 자원으로 전환. 징발·둔전책·고육계 + (예정) 군량 소비로 강해지는 장수 | 이동 군량 부족 → 시장·보급을 오가며 징발로 매 턴 지휘력 5 | 기세(지휘력 연료) / 긴 산길 경로 / — |
| ⑥ 연계 혼합(손권) ✅(군주 규칙) | 武·防·策을 한 턴에 섞어 쓰면 지휘력 +1 | 한 계열만 들고 오면 발동 안 함 → 매 턴 4 지휘력으로 방비·화공·공격을 동시에 | 모든 빌드의 접착제 / 손패 편중 / 군령으로 손패 보정 |

유명 장수 편중 방지: 학소·조인·정보처럼 덜 알려진 장수가 각 빌드의 엔진이고, 여포는 강하지만 불만 페널티로 빌드를 강제한다. 세력 시너지는 두지 않았다 — 위의 전위와 오의 황개가 한 진형에서 섞인다.

## 6. 원정

- 8층 지도(층마다 3갈래, 인접 칸으로만 진군) + 결전. 노드: 전투·정예·장수 영입·시장·휴식·보급·사건·결전.
- 이동마다 군량 1(산길 2). 군량이 모자라면 부족분 1당 병력 −5.
- 지형: 평야(기병 피해 +3), 산길(이동 2, 적의 후열 공격 +2, 매 턴 첫 策 비용 −1), 하천(화상 부여 절반, 방비 +2), 성채(적 방비 10 시작, 승리 군량 +4).
- 사건 6종은 모두 기회비용 선택: 군량↔장수, 군량↔저주 카드, 원군↔보상 축소, 병력↔보물, 병력↔저주 카드, 군량↔카드 복제.

## 7. 반복 플레이와 해금

- 실패 시 덱·장수·자원 초기화. 영구 기록: 원정 수·승리 수·함께 싸운 장수(도감).
- 첫 승리 해금: 장수 진궁·마초, 난이도 「험로」(적 체력 +20%, 시작 군량 −3). 기본 능력치를 올리는 영구 강화는 없다.
- **카드 풀 희석 대책**: 보상 3장 중 1장은 현재 장수 성향(계열·태그·시너지 표기)에 맞는 카드에서 뽑는다. 해금 장수는 기존 빌드를 대체하지 않고 새 축(계책→공격, 기병 기세)을 연다. 앞으로 해금이 늘면 “원정 시작 시 이번 원정에 쓸 카드 묶음 선택”을 도입한다.
