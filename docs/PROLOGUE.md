# 도시 탐색과 인재 카드로 만드는 거병

2026년 10월 10일 구현. 새 천하 캠페인은 주인공이 도시를 탐색하며 인재와 협력하고, 개인 카드를 선택해 거병 덱을 만드는 방식이다. 기존 설전·대결·도시·원정 엔진을 이어 사용한다. 현재 캠페인의 끝은 하남 세 도시의 지역 패권이며 전국 통일은 구현 범위 밖이다.

## 시작과 탐색

시작 화면에서 거병 대표, 보좌, 교리, 특전과 고정 10장 덱 선택을 제거했다. 시나리오·주인공·도시·출신만 고른다. 주인공은 캠페인 정체성으로 유지되며, 최종 관문의 대표와 별도다.

| 주인공 | 기본 원칙과 방향 | 약점 |
| --- | --- | --- |
| 진궁 | 약속 사용 후 명분 1, 신뢰 초기 30 | 군사 기반 부족 |
| 장료 | 군사 사용 후 훈련 1·노출 1, 신뢰 초기 25 | 노출과 관계 관리 |
| 곽가 | 정보 사용 후 다음 경로 공개, 신뢰 초기 25 | 직접 병력 생산 부족 |

원칙은 장소당 1회다. 출신은 재야 명사·향촌 의용군 지도자·지방 관리 3종이다. 형양·성고·공현 선택을 유지하며, 도시별 초기 군량과 도시 카드가 다르다. 인재 사건의 완성 단면과 고정 시드 안내는 형양 기준이다.

시작 거병 덱은 7장이다.

- 공용 수단 4장: 격문 배포, 사재 출연, 수비 교대 조사, 곡물 매입
- 출신 1장: 인망의 추천 / 의용군 모집 / 구관료 소개
- 도시 1장: 공동 창고 / 성문 확보 / 곡물 수레
- 출신 부담 1장: 빈 장부 / 흩어진 향병 / 근거 없는 소문

대표 고유 카드와 보좌 카드는 미리 지급하지 않는다. 카드 소유권은 정의와 인스턴스에 기록한다. 기존 원정의 공용 전투 기본 덱은 도시 창설 후 전투 엔진의 기반으로 유지되며, 거병 중 사용하는 덱은 위 7장부터 별도로 구축한다.

준비는 6단계, 단계마다 세 장소 중 하나다. 향촌·시장·객사·병영·장원·관청·창고·서신망·도적 소굴·빈 군영·나루 등 8종 이상의 기존 장소를 사용한다. 시드로 인재와 장소를 배치하고, 소문 → 위치 단서 → 직접 만남 → 요구 확인 → 완전 파악으로 공개한다. 방문 전 이름과 고유 카드를 숨긴다. 위험·예상 계열·접촉 비용과 기회를 지도에서 확인한다. 정보 카드가 다음 위치 단서를 공개한다.

## 인재와 카드

주요 인재 5명, 일반 인재 3명이다. 각 역할에 공용 카드 2장씩 총 12장, 각 인재에 고유 카드 2장·지원 카드 1장, 합동 카드 4장을 정의했다. 기존 거병 카드 40장과 새 인재·합동 카드 40장이 공존한다. 기존 보상 추첨에서 새 고유 카드를 뽑을 수 없게 했다.

| 인재 | 역할 | 고유 카드 선택지 | 참여 중 원칙 |
| --- | --- | --- | --- |
| 전위 | 군사 지도자 | 철위의 결집 / 퇴로의 호위 | 첫 개인 군사 카드 후 준비력 1 회복 |
| 조인 | 행정·수비 | 성문 정비령 / 수비대의 공론 | 첫 개인 명분 카드 후 노출 2 감소 |
| 정보 | 상단·물류 | 노장의 호송 / 분산 군량망 | 첫 개인 물자 카드 후 1장 뽑기 |
| 순욱 | 명망·행정 | 왕좌의 인선 / 공론의 장부 | 첫 개인 인맥 카드 후 다음 장소 공개 |
| 노숙 | 외교·중재 | 양측의 계산 / 이면의 약정 | 첫 개인 정보 카드 후 자금 1·채무 1 |
| 향촌 훈련관 | 지역 군사 | 향병의 교대 / 향촌의 방진 | 첫 개인 군사 카드 후 준비력 1 회복 |
| 하남 서리 | 지역 행정 | 보존된 호적 / 문서의 효력 | 첫 개인 명분 카드 후 다음 장소 공개 |
| 나루 중개인 | 지역 물류·중재 | 사공의 신용 / 나루의 우회 | 첫 개인 군자금 카드 후 1장 뽑기 |

인재별 역할 공용 2장과 고유 카드 효과·성장 후보·지원·내정·전투·설전 전환은 `src/data/personnel.ts`에 있다. 일반 인재에게도 고유 카드, 성장, 합동 사건이 있으며 향촌 훈련관은 정보와 군량 선대를 만든다.

접촉은 인물을 드러낼 뿐 카드를 주지 않는다. 준비력 1과 표시된 자원으로 부탁을 한 번 수행한 뒤, 임시 지원 / 카드 대신 신뢰 / 거절 중 하나를 선택한다. 임시 지원을 실제 사용하거나 관계 선택으로 협력 실적을 쌓고 신뢰 45·자금 1을 충족하면 등용한다. 고유 카드 두 후보 중 하나와 역할 카드 하나만 보관함에 해금한다. 손패에 자동으로 섞이지 않는다.

인재 화면은 인물·관계와 원칙·성장·카드 보관함·공동 사건을 접고 펼치는 구역으로 나눴다. 손패에서 개인 소유자와 비용을 표시하고, 선택 카드와 관련된 인재를 강조한다. 미리보기는 실제 처리 함수에 복제 상태를 전달하며 신뢰·경험·피로 변화까지 표시한다.

## 신뢰와 충성 및 성장

신뢰는 부탁·협력 실적·반대 카드에 반응하고 등용·합동 조건에 사용한다. 충성은 세력 교리와 휴식 등에 반응하고 개인 카드의 비용과 추가 효과를 바꾼다. 입력 후 무작위 거부나 카드 핵심 효과 실패 확률은 없다.

| 조건 | 확정 결과 |
| --- | --- |
| 충성 40 미만 | 개인 카드 비용 +1 |
| 충성 40 이상 | 기본 비용 |
| 충성 75 이상 | 거병 카드 사용 후 지지 +1 |
| 신뢰 40 미만 | 거병 개인 카드 사용에 자금 1·채무 1 추가 |
| 피로 4 이상 | 개인 카드 비용 +1 |
| 인재가 반대하는 카드 사용 | 기본 효과 적용, 해당 동행 인재 신뢰 −10 |

반대 카드와 대가는 인재 상세와 실제 미리보기로 확인한다. 인재 카드 사용은 경험과 거병 피로를 쌓고 다음 장소에서 피로가 1 감소한다. 전투 종료·실제 내정 카드·설전·외교 지원도 인재 사용 기록과 경험으로 연결했다.

경험 2에서 성장 분기를 한 번 선택한다. 숙련은 역할 카드 교체·정론 강화·피로 2 감소, 권한은 역할 카드 교체·광포 강화·권한 공유 의무다. 덱과 보관함의 카드 수가 늘지 않는다. 숙련은 중용, 권한은 핵심 인재 단계로 기록한다. 분기 선택은 반복할 수 없다.

## 보관함과 활동 편성

개인·세력·도시·임시·약속·소모 소유권을 구분한다. 동행은 최대 3명, 거병 덱은 최소 6장·최대 14장, 활동별 개인 카드 슬롯은 최대 6장, 인재 한 명당 활동 카드 최대 2장이다. 합동 카드도 두 소유자의 슬롯을 각각 차지한다.

카드를 덱에서 빼도 보관함·등용 상태·관계는 남는다. 활동 중 손패 교체는 막는다. 소멸한 카드를 제외했다 다시 넣어도 소멸 기록을 유지한다. 개인 카드를 복제하거나 공용 카드에 전수하여 소유권을 없앨 수 없다. 개인 성장·편성은 인재 화면에서 관리한다.

| 현재 배치 | 활성 활동 |
| --- | --- |
| 거병 동행 | 거병 개인 카드·원칙·합동 카드 |
| 군단 후보 및 원정 군단 | 선택한 전투·설전 카드, 전략 단계 외교 지원 |
| 도시 근무 | 그 도시에 선택한 내정 개인 카드 |
| 대기·휴식·임무 | 군단과 도시 개인 카드 비활성 |
| 협력 종료 | 카드 기록은 남고 모든 개인 활동 비활성 |

도시 임명과 군단 복귀의 기존 비용·행동력·진형 제한을 유지한다. 휴식과 탐문은 대기 인재와 전략 행동력 1을 사용하고 다음 캠페인 턴에 완료한다. 휴식은 피로 해소·충성 5, 탐문은 명망·경험 1이다. 인재가 소속되지 않은 도시나 군단에 개인 카드만 남는 것을 막으며 실제 카드 더미를 초기화하지 않고 필요한 사본만 동기화한다.

## 합동 사건과 거병

합동 카드에는 두 인재의 신뢰 45, 정식 등용, 동행, 협력 실적과 군량 2를 지불하는 공동 사건이 필요하다. 숫자만 맞춰도 자동 생성되지 않는다.

| 합동 카드 | 인재 | 거병 효과 |
| --- | --- | --- |
| 허실상응 | 노숙·전위 | 정보 2·훈련 1·준비력 1 |
| 공론과 문서 | 순욱·하남 서리 | 명분 3·인맥 2·노출 −1 |
| 군량 선대 | 정보·향촌 훈련관 | 군량 5·병력 3·채무 2 |
| 이면 합의 | 노숙·나루 중개인 | 정보 2·인맥 2·최종 집중 1 |

최소 세 장소 이후 최종 계획으로 이동할 수 있다. 보통 여섯 장소를 마치고 주인공 또는 발견·신뢰·등용한 동행 인재를 대표로, 다른 참가자를 보좌로 확정한다. 최종 정론 강화는 전체 한 번이다. 카드 편성·약속·책략과 준비도를 비교한 뒤 실제 관문에 들어간다.

민회와 격문은 설전, 군영 장악은 대결, 성문 내응은 설전과 필요시 대결이다. 준비 카드가 실제 설전 논거와 대결 전술에 반영된다. 보좌는 설전에 임시 신뢰 논거 한 장, 군사형 보좌는 대결 상대 체력 3 감소를 제공한다. 실패·조건부 합의의 실제 군량·병력·부채·약속은 기존 장부에 남는다.

## 창설 후 이어지는 캠페인

성공 결과에서 정식 교리 민본·법도·군략을 선택한다. 군략은 군사 인재 충성 10 증가·다른 인재 10 감소, 민본·법도는 그 반대다. 이는 신뢰와 별개다.

임시 지원은 창설 시 만료된다. 개인 카드는 보관함에 남고 활동별 편성을 해야 사용한다. 전투에서는 전법, 설전에서는 논거, 내정에서는 명령으로 기존 규칙에 연결하며 소유자 표시와 충성·피로 비용을 유지한다. 도시 카드는 시작 도시에서만 활성화한다. 약속·채무는 도시·세력 의무에 남는다. 거병 책략은 첫 도시의 3턴 정책으로 최대 두 개 전환하며 담당 장수가 필요하다.

외교 지원으로 선택한 개인 카드 중 최대 두 장은 계약 체결 후 상단 신뢰를 1씩 높인다. 같은 카드의 지원은 턴당 1회이며 소유 인재가 군단에 있어야 한다. 권한 성장은 실제 권한 의무를 만들지만, 별도 파벌·후계 정치 시스템을 완성한 것은 아니다.

## 저장과 악용 방지

캠페인 저장 봉투 버전 7을 유지하고 선택적 `personnel.version = 1`을 추가했다. 이전 10장 거병 저장과 이전 도시·원정 저장은 기존 방식으로 계속하며 인재 관계를 임의로 만들어 덮어쓰지 않는다. 새 캠페인만 탐색형으로 시작한다.

원본 저장 바이트를 보존하면서 잘못된 관계 수치·중복 카드·조작된 소유자·인재 위치·개인 카드 사본 참조를 거절한다. 미리보기는 원본과 RNG를 건드리지 않는다. 부탁·협력·등용·성장·공동 사건·창설·외교 지원에는 각각 반복 방지 조건이 있다. 대표 교체로 공용 원형 카드가 누적되는 기존 문제도 고쳐 대표 소유로 관리한다.

## 검증과 범위

규칙 테스트와 JSDOM 버튼 테스트는 자동 검증이다. 실제 브라우저·데스크톱·모바일의 화면 배치·사용자 재미는 미검증이다. 사용자 요청대로 브라우저 정책 우회·재시도·관리자 설정 변경은 하지 않았다.

실행 로그와 자동 정책 상세는 `docs/verification/prologue.json` 및 배포 ZIP의 `verification`에 제공한다. 주인공 선택부터 만남·지원 카드·등용·편성·성장·대표·보좌·정제·실제 설전·창설까지 DOM으로 검증했다. 규칙 테스트는 도시 배치·실제 내정 카드 사용·군단 복귀·첫 출진·저장 복원과 개인 카드 악용 방지까지 포함한다.

자동 플레이는 시드 131001~131008, 관계·군사·정보·소형 덱·일반 인재·합동·변형 경로 7정책을 비교한다. `random`은 경로 변형 정책이며 모든 행동을 무작위로 누르는 초보 플레이가 아니다. 성공에는 조건부 창설도 포함한다. 높은 성공률은 재미나 난이도가 적절하다는 근거가 아니다. 인재별 편성·사용에는 임시 지원 실적이 포함되고 합동 사용은 두 참여자의 실적으로 집계한다.

남은 범위는 전국 통일, 포로·타 세력 이적·도시 간 장거리 이동, 별도 파벌·후계, 인재별 장편 다중 사건, 고유 인물 원화 8명의 추가 제작과 사람에 의한 밸런스·화면 검증이다. 현재 첫 단면의 부탁은 인재별 비용·목표가 다른 단회 사건이고, 성장은 두 공통 분기다. 이러한 제한을 확장 완료로 보고하지 않는다.
