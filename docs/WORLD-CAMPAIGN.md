# 천하군진 통합 캠페인 구현과 검증

2026-10-09 기준. 이번 구현은 190년 하남의 형양·성고·공현을 사용하는 첫 통합 캠페인이다. 전국 지도의 역사 지명 맥락을 재사용하지만, 실제 정벌·운영 대상은 세 도시다. 전국 통일 완성판으로 보고하지 않는다.

## 기존 구조 분석과 통합 방식

| 기존 문제 | 이번 변경 |
|---|---|
| 단일 원정과 도시 캠페인 진입 분리 | 본편 버튼 하나, 이전 단일 원정은 접힌 원정 도전 메뉴 |
| 원정 내부의 도시 상태, 캠페인 저장 루트 부재 | CampaignState를 버전 7 저장 루트로 사용 |
| 매 도시 고정 5단계 내정 | 공통 캠페인 턴, 도시별 정산 영수증으로 한 번만 처리 |
| 출진 시 시작 자원을 새로 설정 | 도시 예비병·식량에서 입력량을 차감, 운송 손실 적용 |
| 장수의 도시·군단 중복 가능성 | 군단·도시 담당·대기 중 한 곳에만 배치, 검증기로 중복 거부 |
| 8층 원정 구조 강제 | 기존 이동 엔진을 사용하면서 정찰 2, 정벌 3~4장면 경로 선택 |
| 점령 후 지도와 운영의 연결 부족 | 도시 소유권·실제 운영 장부·보급 연결에 동시 편입 |
| 경쟁 세력의 행동과 비용 부재 | 유한 재고·모병 비용·출병 비용·예고된 공격을 공통 턴에 처리 |

기존 전열·후열 카드 전투, 장수 효과, 설전 덱, 무장 대결, 지역 외교, 도시 행정 카드를 재사용했다. 새 캠페인 화면에서 별도의 새 원정을 시작하는 방식이 아니다. 기존 RunState는 전투·교섭 엔진을 실행하는 내부 어댑터로 남는다.

## 저장과 자원의 주인

CampaignState에는 캠페인 식별자·시나리오, 소유 도시 장부, 장수 명단·피로·임명, 세계 턴·행동력·금고·소유권·관리 방침·준비 상태·인재 단서·경쟁 세력·작전·기록이 있다. activeExpedition에는 기존 엔진이 사용하는 현재 군단 병력·군량·카드·전투·설전·이동 상태가 한 번만 저장된다.

실행 중 activeExpedition은 같은 어댑터를 돌려주는 비열거 참조다. 저장 시 어댑터의 campaign 역참조를 제거해서 순환과 중복 직렬화를 방지한다. UI가 기존 어댑터를 보유하는 것은 엔진 재사용을 위한 것이며 별도 군단 자원 장부는 없다.

| 항목 | 원본 위치와 변경 |
|---|---|
| 세력 금고 | world.treasury, 도시 수입 이전·모병·훈련·외교·출진이 실제 변경 |
| 도시 식량·병력 | CityState.food / reserveTroops, 군단 적재·도시 간 보급·주둔 유지 비용 |
| 출진 병력·군량 | 어댑터 hp / food, 전투 피해·행군·교섭 후 남은 양만 귀환 |
| 준비 자원 | preparation, 창설 시 금고·시작 도시에 이동하고 준비 재고는 0 |
| 인재 | roster, 군단/담당/대기 중 한 곳; 고유 설전 카드·성장 분기는 이동 시 보관 |
| 전체 식량·병력 표시 | 도시 장부의 합계로 계산, 별도 증감 가능한 총량 없음 |

출진 없는 전략 상태에서 군단의 병력·군량은 0이다. 철수·점령 귀환은 작전 ID와 작전 종료 상태로 중복 반환을 막는다. 패전은 잔여 병력 0도 그대로 처리하며 무료 대체 병력을 지급하지 않는다.

## 한 캠페인의 실행 흐름

1. 시작 도시 3종, 재야/소규모 성주, 진궁/장료, 민본/법도/군략, 자금/군량/인재 단서 특전을 고른다. 시작 비용과 약점이 준비 장부에 반영된다.
2. 준비 단계별 행동력 3으로 탐문·후원·군량·모집·민심·거점·감시 회피를 실행한다. 같은 단계에서 같은 행동을 반복할 수 없다. 단계 진행은 군량을 소비하고 노출을 올린다. 5단계 만료 또는 노출 12에서 손실 후 재준비하며 인재 단서는 유지된다.
3. 자금 4, 군량 8, 병력 12, 지지 3, 거점, 인재 2명을 갖추면 거병한다. 관리 협력은 노출 조건, 상단 후원은 추가 자금 조건이 있다. 의병·관리·상단 방식은 도시 덱·준비·부채·관계가 다르다. 성주 시작은 기존 근거지를 받는 별도 시작 조건이다.
4. 세력명·군기 색·목표를 정하고 시작 도시를 지속 운영한다. 목표 표시는 기록되지만 현재 승리 판정은 핵심 도시 점령 또는 종속이라는 공통 지역 판정을 사용한다.
5. 도시의 여섯 구역·행정 덱·정책·인장·시설·집단 관계·약속·담당 장수를 사용한다. 카드 사용만으로 세계 턴이 끝나지 않는다. 도시 담당은 군단에서 제거된다. 이미 업무를 수행한 장수는 같은 턴 배치를 자유롭게 반복할 수 없다.
6. 고정 시드 인재의 단서를 실제 비용으로 얻는다. 단서 2와 안정/주민 관계/명망 중 합류 조건이 필요하다. 후보 목록은 실존 6명과 창작 일반 장수 2명이며 선택한 창업 인물도 이 목록에 포함된다. 후보 8명이 추가 영입 8명을 의미하지 않는다. 경쟁 수비 장수는 별도 창작 인물이다.
7. 도시 예비병을 실제 주민·식량·금고로 모집하고 훈련한다. 인접 목표·정찰/정벌·지형·행군 길이·군량·운송 한도·손실·귀환 거점을 확인하고 출진한다. 병력 상한과 열별 장수 제한은 기존 엔진 제약을 유지한다.
8. 실제 도적 전투, 기존 사절 교섭·설전·협정, 성외 준비와 정벌을 실행한다. 무장 대결 규칙과 카드 엔진도 유지되며 개별 사건 조건에 따라 진입한다. 모든 경로에서 대결이 반드시 발생하지 않는다. 카드·유물·설전 성장·인물 관계를 계속 사용한다. 이전 원정 좌표에 묶인 지역 협정은 새 경로 시작 시 종료 기록으로 보존한다.
9. 성외 준비 두 가지 후 성문 돌파/설득/포위/내부 협력 조건을 고른다. 점령 정책은 안정·피해·관계·도시 덱에 남는다. 경쟁 핵심 도시의 재고는 경쟁 장부에서 제거하고 점령 도시로 옮긴다. 중립 도시의 시나리오 초기 장부는 첫 편입 시 생성된다.
10. 소유 도시를 지도·보급망에 넣고 생존 군단을 귀환시킨다. 직접 통치는 최대 두 도시다. 나머지는 실제 행정 손패와 비용으로 위임 운영한다. 연결된 도시 간 식량 발송은 원본 재고·행동력·운송량·손실을 적용한다.
11. 공통 턴 종료로 도시별 생산·정책·현안·유지·부채·피로와 경쟁 세력을 한 번 정산한다. 적은 유한 자금·식량·주민을 써서 모병·출병하며 공격을 예고한다. 도시 2개 이상, 각 안정 25 이상, 보급 연결, 경쟁 핵심 점령 또는 종속이면 지역 패권에 도달한다.

## 저장 호환

본편 저장 키는 `cheonha-gunjin.campaign`, 외부 버전은 7이다. 내부 RunState 버전 6은 기존 엔진 호환 때문에 유지한다. 단일 원정 키 `cheonha-gunjin.run`은 별도로 보존한다.

이전 도시 캠페인은 제목 화면의 가져오기로 복제·검증한 뒤 새 키에 저장한다. 원래 키를 삭제하지 않는다. 도시·담당·손패·덱·피로·진행 중 활동을 유지하며, 비출진 상태의 이전 군단 잔여 병력·군량은 운영 도시 장부로 합친다. 진행 중 이전 8층 경로는 마무리할 수 있게 보존한다. 단일 원정은 통합 저장으로 강제 변환하지 않는다.

손상·미지원 버전·자원 범위 위반은 변환을 거부하고 실패 이유와 기존 저장 계속하기를 제공한다. 기존 저장 삭제·자동 초기화는 하지 않는다. 브라우저 저장 위치는 서버 주소마다 다르므로 다른 포트·브라우저·file 주소는 동일 저장을 공유하지 않는다.

## 남은 범위와 확장 기반

전국 도시·복수 군단·포로·시대 전환·계절·전국 통일은 미구현이다. 지도 보조 거점 두 개는 맥락 표시에 그치며 별도 점령 규칙이 없다. 경쟁 AI는 유한 전략 재고를 쓰지만 플레이어와 동일한 전체 CityState 행정 엔진을 운영하지 않는다. 현재 소규모 적 공격에서 도시 상실·재탈환 분기는 충분히 검증되지 않았다. 거병 노동자 세부 배치, 군단별 독립 덱 보관, 심화 외교와 승리 목표별 독립 판정도 남았다.

전국 확장은 도시 ID·연결 도로·경로·소유권·정산 영수증·한 번 귀환·인물 배치 검증을 기반으로 진행할 수 있다. 다만 현재 CityId 3종과 단일 어댑터 군단을 일반화하고, 경쟁 세력을 같은 도시 장부 체계로 옮기는 작업이 먼저 필요하다. 아직 전국 완성이 쉬운 데이터 추가만으로 끝난다고 주장하지 않는다.
