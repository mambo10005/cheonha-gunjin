# 천하군진 — 카드 거병 시드 121001 실행 안내

> 이전 시작 방식의 기록입니다. 현재 새 캠페인은 [도시 탐색형 거병](PROLOGUE.md)과 [시드 131001 안내](PROLOGUE-PLAY-GUIDE.md)를 따릅니다. 이전 저장은 이 문서의 기존 규칙으로 계속합니다.


현재 카드 거병의 기본 검증 시드는 **121001**이다. 이전 61001·111001 안내는 이전 기능·준비 규칙을 설명한다. 이 안내의 경로·카드 효과는 현재 코드와 자동 규칙/DOM 검증 기준이며, 실제 브라우저와 사용자 재미는 **미검증**이다.

## 설치와 접속

저장소 폴더에서 Node 22.18 이상을 사용한다. 현재 package.json에 맞는 명령은 다음과 같다.

```powershell
npm ci
npm run dev
```

터미널에 Vite가 출력하는 `Local: http://localhost:.../` 주소를 복사해 브라우저에서 연다. 기본 포트 5173이 사용 중이면 실제 출력 포트가 달라질 수 있으므로 주소를 추정하지 않는다. 서버가 종료되면 접속되지 않는다. 배포 빌드는 `npm run build`, 배포 미리보기는 `npm run preview`다. 이 안내에서는 사용자가 직접 서버와 브라우저를 실행한다. 도구·관리자 정책을 변경하지 않는다.

이전 화면이 나오면 같은 주소에서 새로고침한다. 저장은 브라우저·주소·포트별로 다르므로 복원 확인 동안 같은 주소를 유지한다. 기존 저장이 있으면 이어하기를 먼저 확인하거나 내보내기로 보관한 후 새 캠페인을 시작한다.

## 시작 조합

**천하 캠페인 시작** → 지도에서 **형양** → 시드 **121001** → 대표 **진궁** → 출신 **재야 명사** → 보좌 **전위 호위대** → 교리 **민본** → 특전 **군량 +5 / 자금 −2** → **이 도시에서 기반 마련**.

초기 덱은 10장이다. 전체 거병 덱을 열어 공용 카드·진궁 고유 2장·향촌 카드·호위 카드·부담 카드가 있는지 확인한다. 시작 책략은 민심 규합, 핵심 협력은 전위 호위대다. 시작 장부는 자금 3·군량 13·병력 4·지지 3·명분 3이다. 손패 4장과 전체 덱 10장은 서로 다른 수량이다.

## 6개 준비 장소

다음은 균형 자동 정책으로 확인한 고정 경로다. 카드 선택은 아래 순서를 따라야 같은 더미와 효과를 기대할 수 있다. 다른 사용 순서나 보상을 고르면 후속 손패와 결과가 바뀐다.

| 단계 | 장소 | 사건과 카드 순서 | 보상 |
|---|---|---|---|
| 1 | 향촌 회합 | 신중한 접촉 → 공동 창고 → 진궁의 조건 장부 → 인망의 추천 | 향촌 대표단 협력 접촉 |
| 2 | 객사 | 신중한 접촉. 이 손패에 사용 가능한 논거가 없으면 바로 종료 | 향촌 대표 카드 획득 |
| 3 | 향촌 회합 | 신중한 접촉 → 주민 보호 서약 → 인망의 추천 → 격문 배포 | 기존 카드 강화·제거·개조를 열고 격문 배포 정론 강화 |
| 4 | 빈 군영·정제 | 신중한 접촉 → 공동 창고 → 빈 장부 | 빈 장부 제거 |
| 5 | 빈 군영·정제 | 신중한 접촉 → 사재 출연 → 곡물 매입 → 군영 구령 | 의용군 맹약 책략 획득 |
| 6 | 나루·역참·휴식 | 신중한 접촉 → 향촌 대표 → 불리함 전환 | 카드 받지 않기 |

카드를 누르면 준비력·자원·손패의 실제 규칙 예상이 나온다. **이 카드 사용**으로 확정하고 기록에서 호위 지원·조건의 책임·향촌 협력 등의 원인을 확인한다. 카드를 쓰는 것만으로 단계가 끝나지 않는다. 진행 조건을 채운 다음 **준비 단계 종료·보상으로**를 눌러야 다음 단계가 된다. 보상은 하나만 고를 수 있다.

공동 창고는 군량·지지를 올리고 전위 보좌의 훈련도 발생한다. 주민 보호 서약은 지지·명분을 얻는 대신 향촌 자치 의무를 남기고 런에서 소멸한다. 부담 카드를 제거하고 마지막 카드를 받지 않으면 전체 덱은 11장으로 끝난다. 이 경로에서는 순서 책략 연쇄 횟수가 0일 수 있다. 이것을 책략이 항상 자동 발동한다고 해석하지 않는다.

연쇄를 별도로 확인하려면 **향촌 의용군 지도자·장료·전위**로 새 캠페인을 시작한다. 군량·물자 계열의 수레 다음에 군사 계열의 훈련을 쓰면 의용군 맹약이 발동한다. 반대로 쓰면 발동하지 않는다. 곽가·지방 관리 조합에서는 정보 다음 인맥을 연결해 내응의 문과 생성 카드 효과를 비교한다. 현재 손패와 장소의 사용 계열이 맞아야 실행할 수 있다.

## 민회 설전과 창설

여섯 보상을 마친 뒤 **민회와 격문 → 이 계획으로 관문 시작**을 고른다. 준비 카드의 임시 논거가 기존 진궁 설전 덱에 섞인다. 명분·안전 등 요구 축, 신뢰, 부담을 함께 본다. 요구를 채우지 않은 채 최종 제안을 하면 조건부 협력이나 결렬이 나올 수 있다.

논거를 써도 라운드가 자동 종료되지 않는다. 집중이 부족하거나 상대 반론을 받을 준비가 되었을 때 **라운드 종료·상대 반론**을 누른다. 요구·신뢰를 충족하고 부담 상한 안에 있으면 **현재 조건으로 최종 제안**한다. 추가 공개 반론은 **설전 기록·추가 공개 반론**을 펼쳐 확인한다. 군량 담보 카드는 실제 준비 군량을 소비한다.

**설전 결과 확인** → 결과·남은 장부·약속·전환 예정 확인 → 세력명·군기 색 설정 → **결과를 도시로 이어서 세력 창설**.

위 준비 경로와 균형 설전 자동 정책은 대성공, 금고 6·군량 19·예비병 6·도시 안정 51·진궁과 전위·향촌 자치에 해당하는 공동 운영 약속으로 이어졌다. **자동 규칙 관측값**이며 수동 설전 선택에 따른 결과 보장은 아니다. 준비 카드 사용·담보·최종 제안 순서가 달라지면 잔여 비축과 결과가 달라진다.

도시 카드에는 창고 감찰·향촌 중재, 전투 덱에는 반격 태세, 설전 성장에는 권한 문서가 추가되는지 확인한다. 세계·행동 기록에서 거병 카드별 전환과 시작 자원 출처를 확인한다. 약속은 설명 문구로만 끝나지 않고 도시 의무 목록에 있어야 한다.

## 대결·복합 거병 비교

새 캠페인에서 **향촌 의용군 지도자·장료·전위**를 고르고 병영·창고·군사 보상 중심으로 준비한다. **군영 장악**에서는 대결 대표 선택을 전위로 바꾼다. 시작 기세·방비·획득 전술과 상대 의도를 확인한 후 예상 피해를 비교한다. 대결은 행동마다 상대 행동을 해결하며 최대 4회다. 종료 후 **대결 결과 확인**을 눌러 승리 보너스, 패배 부상·병력 손실, 창설 부담을 확인한다.

**지방 관리·곽가**는 정보·인맥·관청 경로와 **성문 내응**을 비교한다. 설전 완전 협력과 정보 6·인맥 4·노출 12 미만이면 대결 없이 인수한다. 준비가 부족하거나 설전이 불완전하면 상대 지원을 반영한 대결로 이어진다. 설전 성공 뒤 대결을 져도 자동 성공하지 않는다. 이 두 조합의 규칙·대결 DOM은 자동 검증했으며 실제 수동 플레이는 미검증이다.

## 첫 도시와 원정

창설 후 지도에서 형양을 선택한다. **구역·내정 카드·임명·시설**을 열어 진궁을 도시 담당으로 임명하면 진궁은 출진 후보에서 빠지고 전위가 군단에 남는지 확인한다. 카드 예상 → 실제 내정 카드 사용도 비교한다. 군단에 필요한 장수를 모두 도시 담당으로 임명하지 않는다.

금고·인력·식량을 확인하고 **모병**을 1회 한다. 이 조합의 자동 관측 예비병 6명에 실제 모병 12명을 더하면 18명이다. 모병은 금고 2·인력 2·식량 2를 낸다. 첫 검증 출진은 지도에서 성고 선택 → 병력 18·군량 12 입력 → **군단 편성 확정·출진**. 출진 금고 2와 도시 예비병·군량의 실제 차감을 확인한다. 현재 비축이 다르면 그 화면의 비용과 허용 수량에 맞춘다.

이후 기존 전투·설전·외교 경로를 진행한다. 도시 편입과 공통 턴까지 규칙으로 검증했으나 이 안내의 18명 출진이 모든 수동 선택에서 정벌 성공을 보장하지는 않는다. 도시 운영 후 여유 자원·군단 조합을 더 준비할 수도 있다.

## 새로고침 복원

같은 브라우저·같은 접속 주소에서 아래 상태마다 수량과 화면을 기록하고 새로고침 후 이어한다.

1. 장소 진입 후: 손패 UID·준비력·방문 경로·소멸 더미가 같다.
2. 보상 화면: 후보 3장·책략·협력자가 같다. 이미 받은 보상은 다시 받을 수 없다.
3. 설전 또는 대결 중: 라운드·집중/기세·실제 군량·반론·전술 사용 여부가 같다.
4. 결과 직전과 창설 직후: 동일 결과이며 카드·장수·자금이 두 번 지급되지 않는다.
5. 출진 직후: 목표·군단·도시 잔여 비축이 같다. 캠페인 시드가 같고 원정 시드는 달라질 수 있다.

기존 준비 저장은 **현재 준비를 카드 거병으로 전환**을 눌러 시작한다. 기존 자금·군량·병력·지지·장수 보존을 확인한다. 기존 전략·원정 저장에 새 시작 덱을 임의로 추가하지 않는다.

## 화면과 문제 기록

데스크톱에서 준비 지도 좌우 스크롤, 카드 설명·비용·전환 글자, 긴 기록 펼침, 최종 계획 비교와 버튼 가림을 확인한다. 모바일에서는 세로 화면에서 지도만 좌우 탐색되는지, 카드와 보상 버튼 터치가 되는지, 긴 한글·수치·설전 요구·대결 예상이 잘리지 않는지, 새로고침 후 스크롤과 진행이 읽기 쉬운지 확인한다. 브라우저 확대 125%·150%도 비교한다. **실제 화면 점검은 미검증**이다.

브라우저 개발자 도구의 콘솔에서 빨간 오류를 복사하고 다음 양식에 기록한다.

```text
날짜 / 브라우저 버전 / 화면 크기 / 확대율:
접속 주소(포트 포함):
시드 / 도시 / 출신 / 대표 / 보좌:
준비 단계·장소 / 계획 / 활동·라운드:
직전에 누른 버튼·카드 순서:
기대 결과 / 실제 결과:
새로고침 전후 자원·손패·보상 차이:
콘솔 오류 원문:
화면 캡처 / 저장 내보내기 파일:
재현 여부 / 재미·선택 난도에 대한 의견:
```

자동 테스트는 `npm test`, 타입·빌드는 `npm run build`, 153회 규칙 자동 플레이는 `npm run sim:raising`이다. 이 명령들의 통과와 위 사용자 플레이 검증은 별도로 기록한다. 자동 통과만으로 실제 화면·재미를 검증했다고 표시하지 않는다.
