# 시드 131001 도시 탐색형 거병 실행 안내

새 탐색형 캠페인의 검증 시드는 **131001**이다. 아래 경로는 자동 규칙 엔진에서 창설까지 확인했다. 실제 브라우저 화면과 사람이 느끼는 재미는 미검증이다. 카드 사용 순서를 바꾸면 손패·자원·결과도 달라진다.

## 실행

저장소 폴더에서 Node 22.18 이상을 사용한다.

```powershell
npm ci
npm run dev
```

개발 서버가 표시한 `Local` 주소를 직접 연다. 기본 포트가 사용 중이면 Vite가 다른 포트를 출력할 수 있으므로 주소를 그대로 확인한다. 브라우저 정책과 관리자 설정을 변경할 필요가 없다. 자동 검증 명령은 `npm test`, `npm run build`, `npm run sim:prologue`다.

**천하 캠페인 시작 → 진궁 → 형양 → 재야 명사 → 시드 131001 → 이 도시에서 이야기를 시작**을 선택한다. 대표·보좌·교리 선택과 완성 10장 덱 미리보기는 없어야 한다. 거병 덱 7장, 동행 0명, 보관함 7장으로 시작한다. 기존 저장 이어하기는 이전 규칙을 유지하므로 새 흐름은 새 캠페인에서 시작한다.

## 세 사람을 만나기

다음은 합동 카드 경로의 장소와 인물이다. 아직 방문하지 않은 인재 이름은 게임에서 숨겨져 있으며 아래 표는 공략 정보다.

| 단계 | 선택 | 인물 |
| --- | --- | --- |
| 1 | 가운데 향촌 회합 | 향촌 훈련관 |
| 2 | 오른쪽 객사 | 순욱 |
| 3 | 오른쪽 나루·역참 | 정보 |
| 4 | 왼쪽 빈 군영 | 향촌 훈련관 |
| 5 | 오른쪽 빈 군영 | 조인 |
| 6 | 오른쪽 향촌 회합 | 향촌 훈련관 |

처음 만난 세 인재에게 다음 순서로 진행한다.

1. 인재의 부탁과 비용을 읽고 **부탁 수행**을 누른다. 준비력 1과 자원을 지불하며 신뢰가 오른다.
2. **임시 지원 카드 받기**를 고른다. 한 장만 손에 들어오며, 같은 협력 보상을 다시 받을 수 없다. 장소의 인재가 준 임시 카드는 그 장소의 계열 제한과 관계없이 사용할 수 있다.
3. 손패의 지원 카드를 선택하고 실제 예상 결과를 확인한 뒤 **이 카드 사용**을 누른다. 협력 실적과 신뢰·경험이 생긴다. 카드 사용만으로 준비 단계가 끝나지 않는다.
4. 신뢰 45와 자금 1이 있으면 첫 번째 고유 카드 후보로 등용한다. 역할 카드와 고유 카드는 **보관함**에 들어가며 현재 덱 장수가 자동으로 늘지 않는다.
5. 장소 사건을 한 번 해결하고, 남은 준비력으로 필요한 카드를 사용한 뒤 **준비 단계 종료**를 누른다.
6. 보상을 고른 후 다음 장소에 들어가기 전에 **카드 보관함**에서 사용한 임시 지원을 덱에서 빼고, 새 개인 카드 두 장을 편성한다. 인재당 2장·동행 3명 제한을 확인한다.

첫 보상은 책략, 두 번째는 부담 카드 제거, 이후 부족한 자금·군량과 책략을 비교하면 된다. 정보·군량·명분 수단을 모두 빼지 않는 것이 좋다. 약속·차입은 창설 후에도 의무가 남는다.

## 군량 선대와 성장

정보와 향촌 훈련관이 모두 동행·등용 상태이고 각 신뢰 45와 협력 실적을 갖추면, 장소 사이 **함께 만드는 카드**를 연다. 군량 2를 지불하고 **군량 선대 공동 사건**을 해결한다.

보관함에 군량 선대가 해금된다. 두 인재가 각각 두 장을 이미 편성했다면 각자의 역할 공용 카드 한 장씩을 제외하고 합동 카드 한 장을 넣는다. 두 사람 모두 슬롯 하나를 사용한다. 나머지 개인 고유 카드는 유지할 수 있다. 사용 시 군량 5·병력 3·채무 2가 발생한다.

경험 2를 쌓은 인재의 **성장**을 열어 숙련을 선택한다. 역할 카드가 정론 강화된 상위 역할 카드로 교체되며 보관함 장수는 늘지 않는다. 권한 분기는 더 공격적인 강화와 권한 공유 의무를 함께 준다. 자동 합동 경로에서는 군량 선대를 3회 사용하고 성장 2회를 선택해 창설까지 진행했다. 동일한 결과에는 동일한 카드 사용 순서가 필요하다.

## 대표와 보좌를 정하고 거병하기

여섯 장소를 마치면 최종 계획 화면이 열린다. 대표 **진궁**, 보좌 **향촌 훈련관**을 선택하고 **대표·보좌 확정**을 누른다. 이 시점까지 주인공 정체성과 대표는 별개로 유지된다.

보관함에서 한 장을 **최종 정론 강화**한다. 전체 한 번만 가능하다. 명분·지지와 노출을 비교하고 **민회와 격문**으로 들어간다. 준비 카드는 실제 설전 논거로 들어가며 소유 인재 이름이 표시된다.

손패로 공개된 요구·신뢰를 채우고, 집중이 부족하면 **라운드 종료**로 상대 반론을 받는다. 카드를 한 장 썼다고 라운드가 끝나지 않는다. 최종 제안 버튼의 예상 결과를 확인하고 조건을 제시한다. 이 안내는 자동 성공 버튼 순서를 보장하지 않는다. 군영 장악은 실제 대결, 성문 내응은 설전 후 필요하면 대결로 이어진다.

성공 결과에서 **민본** 교리를 선택하고 **세력 창설**을 누른다. 임시 지원은 기한 만료로 표시되고, 등용 인재와 개인 카드·성장·부채·약속은 남아야 한다.

## 도시 배치와 첫 원정

전도의 **인재·활동 카드**에서 사용할 카드에 **전투·설전·내정 덱에 편성**을 각각 지정한다. 미편성 카드는 보관함에 남는다.

형양의 **구역·내정 카드·임명·시설**을 열어 순욱을 민생·기록 담당에 임명한다. 순욱의 군단 카드가 빠지고 선택한 내정 카드가 도시 버림 더미에 들어간다. 다음 뽑기 때 사용할 수 있으며 즉시 손에 주는 방식이 아니다. 도시 근무와 군단은 동시에 할 수 없다.

군단에는 진궁과 향촌 훈련관·정보 등을 두고, 전투·설전 카드를 선택한다. 장거리 이동·포로·전국 통일은 현재 범위 밖이다. 대기 인재의 휴식·탐문은 전략 행동력 1과 한 턴을 사용한다.

원정은 인접 목표 **성고**를 선택하고 도시의 실제 병력·군량·금고를 확인한 뒤 출진한다. 병력 최소 12, 금고 2, 전략 행동력 1과 표시된 이동 군량이 필요하다. 합동 자동 경로의 한 실행에서는 창설 시 금고 9·군량 43·병력 19가 남았다. 이것은 자동 정책 기록이며 사용자의 카드 순서에 따라 달라진다. 부족하면 모병·도시 생산과 정산으로 준비한다.

## 수동 화면과 저장 점검

부탁 직후, 임시 카드 사용 직후, 보상 선택 전, 설전 중, 도시 임명 후 각각 새로고침하고 **천하 캠페인 이어하기**를 선택한다. 인재 단계·신뢰·충성·카드 더미·성장·자원·상대 요구가 같아야 한다. 새 보상을 다시 받거나 손패가 새로 섞이면 문제로 기록한다.

데스크톱은 지도 스크롤, 개인 카드 이름과 비용, 키보드 초점, 펼친 보관함을 확인한다. 모바일은 390px 정도의 좁은 폭에서 버튼 잘림·가로 넘침·한글 가독성·손패 스크롤을 점검한다. 이 항목들은 실제 브라우저에서 아직 확인하지 않았다.

기록 양식:

```text
시드 / 주인공 / 도시 / 출신:
브라우저 / 버전 / 창 크기:
진행 단계 / 장소 / 인재:
누른 버튼과 카드 순서:
예상 결과:
실제 결과:
새로고침 전후 차이:
콘솔 오류 전문:
화면 캡처 파일:
```

자동 테스트 통과는 실제 렌더링과 사람의 재미 검증을 대신하지 않는다.
