# 천하군진

**바로 플레이:** https://mambo10005.github.io/cheonha-gunjin/ — `main`에 푸시할 때마다 GitHub Actions(`.github/workflows/pages.yml`)가 빌드해 GitHub Pages에 올린다. 저장은 브라우저 localStorage에 남는다.

삼국지 장수 조합형 덱빌딩 로그라이트 — 브라우저 2D 프로토타입 v0.5

본편 진입은 **천하 캠페인 시작**이다. 시작 도시 → 거병 준비 → 세력 창설 → 도시 운영 → 실제 병력·군량을 싣고 출진 → 전투·설전·외교 → 도시 편입 → 복수 도시의 공통 턴과 보급 → 지역 패권으로 이어진다. 첫 통합 범위는 190년 하남의 형양·성고·공현 세 도시다. 기존 단일 원정은 **원정 도전**에 보존했다.

새 캠페인은 **시드 141001 공간형 도시 탐색**이다. 진궁·장료·곽가 중 주인공과 도시·출신을 고르고 최소 7장으로 시작한다. 형양 10개 장소를 연결된 도로로 이동하며 시간·피로·노출을 관리한다. 장소 사건, 인재 부탁·협력·등용, 카드·물품, 실제 설전·대결과 성장을 거쳐 거병한다. 거병 뒤에는 같은 도시 지도가 내정·인사·군단 운영으로 이어진다.

[도시 탐색 구현·검증·미완성 범위](docs/CITY-EXPLORATION.md) · [시드 141001 실행 안내](docs/CITY-EXPLORATION-GUIDE.md). 기존 121001/131001 거병 저장은 이전 경로·선택을 보존하여 계속한다. 이전 기록은 [탐색형 거병](docs/PROLOGUE.md)에 있다. 자동 규칙·DOM 테스트와 실제 브라우저·사용자 플레이 검증은 구분하며 실제 브라우저는 미검증이다.

전투 화면은 공간형 군진·열별 위협·실제 규칙 예상·저장 후 연출을 사용한다. **새 원정 → 군진 전투 체험 (91001)**에서 전위·곽가의 반격/의도 변경 조합을 확인한다. [전투 구현·실행·미검증 항목](docs/BATTLE-CINEMATIC.md)을 참고한다. 실제 브라우저 검증과 최종 원화·음향 제작은 남아 있다.

새 원정은 190년 낙양 주변의 역사 지명 맥락과 고정 지형을 사용하는 탐색 지도로 진행한다. [역사 지역 지도 구현·출처·실행 안내](docs/HISTORICAL-REGION.md)를 참고한다. `새 원정 → 역사 지리 원정 · 낙양 (81001)`에서 외교·설전·대결 경로를 비교할 수 있다. 기존 전용 데모와 저장은 기존 지도에서 계속한다. 규칙·DOM 자동 테스트와 실제 브라우저 플레이 검증을 구분하며, 새 지도의 실제 브라우저 검증은 미실시다.

군주가 되어 8층 원정 지도를 따라 낙양의 동탁에게 진군한다. 장수는 전열·후열 진형에 상주하는 **능력**이고,
전법 카드(武·防·策)는 매 턴 내리는 **명령**이다. 적은 다음 행동과 **공격할 열**을 미리 보여 준다.
방비를 그 열에 쌓을지, 계책으로 의도를 비틀지, 기세를 몰아 먼저 쓰러뜨릴지를 고른다.

설계 판단은 [docs/DESIGN.md](docs/DESIGN.md)에 있다.

## 실행

```bash
npm ci
npm run dev        # Vite 개발 서버 → 브라우저에서 열기
npm test           # 규칙 + JSDOM 자동 테스트
npm run sim        # 헤드리스 자동 플레이 200회 × 군주 2명
npm run sim -- 300 1   # 300회, 난이도 험로
npm run build      # 타입 검사 + 배포용 빌드(dist/)
npm run sim:exploration # 도시 탐색 정책별 자동 진행 + 저장 복원·내정·첫 출진
npm run sim:prologue # 탐색형 거병 56회 + 매 행동 저장 복원
npm run sim:raising # 카드 거병 자동 플레이 153회 + 매 행동 저장 복원
```

- Node **22.18 이상** 필요 (테스트·시뮬레이션은 Node의 TypeScript 타입 제거 기능으로 `.ts`를 직접 실행).
- 런타임 의존성 없음. 개발 의존성은 `vite`, `typescript`, DOM 검사용 `jsdom`과 타입 패키지다.

## 조작

- 카드를 누르면 선택 → 적이나 열(전열/후열)을 누르면 사용. 대상이 없는 카드는 한 번 더 누르면 사용.
- 선택한 카드는 실제 규칙으로 계산한 **미리보기**를 보여 준다(복제 상태에서 처리하므로 설명과 결과가 어긋나지 않음).
- 키보드: `1`~`9` 카드 선택, `E` 턴 종료, `Esc` 선택 취소. 우클릭도 선택 취소.
- 지도에서는 장수 열을 무료로 바꾸고, 전투 중에는 지휘력 1(조조는 매 턴 첫 교대 무료).

## 구조

```
src/
  core/        규칙 엔진 (DOM 없음)
    types.ts     모든 상태 타입
    rng.ts       시드 난수 (상태가 숫자 하나 → 저장·재현 가능)
    combat.ts    전투: 카드 처리 순서, 장수 훅, 적 턴, 미리보기
    run.ts       원정: 지도 생성, 이동, 보상, 영입, 시장, 휴식, 사건, 메타 해금
    describe.ts  효과 데이터 → 한국어 설명 자동 생성
    save.ts      버전 있는 저장/불러오기
  data/        장수·카드·적·사건·보물·지형·군주 데이터
  ui/          화면 표시(main.ts, style.css)
  sim/         헤드리스 자동 플레이
tests/         node:test 단위 테스트
docs/DESIGN.md 설계서
```

전투 상태(`BattleState`)와 원정 상태(`RunState`)는 분리되어 있고, 전투가 끝나면 `finishBattle`이 결과만 원정에 반영한다.
전투 도중 저장해도 시드 난수 상태까지 저장되므로 불러온 뒤 같은 행동을 하면 같은 결과가 나온다.

## 현재 범위

군주 2 · 장수 12(영입 8, 시작 2, 해금 2) · 전법 25 + 저주 2 · 보물 10 · 일반 편성 6 · 정예 2 · 보스 1(2단계) · 사건 6 · 지형 4.
구현된 빌드: 방어·반격, 화공, 기병·기세, 계책(부분). 첫 승리 시 진궁·마초와 난이도 「험로」 해금.

## 알려진 문제

- 밸런스는 봇 시뮬레이션으로만 맞췄다. 보스 직전까지는 쉽고 동탁에서 급격히 어려워지는 곡선이다.
- 군량 운영 빌드(⑤)는 설계만 있고 전용 장수가 없다.
- 장수 초상·효과음·애니메이션 없음(텍스트와 색으로 대체).
- 영구 해금은 첫 승리 1단계뿐이다.

## v0.2 — 무장 대결·설전·외교

기존 8층 원정(7층 + 결전), 장수 4명·전열/후열, 카드 덱·보상은 유지한다.

- 무장 대결: 화웅·장보·서량 기병 편성에서 선택적으로 제안(원정당 최대 2회). 4회 행동, 상대 다음 행동과 실제 규칙 미리보기. 거절 무료. 승리 전열 방비6, 무승부 방비2, 패배·기권은 첫 턴 지휘력-1.
- 설전: 실리·명분·신뢰·안전 논점에 대응하는 4회 협상. 도전 군량1. 영입 비용 할인, 보급 조건 개선, 외교 조건 개선. 결과 뒤 조건 수락 또는 포기. 기존 무료 영입은 유지.
- 외교: 지역 세력 3곳, 보급·통행·지원 거래 3종. 관계는 원정 안에서만 유지. 표시한 비용·보상·만료·관계 변화를 실제 적용. 거래 장소당1회, 지원 다음 전투1회, 통행 이동 회수로 만료.
- 활동 사건 4개를 기존 사건 칸에 배치(원정당 최대 2곳). 보급 거점에서도 기본 보상 또는 설전 선택. 대표의 적성·통찰·중재·반격·사절 특성 활용.
- 군주 선택의 **검증 원정 시작 (시드 31001)**: 군량20·전위/곽가/장료. 1층 대결 → 전투/보상 → 2층 영입 설전 → 3층 외교 보급으로 우호 → 4층 통행 또는 지원 → 후속 이동/전투. 일반 숫자 시드 입력과 구분되는 검증 전용 입구다.
- 원정 저장 버전2. 버전1 저장에 신규 활동 기본값을 채운다. 기존 전법 영문 ID는 유지. 진행 중 대결·설전, 관계·협정·결과 적용 상태·RNG까지 저장. 손상·비호환 저장은 안내하고 새 원정을 허용.
- 신규 화면은 social-view.ts·공통 html.ts로 분리. 규칙은 core의 duel/debate/diplomacy/social-run에 둔다. 타입 검사는 테스트·자동 플레이까지 포함한다. 런타임 의존성 없음. JSDOM은 화면 입력 회귀 테스트용 개발 의존성이다.

통합 판단·정확한 수치·유효 기간은 [docs/SOCIAL.md](docs/SOCIAL.md).
자동 플레이는 신규 상태에서도 끝까지 진행하지만 대표/협정의 장기 가치를 최적화하지 않는다. 실제 브라우저·모바일 렌더링·사람의 재미 평가는 별도 확인이 필요하다.


v0.2 검증: 테스트 **76개 통과**, 전체 타입 검사·Vite 빌드 통과, 군주2명×난이도2개×100회 자동 플레이 실행. DOM 클릭·저장 복원 회귀 테스트 통과. 실제 브라우저 접근은 환경의 로컬 서버 연결 실패로 미실시.


## v0.3 원정 빌드

시작 교리 3방향, 교리 슬롯 2개, 장수의 한 분기·2단계 성장, 대결 장착 전술과 성장 보상을 일반 전투에 연결했다. 1·3·5층 완료 후 성장·혼합·회복 중 선택한다. 군주 선택 화면의 빌드 검증 버튼(시드 41001)으로 같은 지도에서 세 방향을 비교할 수 있다.

v0.3 당시에는 첫 번째 완성 단위만 완료했다. 당시 설전/외교는 v0.2 규칙이었다. 규칙, 재현 방법, 저장 버전 3의 호환성, 한계와 다음 작업은 [docs/BUILD.md](docs/BUILD.md)를 기준으로 한다.

현재 v0.3 검증: 테스트 **96개**, 타입 검사·빌드 통과. 두 군주·두 난이도 총 160회 자동 플레이 및 세 빌드 고정 시나리오 실행. 실제 브라우저 확인은 로컬 파일 프로토콜 차단으로 미검증이다. 봇 승률은 재미 평가가 아니다.

## v0.4 설전과 지속 협정

상대별 요구·신뢰·부담을 충족하는 논거 조합, 실제 군량 지불·권한 약속, 교리/성장 정보와 협정 신용을 연결했다. 상단 후원·향촌 호송·공동 작전은 활성 2슬롯과 지정 보급/전투 의무를 갖고, 이행·만료·포기·교체에 따라 관계와 보상이 달라진다. 공동 작전은 지정 장수 성장으로 이어진다. 군주 선택의 **설전·협정 검증 원정 (시드 51001)**에서 확인할 수 있다.

테스트 **118개**, 타입 검사·Vite 빌드 통과. 실제 전투로 진행한 같은 시드의 협정 선택 세 비교는 `npm run sim:accords`로 재현한다. 저장 버전 4이며 이전 원정은 기존 활동 규칙으로 이어간다. 브라우저 도구의 로컬 파일 차단은 해제하지 못했고 실제 시각 검증·사람 플레이는 미실시다.

구체적 규칙, 직접 검증 결과, 구현 위치, 저장 호환성, 다음 단위는 [docs/ACCORDS.md](docs/ACCORDS.md)를 기준으로 한다. 전법 개조·정찰·위험 분기와 연속 사건·보스 변형은 후속 작업이다.

수동 브라우저 검증은 [docs/MANUAL-BROWSER-TEST.md](docs/MANUAL-BROWSER-TEST.md)를 따라 실행한다. 31001은 이전 활동 규칙, 51001은 최신 설전·지속 협정, 41001은 빌드·대결 전술을 확인한다. 자동 테스트와 사용자 확인 결과는 구분한다.

## 설전 인물 무대

설전을 좌우 인물·중앙 요구·논거 손패·이벤트 대기열로 개선했습니다. 규칙은 유지하며 패 선택 후 상세 미리보기에서 실행합니다. [설전 구현·수동 검증 기록](docs/DEBATE-SCENE.md), [정보 구조 와이어프레임](docs/DEBATE-WIREFRAME.html)을 참고하세요. 군주 선택 화면의 곽가/진궁 설전 무대 검증 버튼(51001)으로 진입할 수 있습니다. 임시 자체 제작 SVG를 사용하며 실제 브라우저 검증은 미검증입니다.


시네마틱 설전 첫 슬라이스(곽가·상단 교섭관·군막), 자산 사양과 미검증 항목은 [구현·검증 기록](docs/CINEMATIC-DEBATE.md)에 있습니다. 자동 테스트 통과와 실제 브라우저 플레이 검증을 구분합니다.


0.5.0 설전 덱 원정: 곽가/진궁 시작 덱·논법 인장·성장·원정 의무·저장 v5와 검증 한계는 [설전 덱 구축 기록](docs/DEBATE-DECK.md)을 참조하세요. 새 원정의 전용 시드 61001 버튼으로 진입합니다.


## 전략 지도 수직 단면

거점 선택 → 실제 이동 미리보기 → 진군 확정으로 변경했다. 낙양 행군도, 현재 주변 3층/전체/결전 카메라, 경로 비교, 의무 인장, 기록·군단 서랍을 제공한다. `docs/STRATEGIC-MAP.md`에 분석·규칙·아트 상태·수동 검증 방법을 기록했다.

현재 지도 변경 검증: `npm test` 180개 통과, `npm run build` 통과. 실제 브라우저 시각·모바일 터치 검증은 미실시이며 위 이전 검증 표의 브라우저 항목은 이번 지도 변경 검증으로 사용할 수 없다. `node scripts/render-map-fixtures.ts`는 정적 DOM 자료를 생성하며 브라우저 캡처가 아니다.

## 객사 인물·도시 의뢰

객사 주인·손님 초상과 대화, 주요 인재의 단계형 의뢰, 도시 조사·실제 설전/대결·귀환 보고, 소문·숙박·거병 후 정보와 외교를 연결했다. [구현과 검증](docs/INN.md), [시드 141001 실행 안내](docs/INN-PLAY-GUIDE.md)를 참조한다. `npm run sim:inn`으로 9개 정책 표본을 실행한다. 실제 브라우저와 사람 플레이는 미검증이다.
